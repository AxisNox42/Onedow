Onedow — 데스크톱 오버레이 로그라이트
========================================

압축을 푼 뒤 이 폴더(Onedow) 구조를 그대로 유지하세요.

  Onedow/
    Resource/     … 공용 (건드리지 마세요)
    Font/         … 공용
    Icons/        … 공용
    WindowsOS/
      Onedow.exe  … Windows 실행
    macOS/
      Onedow      … macOS 실행

실행 방법
---------
• Windows : WindowsOS\Onedow.exe 더블클릭
• macOS   : macOS/Onedow 더블클릭 (처음 실행 시 보안 허용 필요할 수 있음)

※ Resource·Font는 Onedow 폴더 바로 아래에 있어야 합니다.
  실행 파일만 따로 빼면 소리·폰트가 안 나올 수 있습니다.
