# 스킬 HUD 재설계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 좌하단 스킬 HUD를 아이콘 + 내부 부채꼴 쿨다운 + 패시브 원 행으로 바꿔, 준비/쿨다운/지속/빈 슬롯/패시브 상태가 어떤 바탕화면에서도 한눈에 읽히게 한다.

**Architecture:** 웨이브 HUD의 선 프리미티브를 `HudLines.h`로 뽑아 공유한다. 게임 상태 → 표시 상태 변환은 GL 없는 `SkillHudModel.h`(단위 테스트 대상), 그리기는 헤더 전용 `SkillHud.h`. `main.cpp`의 옛 `skillBox`/`drawSlot` 블록은 입력 채우기 + 두 함수 호출로 바뀐다.

**Tech Stack:** C++17, OpenGL 배치 렌더러(`BatchTri`, `drawCircle`), MSBuild(`scripts/build_windows.ps1`), cl 단일 파일 테스트, 스모크 캡처(`scripts/smoke_ui.ps1`).

**Spec:** `Docs/superpowers/specs/2026-10-17-skill-hud-design.md`

## Global Constraints

- 범위는 표시만. `EquipSkill`, 스킬 종류, 슬롯 수, 쿨다운 수치(`PlayerSkillCooldownMax`, `DASH_CD` 등)는 바꾸지 않는다.
- 선만 쓴다. 판·막 없음, 점선 없음. 예외는 쿨다운·충전의 내부 부채꼴 채움.
- 모든 선 글리프 밑에 키라인: 색 × 0.18, 알파 0.88, 두께 +3.2·hs (`KeyCol`).
- 글자는 키 글자(SHIFT/Q/E/R)와 쿨다운 중 남은 초(`ceil`)만. 스킬 이름 글자 없음.
- 액티브 사각 한 변 60·hs, 간격 10·hs, 4칸 고정. 패시브 원 반지름 17·hs, 간격 12·hs, 순서 RAIN → LSTP → DEATH, 가진 것만.
- 색: 대시 (0.40, 1.00, 1.00), TIME (0.40, 0.90, 1.00), CLOSE (0.50, 0.80, 1.00), FOCUS (0.59, 0.94, 0.86), RAIN (1.00, 0.50, 0.20), LSTP (0.70, 0.70, 0.85), DEATH (1.00, 0.36, 0.38), 빈 슬롯 (0.36, 0.41, 0.53).
- 펄스 길이 0.45초, 바깥으로 0 → 14·hs. PAUSED에서는 흐르지 않는다.
- 표시 상태: RUNNING, 인벤토리가 닫힌 PAUSED.
- 웨이브 HUD 동작은 바뀌지 않는다.

## Review Focus

- 런 재시작 직후: RAIN 타이머가 0으로 되감겨도 펄스가 나면 안 된다 → Task 2 `pulse_reset_no_spurious` + Task 5에서 재시작 경로에 `Reset()`.
- `cdMax`가 0이거나 `cd > cdMax`(옛 상태·스모크 값): 비율은 NaN 없이 0 ~ 1로 잘린다 → Task 2 `frac_clamped`.
- 쿨다운 중인 슬롯에 다른 스킬이 들어와 cd가 0이 됨: "쿨 끝남"이 아니므로 펄스가 나면 안 된다 → Task 2 `pulse_not_on_swap`.
- 두 자리 초가 60·hs 틀 안에서 흐린 아이콘 위에 겹쳐도 읽혀야 한다 → Task 5 MIX 캡처의 CLOSE "10"으로 확인 (흰·회색 합성 둘 다).
- 1280×720 같은 작은 창: 패시브 행과 액티브 행이 겹치지 않고 웨이브·HP 호와도 안 겹친다 → Task 5 캡처에 1280x720 추가.

### Task 2: 표시 상태 모델 `SkillHudModel.h` (TDD)

**Files:**
- Create: `WiNILL/Render/SkillHudModel.h`
- Test: `tests/skill_hud_model_test.cpp`, `scripts/test_skill_hud_model.ps1` (`scripts/test_quasar_fall.ps1`을 본떠 `/I WiNILL\Render`, 소스는 테스트 파일 하나)

**Interfaces:**
- Produces (모두 `namespace skill_hud`, GL·게임 헤더 include 없음, `<algorithm>`·`<cmath>`만):
  - `enum class SkillGlyph { Dash, Flash, Burst, Focus, TimeStop };`
  - `enum class PassiveGlyph { Rain, LightStep, Death };`
  - `enum class HudColor { Dash, Time, Close, Focus, Rain, LightStep, Death, Empty };`
  - `constexpr float kPulseDur = 0.45f;`
  - `struct SkillHudInputs { bool equipped[3]; SkillGlyph glyph[3]; float cd[3]; float cdMax[3]; float dashCd, dashCdMax; bool dashActive; float dashProgress; bool dashUpgrade; float hyperFocusTimer, hyperFocusDur; float timeStopTimer, timeStopDur; bool rainOwned; float rainTimer, rainCooldown; bool lightStepOwned; float lightStepDisable, lightStepHitLock; bool deathActive; int deathStacks; };`
  - `struct SkillSlotView { bool empty; SkillGlyph glyph; HudColor color; float cdRemain, cdMax; float elapsedFrac; float effectFrac; float pulse; const wchar_t* key; };` (`pulse` = 남은 펄스 시간, 0 ~ kPulseDur)
  - `struct PassiveView { PassiveGlyph glyph; HudColor color; float chargeFrac; bool on; int stacks; float pulse; };`
  - `struct SkillHudView { SkillSlotView slots[4]; PassiveView passives[3]; int passiveCount; };`
  - `struct SkillHudPulse { float slot[4]; float rain; float prevCd[4]; bool prevEquipped[4]; SkillGlyph prevGlyph[4]; float prevRain; void Reset(); void Update(const SkillHudInputs&, float delta); };`
  - `SkillHudView BuildSkillHudView(const SkillHudInputs&, const SkillHudPulse&);`

규칙(스펙에서): 입력 배열 `i`(0~2)는 뷰 슬롯 `i + 1`. 슬롯 0 = 대시(키 `L"SHIFT"`, glyph `dashUpgrade ? Flash : Dash`, 색 Dash), 슬롯 1~3 = Q/E/R(`equipped`가 false면 `empty`, 색 Empty). glyph → 색: Burst→Close, Focus→Focus, TimeStop→Time. `elapsedFrac = cdMax > 0 ? clamp(1 − cd/cdMax, 0, 1) : 1`이고 `cd <= 0`이면 1. `effectFrac`: Dash = `dashActive ? 1 − dashProgress : 0`, Focus = `hyperFocusTimer / hyperFocusDur`, TimeStop = `timeStopTimer / timeStopDur`, Burst = 0 (전부 0 ~ 1로 자름). RAIN `chargeFrac = rainTimer / rainCooldown`. LSTP `on = lightStepDisable <= 0`, OFF일 때 `chargeFrac = 1 − lightStepDisable / lightStepHitLock`, ON이면 1. DEATH `stacks = clamp(deathStacks, 1, 3)`. 펄스: 같은 슬롯이 직전 프레임에도 같은 glyph로 장착되어 있었고 `prevCd > 0 && cd <= 0`이면 `slot[i] = kPulseDur`; RAIN은 `prevRain > rainTimer + 0.5f`(되감김)이면 `rain = kPulseDur`; 그 외엔 `delta`만큼 줄인다. `delta <= 0`이면 아무 필드도 바꾸지 않는다.

- [ ] **Step 1: 실패하는 테스트 작성** (`tests/skill_hud_model_test.cpp`, `assert` + 마지막에 `std::puts("skill_hud_model: ok")`, 각 케이스는 `static void name()`)

```cpp
using namespace skill_hud;
static SkillHudInputs Base() { SkillHudInputs in{}; in.hyperFocusDur = 5.0f; in.timeStopDur = 1.5f;
    in.rainCooldown = 15.0f; in.lightStepHitLock = 10.0f; in.dashCdMax = 2.9f; return in; }
static bool Near(float a, float b) { return std::fabs(a - b) < 1e-4f; }

static void empty_slots() { auto v = BuildSkillHudView(Base(), SkillHudPulse{});
    assert(!v.slots[0].empty && v.slots[1].empty && v.slots[2].empty && v.slots[3].empty);
    assert(v.slots[1].color == HudColor::Empty); assert(v.passiveCount == 0); }
static void cooldown_frac() { auto in = Base(); in.equipped[0] = true; in.glyph[0] = SkillGlyph::Burst;
    in.cd[0] = 6.0f; in.cdMax[0] = 16.0f; auto v = BuildSkillHudView(in, SkillHudPulse{});
    assert(Near(v.slots[1].elapsedFrac, 0.625f)); assert(v.slots[1].color == HudColor::Close);
    assert(std::wcscmp(v.slots[1].key, L"Q") == 0); }
static void frac_clamped() { auto in = Base(); in.equipped[0] = true; in.glyph[0] = SkillGlyph::Burst;
    in.cd[0] = 5.0f; in.cdMax[0] = 0.0f; in.dashCd = 9.0f; in.dashCdMax = 2.9f;
    auto v = BuildSkillHudView(in, SkillHudPulse{});
    assert(v.slots[1].elapsedFrac >= 0.0f && v.slots[1].elapsedFrac <= 1.0f);
    assert(Near(v.slots[0].elapsedFrac, 0.0f)); }
static void effect_frac() { auto in = Base(); in.equipped[1] = true; in.glyph[1] = SkillGlyph::Focus;
    in.hyperFocusTimer = 2.5f; in.equipped[0] = true; in.glyph[0] = SkillGlyph::Burst;
    auto v = BuildSkillHudView(in, SkillHudPulse{});
    assert(Near(v.slots[2].effectFrac, 0.5f)); assert(Near(v.slots[1].effectFrac, 0.0f)); }
static void flash_glyph() { auto in = Base(); in.dashUpgrade = true;
    assert(BuildSkillHudView(in, SkillHudPulse{}).slots[0].glyph == SkillGlyph::Flash); }
static void passive_order_and_stacks() { auto in = Base(); in.deathActive = true; in.deathStacks = 5;
    in.rainOwned = true; in.rainTimer = 9.0f; auto v = BuildSkillHudView(in, SkillHudPulse{});
    assert(v.passiveCount == 2); assert(v.passives[0].glyph == PassiveGlyph::Rain);
    assert(Near(v.passives[0].chargeFrac, 0.6f)); assert(v.passives[1].stacks == 3); }
static void light_step_off() { auto in = Base(); in.lightStepOwned = true; in.lightStepDisable = 7.0f;
    auto v = BuildSkillHudView(in, SkillHudPulse{});
    assert(!v.passives[0].on && Near(v.passives[0].chargeFrac, 0.3f)); }
static void pulse_on_ready_and_pause() { auto in = Base(); in.equipped[2] = true; in.glyph[2] = SkillGlyph::TimeStop;
    in.cd[2] = 0.1f; SkillHudPulse p{}; p.Reset(); p.Update(in, 0.016f); in.cd[2] = 0.0f; p.Update(in, 0.016f);
    assert(Near(p.slot[3], kPulseDur)); p.Update(in, 0.0f); assert(Near(p.slot[3], kPulseDur));
    p.Update(in, 0.2f); assert(Near(p.slot[3], kPulseDur - 0.2f)); }
static void pulse_not_on_swap() { auto in = Base(); in.equipped[0] = true; in.glyph[0] = SkillGlyph::Burst;
    in.cd[0] = 8.0f; SkillHudPulse p{}; p.Reset(); p.Update(in, 0.016f);
    in.glyph[0] = SkillGlyph::Focus; in.cd[0] = 0.0f; p.Update(in, 0.016f); assert(Near(p.slot[1], 0.0f)); }
static void pulse_rain_fire() { auto in = Base(); in.rainOwned = true; in.rainTimer = 14.9f; SkillHudPulse p{}; p.Reset();
    p.Update(in, 0.016f); in.rainTimer = 0.0f; p.Update(in, 0.016f); assert(Near(p.rain, kPulseDur)); }
static void pulse_reset_no_spurious() { auto in = Base(); in.rainOwned = true; in.rainTimer = 12.0f;
    in.equipped[0] = true; in.glyph[0] = SkillGlyph::Burst; in.cd[0] = 3.0f; SkillHudPulse p{}; p.Reset();
    p.Update(in, 0.016f); p.Reset(); in.rainTimer = 0.0f; in.cd[0] = 0.0f; p.Update(in, 0.016f);
    assert(Near(p.rain, 0.0f) && Near(p.slot[1], 0.0f)); }
```
