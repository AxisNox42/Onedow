# NORMA 동작 구조 초안 v1

작성일: 2026-10-23. 대화에서 합의한 방향은 **본체와 스킬의 연관을 동작으로 먼저 만든다**는 것이다. 아래 동작은 검토용 제안이며 확정 외형이나 구현 명세가 아니다. 기존 패턴의 피해량·탄도·공간 판정은 바꾸지 않는다.

![십자 연사·조준 연사·창 닫기의 준비→실행→지속→회복](Concepts/Norma_Motion_Structure_v1.png)

동작 보드는 내장 image_gen으로 생성했다. 화살표는 동작 설명이며 실제 공격이나 연결선이 아니다. 그림의 직각 부품은 임시 외형이다. 조준 예고의 점 표기는 개념도 표현이며 실제 구현에서는 기존 선만 쓰는 규칙을 따른다.

## 공통 원칙

- 본체의 준비 자세에서 다음 행동의 방향과 성격이 읽혀야 한다.
- 본체가 움직이는 순간과 탄 발사·창 명령이 실행되는 순간을 맞춘다.
- 동작은 준비 → 힘을 쓰는 순간 → 지속 → 회복으로 나눈다. 발광을 빼도 구별되어야 한다.
- 코어는 피격 위치를 읽는 기준으로 유지한다. 외곽 부품은 회전·평행 이동·접힘을 시험하는 임시 선 구조다. 직각 프레임 4개 외형을 확정하지 않는다.
- 창 명령 레이저는 기존처럼 순간적으로 번쩍이고 사라진다. 창과 본체를 계속 잇는 선은 쓰지 않는다.
- 프레임의 이동이나 예고 도형 자체에는 새 피해 판정을 추가하지 않는다. 시각적으로 돌진·압착 피해를 암시하지 않도록 본체 판정의 기준을 유지한다.

창 닫기는 본체와 대상 창을 왕복해서 보게 만들지 않도록 **남은 시간·탈출 판단에 필요한 정보는 대상 창에 둔다.** 본체는 원인과 힘의 사용을 설명한다. 배경 창 조작이나 기존 창의 실제 크기 변경을 연출 때문에 추가하지 않는다.

## 창 생성과 다른 패턴에 연결

### 상시 창 생성

본체 외곽이 잠깐 모여 작은 사각 구도를 만들고, 한 번 벌어지는 순간 대상 위치로 생성 레이저가 번쩍인다. 대상 위치의 네 괄호는 기존 1.6배 크기에서 조여 붙고 창이 열린다. 본체가 펼쳐지는 힘과 창이 열리는 결과를 같은 순간에 맞춘다.

생성은 공격과 별도 주기로 작동한다. 연사 중에는 전체 본체 자세를 덮어쓰지 않고 코어의 짧은 수축과 대상 창의 괄호만 사용한다. 공격의 발사축·예고를 흐리지 않는다.

### 1 창 너머의 보스

대상 창 방향으로 외곽이 접혀 폭이 좁아지고, 기존 이동에 맞춰 코어와 외곽이 함께 창 안으로 들어간다. 도착 직후 네 발사구가 열리며 창 안 십자 연사를 시작한다. 나올 때는 발사를 멈추고 다시 접힌 뒤 복귀한다. 이동은 기존 경로를 따르고 새로운 순간이동을 제안하지 않는다.

### 2 피난 창

피난처 접근 보정과 기존 예고를 유지한다. 본체는 조준 연사와 달리 사방으로 크게 열리고, 기존 원형 탄 한 파가 나갈 때마다 바깥으로 한 번 팽창했다 돌아온다. 넓은 개방 자세가 전역 탄막을 예고한다. 피난 창에는 기존 강조를 유지해 시선이 실제 대피 위치로 향하게 한다.

### 8 탄 상자 던지기

기존 작은 창이 본체에서 커져 나오는 연출을 본체 동작에 연결한다. 본체는 창이 나오는 쪽으로 비대칭으로 벌어지고, 채우는 동안 짧게 맥동한다. 상자가 출발할 때 뒤로 당겼다가 앞으로 밀어내고 반동으로 복귀한다. 이후 상자의 비행·폭발은 독립해 진행되며 본체가 계속 연결되지는 않는다.

### 9 몹 소환

본체 외곽은 발사구처럼 바깥을 겨누지 않고 코어를 감싸는 닫힌 자세를 취한다. 소환 시작에 한 번 힘을 주고 대상 창의 기존 별자리 컴파일을 시작한다. 이후 예고의 주역은 창 안에서 별을 잇는 머리다. 본체의 기존 보조 사격은 발사 순간의 작은 반동만 사용한다. 소환이 끝날 때 코어가 짧게 풀리고, 취소된 창에서는 별자리 연결이 꺼진다.

## 검토 순서

1. 임시 코어와 선 부품으로 십자 연사·조준 연사·창 닫기의 준비 자세와 실행 순간을 나란히 본다.
2. 색·발광·파티클 없이도 세 행동이 구별되는지 확인한다.
3. 탄이 실제 발사구에서 나오고 창의 반응이 본체 동작과 맞는지 확인한다.
4. 실제 플레이 크기에서 공격 방향과 피격 위치가 읽히는지 본다.
5. 그 결과로 필요한 부품과 실루엣을 선택한 뒤 최종 외형·탄 모양·이펙트를 정한다.

기존 예고 시간 안에서 먼저 동작을 배분한다. 동작을 강조하기 위해 공격 시간이나 난이도를 바로 바꾸지 않는다. 회복 자세와 실제 공격 가능 시간은 일치시킨다.
