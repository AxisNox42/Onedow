# 난이도 선택 씬 재기획안

작성일: 2026-08-19

## 1. 핵심 방향

UI는 갈아엎는다는 기준으로 다시 잡는다. 이 게임은 PC 게임이므로 모바일처럼 모든 정보를 작게 압축할 필요가 없다.

목표는 `작은 설정창`이 아니라 `런 시작 전 작전 세팅 화면`이다. 메인 메뉴에서 시작을 누르면, 플레이어가 이번 판의 난이도, 총기, 시련을 큰 화면에서 확실히 고르고 바로 전투에 들어가는 구조가 좋다.

최종 권장 구조:

```text
MAIN MENU
  -> RUN CONFIG
      난이도 선택
      총기 선택
      시련 선택
      최종 요약
  -> GAME
```

여러 씬으로 나누지 않고, 한 씬 안에서 크게 보여주는 방향을 권장한다.

## 2. 난이도 철학 변경

기본 게임 자체의 난이도는 지금보다 조금 더 올리는 방향이 좋다.

시련은 부족한 난이도를 메우는 장치가 아니라, 이미 완성된 기본 난이도 위에 더 위험한 조건을 얹는 선택이어야 한다.

정리하면:

```text
기본 난이도 = 게임의 정식 밸런스
시련 = 추가 위험 + 추가 보상
```

이렇게 가야 시련을 선택하지 않은 플레이도 허전하지 않고, 시련을 선택했을 때는 "진짜 더 어려운 런을 선택했다"는 느낌이 난다.

## 3. 한 씬 유지 이유

PC 기준으로 UI를 크게 잡을 수 있다면, 한 화면에 3가지 정보를 넣는 것이 더 낫다.

장점:

- 난이도, 총기, 시련, 점수 배율을 한 번에 확인할 수 있다.
- 재도전 흐름이 빠르다.
- `EXECUTE` 직전에 최종 조합을 눈으로 확인할 수 있다.
- 시련이 선택사항이라는 점이 자연스럽게 드러난다.
- 메인 메뉴와 같은 배경을 유지하기 쉬워 화면 전환 피로가 적다.

여러 씬으로 나누는 방식은 선택지가 아주 많아졌을 때만 고려한다. 지금처럼 난이도 3개, 총기 4개, 시련 후보 3개라면 단일 씬이 적합하다.

## 4. 화면 레이아웃

PC 화면 기준으로 크게 3구역을 둔다.

```text
┌──────────────────────────────────────────────────────────────┐
│ RUN CONFIG                         PROFILE / SCORE RATE       │
├───────────────────────┬───────────────────────┬──────────────┤
│ DIFFICULTY            │ LOADOUT               │ OPTIONAL RISK │
│                       │                       │              │
│ [ EASY ]              │ [ RIFLE    ]          │ [ TRIAL A ]   │
│ [ NORMAL ]            │ [ REVOLVER ]          │ [ TRIAL B ]   │
│ [ HARD ]              │ [ SHOTGUN  ]          │ [ TRIAL C ]   │
│                       │ [ SMG      ]          │ [ REROLL  ]   │
├───────────────────────┴───────────────────────┴──────────────┤
│ [ BACK ]                                      [ EXECUTE RUN ] │
└──────────────────────────────────────────────────────────────┘
```

비율 권장:

- 난이도: 화면 가로의 35-40%
- 총기: 화면 가로의 35-40%
- 시련: 화면 가로의 20-25%

난이도와 총기는 크게, 시련은 선택사항답게 한 단계 작게 둔다.

## 5. 난이도 영역

난이도는 화면에서 가장 먼저 읽히는 영역이어야 한다.

권장 디자인:

- 왼쪽 대형 패널.
- Easy / Normal / Hard를 세로 카드 3개로 배치.
- 선택한 난이도는 카드 전체가 켜지고, 나머지는 낮은 알파로 둔다.
- 각 카드에는 긴 설명 대신 체감 포인트만 적는다.

예시:

```text
EASY
ASSISTED RUN
위협도 낮음 / 일부 압박 완화

NORMAL
STANDARD RUN
게임의 기준 밸런스

HARD
FULL PRESSURE
적 밀도와 보스 압박 강화
```

중요한 점은 `Easy = 너무 쉬운 모드`가 되면 안 된다는 것이다. Easy는 입문용이지만, 게임의 핵심 압박은 남아 있어야 한다.

## 6. 총기 선택 영역

총기는 이번 판의 플레이 감각을 정하므로 난이도만큼 중요하다.

권장 디자인:

- 중앙 대형 패널.
- 2x2 카드 배치.
- 각 총기는 이름, 역할, 간단한 스탯 방향을 보여준다.
- 선택한 총기에는 큰 무기 실루엣 또는 아이콘을 붙인다.

예시:

```text
RIFLE
Balanced
연사 / 안정성 / 기본형

REVOLVER
Burst
강한 단발 / 정밀함

SHOTGUN
Close Pressure
근거리 폭발력 / 위험한 거리

SMG
Suppressive Fire
고속 연사 / 낮은 단발 피해
```

총기 카드는 작게 만들면 선택 맛이 약하다. PC UI 기준에서는 카드 하나가 확실히 커야 한다.

## 7. 시련 영역

시련은 오른쪽 보조 패널로 둔다.

시련의 역할:

- 기본 난이도 위에 추가 위험을 얹는다.
- 점수 배율을 올린다.
- 선택하지 않아도 정상적인 런이 되게 한다.

권장 디자인:

```text
OPTIONAL RISK

[ OVERCLOCK    ]
enemy speed up

[ MEMORY LEAK  ]
max hp down

[ HARDENED     ]
enemy hp up

SCORE RATE x1.35
[ REROLL ]
```

규칙:

- 기본 선택은 0개.
- 선택 가능한 후보는 3개.
- `REROLL`은 이 영역 안에 둔다.
- `EXECUTE`는 시련을 고르지 않아도 항상 가능하다.
- 시련 선택 시 점수 배율이 즉시 크게 바뀌어야 한다.

## 8. 최종 요약 영역

상단 오른쪽 또는 하단 중앙에 최종 요약을 고정한다.

예시:

```text
PROFILE  NORMAL / SMG / 2 TRIALS
SCORE RATE x1.35
```

이 영역은 큰 UI에서 길을 잃지 않게 해주는 장치다. 플레이어는 어떤 카드를 눌렀든 마지막에 이 줄만 보고 현재 설정을 확인할 수 있어야 한다.

## 9. 버튼 구조

하단은 단순하게 둔다.

```text
[ BACK ]                                      [ EXECUTE RUN ]
```

`REROLL`은 하단 공통 버튼이 아니라 시련 패널 안에 둔다. 그래야 어떤 기능인지 명확하다.

`EXECUTE RUN`은 화면에서 가장 강한 버튼이어야 한다.

권장:

- 크기 크게.
- 선택 난이도 색을 약하게 반영.
- Hover 시 테두리와 내부 발광.
- 클릭 시 패널 전체가 짧게 점등되고 게임 시작.

## 10. 화면 전환

메인 메뉴와 배경은 동일하게 유지한다.

권장 연출:

- 전체 화면 검은 딤 사용 안 함.
- 배경은 그대로 유지.
- RUN CONFIG 패널만 부드럽게 등장.
- 난이도/총기/시련 패널이 0.05초 간격으로 순서대로 켜짐.
- 선택 시 카드 내부에 짧은 스캔라인 반응.

이 화면은 메인 메뉴에서 분리된 새 공간이 아니라, 메인 메뉴 위에 런 설정이 펼쳐지는 느낌이면 좋다.

## 11. 난이도와 시련의 관계

추천 밸런스 방향:

```text
EASY   = 낮은 압박이지만 게임의 핵심 패턴은 유지
NORMAL = 개발자가 의도한 기본 난이도
HARD   = 적 밀도, 보스 압박, 실수 비용 증가
TRIAL  = 어떤 난이도에서도 추가로 얹는 선택형 위험
```

시련은 Hard 전용 콘텐츠가 아니라 모든 난이도에서 선택 가능해야 한다.

예시 조합:

```text
Easy + 2 Trials
입문 난이도지만 특정 조건 때문에 긴장감이 생기는 런

Normal + 0 Trials
기본 정식 플레이

Hard + 3 Trials
도전용 고압박 플레이
```

이렇게 하면 플레이어가 자기 실력에 맞게 난이도를 세밀하게 조절할 수 있다.

## 12. 구현 우선순위

1. 현재 작은 패널 느낌을 버리고 화면 폭을 더 크게 사용한다.
2. 난이도 영역을 왼쪽 대형 세로 카드 3개로 재배치한다.
3. 총기 영역을 중앙 2x2 대형 카드로 재배치한다.
4. 시련 영역을 오른쪽 보조 패널로 정리하고 `REROLL`을 내부로 넣는다.
5. 상단 또는 하단에 `PROFILE / SCORE RATE` 요약을 크게 고정한다.
6. `EXECUTE RUN` 버튼을 가장 큰 액션으로 만든다.
7. 기본 난이도 수치를 전체적으로 약간 올리고, 시련은 추가 난이도 장치로 분리한다.

## 13. 최종 결론

난이도 선택 씬은 여러 단계로 쪼개지 않는다.

대신 PC 게임답게 한 화면을 크게 쓰고, `난이도 / 총기 / 시련`을 각각 독립된 대형 영역으로 보여준다.

가장 중요한 변경점은 시련의 위치다. 시련은 게임을 어렵게 만드는 주 장치가 아니라, 이미 충분히 성립하는 기본 난이도 위에 얹는 선택형 도전 요소로 둔다. 이 방향이 반복 플레이와 장기 밸런스 모두에 더 안정적이다.
