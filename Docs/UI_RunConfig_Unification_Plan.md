# UI 비주얼 리디자인 기획안 - RUN CONFIG 무드 기준

## 방향

이 작업은 단순히 버튼 모양을 맞추는 것이 아니라, 게임의 UI 전체 인상을 RUN CONFIG 쪽의 어둡고 선명한 시스템 UI로 바꾸는 작업이다.

목표는 다음 느낌이다.

- 별자리/천체 관측 장비 같은 기하학 UI
- 검은 OS 위에 뜬 전투 준비 시스템
- 장식은 적지만, 선과 코너가 날카로운 인터페이스
- 배경은 살아 있지만, 정보 패널은 확실히 읽히는 불투명한 구조
- 판타지 UI가 아니라 사이버 천문 관측 터미널 같은 분위기

## 핵심 무드 키워드

- `ASTRAL OS`
- `COMBAT TERMINAL`
- `CONSTELLATION MAP`
- `DARK GLASS, HARD FRAME`
- `PRE-RUN DIAGNOSTIC`

UI가 예쁜 창 모음이 아니라, 게임 세계 안의 전투 시스템 화면처럼 보여야 한다.

## 디자인 원칙

### 1. 투명 유리 느낌 줄이기

현재 여러 화면은 배경이 너무 많이 비쳐서 UI가 떠 보인다. 앞으로는 투명함보다 불투명한 어두운 면을 우선한다.

- 메인 패널 배경은 거의 불투명
- 텍스트 뒤에는 반드시 어두운 면
- 배경은 분위기용이고, 정보보다 강하면 안 됨

### 2. 글로우보다 명도

글로우를 키워서 눈에 띄게 하는 방식은 줄인다. 대신 대비와 면적, 텍스트 크기로 가시성을 만든다.

- 흰색/청백색 텍스트를 명확히 사용
- 고유 색상은 테두리, 코너, 선택 강조에 제한
- 번지는 글로우보다 또렷한 선

### 3. 장식 애니메이션 줄이기

로딩줄, 계속 흐르는 스윕, 의미 없는 점선 회전은 UI 의미를 흐린다.

허용:

- 선택 시 짧은 페이드
- 그래프 모핑
- 카드가 활성화될 때 코너가 밝아지는 정도

금지:

- 카드 밖으로 흐르는 라인
- 로딩바처럼 보이는 스윕
- 의미 없는 세로 슬라이더
- 과한 반짝임

### 4. 화면마다 다른 게임처럼 보이지 않게 하기

모든 화면은 같은 OS의 다른 페이지처럼 보여야 한다.

- RUN CONFIG: 전투 실행 준비 화면
- ARMORY: 장비/해금 관리 화면
- ASTRAL LOG: 관측 기록 화면
- SETTINGS: 시스템 설정 화면
- TRIAL SELECT: 위험 모듈 장착 화면

각 화면의 역할은 다르지만, 같은 시스템 언어를 사용한다.

## RUN CONFIG에서 가져갈 요소

RUN CONFIG의 다음 요소를 전체 UI 기준으로 삼는다.

- 큰 영문 타이틀
- 불투명한 어두운 패널
- 얇은 테두리와 굵은 코너 브라켓
- 선택된 항목의 색상 강조
- 좌측 선택 영역 + 우측 상세 영역
- 하단 또는 상세 패널 내부의 확정 버튼
- 스탯/수치/카드가 전부 데이터 패널처럼 보이는 구성

단, RUN CONFIG의 현재 상태를 그대로 복사하는 것이 아니라, 이 느낌을 기준으로 더 정제한다.

## 화면별 리디자인 방향

### MAIN MENU

현재 메인 메뉴가 다른 UI보다 독립적인 느낌이 강하면, RUN CONFIG로 넘어갈 때 연결감이 떨어진다.

변경 방향:

- 버튼을 더 단단한 패널형으로 변경
- 과한 육각형/장식형 버튼은 줄이기
- 시작 버튼을 RUN CONFIG의 실행 버튼과 같은 계열로 만들기
- 배경은 유지하되 버튼 뒤는 더 어둡고 선명하게

목표 느낌:

> 게임 진입 메뉴가 아니라, OS 부팅 후 주요 모듈을 여는 느낌

### RUN CONFIG

기준 화면이다.

더 다듬을 방향:

- 좌측 무기 카드의 장식선 최소화
- 선택 카드와 비선택 카드의 명도 차이를 명확히
- 시작 버튼은 상세 패널 안에 유지
- 시련 모듈과 시작 버튼이 하나의 실행 구역처럼 보이게 정리
- 그래프/스탯은 현재 방향 유지

목표 느낌:

> 출격 직전 무기 시스템과 위험 모듈을 확인하는 전투 준비 콘솔

### ARMORY

ARMORY는 상점이라기보다 영구 해금/장비 데이터베이스처럼 보여야 한다.

변경 방향:

- 카테고리 목록을 더 불투명하게
- 아이템 리스트는 RUN CONFIG의 선택 카드보다 작고 촘촘한 데이터 슬롯 느낌
- 우측 상세 패널은 큰 타이틀, 해금 상태, 효과, 구매 버튼 순서
- 구매 버튼은 패널 내부 하단에 배치
- 코인 패널은 자원 표시로 유지하되 시선 방해 금지

목표 느낌:

> 상점이 아니라 무기 시스템 저장소

### ASTRAL LOG

ASTRAL LOG는 도감보다는 관측 기록이어야 한다.

변경 방향:

- 고유창 느낌의 떠 있는 UI 제거
- 좌측 리스트는 ARMORY와 같은 데이터 목록으로 통일
- 우측은 관측 대상의 이름, 분류, 시각 자료, 기록 텍스트
- 미해금 항목도 같은 레이아웃을 유지하고 정보만 가림
- 별자리 노드/선은 이 화면의 핵심 비주얼로 사용

목표 느낌:

> 적과 모듈을 기록한 천문 관측 로그

### SETTINGS

SETTINGS는 기능 화면이라 가장 차분해야 한다.

변경 방향:

- 설명 텍스트는 제거한 현재 방향 유지
- 행 제목과 선택값만 명확히
- 각 행은 불투명한 장비 설정 슬롯처럼 보이게
- 좌측 탭 카드도 RUN CONFIG 카드와 같은 무드로 정리
- 위험 동작만 붉은색 사용

목표 느낌:

> OS 시스템 파라미터 설정 화면

### TRIAL SELECT

시련 선택은 위험 모듈을 장착하는 느낌이어야 한다.

변경 방향:

- RUN CONFIG에서 분리된 새 화면처럼 보이지 않게 함
- 시련 카드들은 위험 모듈 슬롯처럼 표현
- 선택된 시련은 강한 불투명 배경과 경고 색상
- 최종 시작 버튼은 우측 하단 내부에 배치
- 선택 개수는 시스템 카운터처럼 표시

목표 느낌:

> 출격 전에 위험 레이어를 장착하는 모듈 선택 화면

## 비주얼 세부 규칙

### 패널

- 배경 알파는 0.90 이상을 기본으로 한다.
- 카드 안의 텍스트가 배경과 섞이면 실패로 본다.
- 패널은 둥글지 않게, 직선과 코너를 중심으로 한다.

### 선

- 전체 테두리는 얇게
- 코너는 조금 굵게
- 의미 없는 내부 선은 제거
- 선이 텍스트를 가로지르면 안 됨

### 텍스트

- 제목은 크고 선명하게
- 부제목은 최대한 제거
- 설명문은 짧게
- 버튼 텍스트는 흰색 유지
- 호버 시 텍스트 색 반전 금지

### 색상

- 기본: 검은 네이비
- 텍스트: 흰색/청백색
- 강조: 화면 또는 선택 대상의 고유 색
- 위험: 붉은색
- 코인/자원: 노란색이지만 작고 절제

### 애니메이션

- 화면 진입: 짧은 페이드
- 선택 변경: 짧은 모핑/페이드
- 그래프: 부드러운 수치 이동
- 버튼: 호버 시 면 밝기 증가
- 금지: 로딩줄, 스윕, 과한 점선 회전

## 우선순위

1. RUN CONFIG 최종 고정
2. ARMORY를 RUN CONFIG 무드로 변경
3. SETTINGS를 같은 밀도와 패널 톤으로 정리
4. ASTRAL LOG의 고유창 UI 제거 및 관측 로그화
5. TRIAL SELECT를 위험 모듈 장착 화면으로 변경
6. MAIN MENU를 같은 OS 부팅/모듈 선택 느낌으로 정리

## 판단 기준

리디자인이 끝났을 때 다음 질문에 모두 그렇다고 답할 수 있어야 한다.

- 이 UI들이 같은 게임의 같은 시스템처럼 보이는가?
- 배경이 보이더라도 텍스트가 확실히 읽히는가?
- 버튼과 확정 동작이 즉시 눈에 들어오는가?
- 장식선이 기능을 방해하지 않는가?
- 판타지/일반 상점 UI가 아니라 전투 OS처럼 보이는가?
