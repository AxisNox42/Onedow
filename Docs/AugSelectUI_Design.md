## 목표

게임의 **가짜 OS 창** 테마를 살리면서,  
증강 선택이 "중요한 선택의 순간"처럼 느껴지게 한다.  
게임플레이 흐름을 너무 길게 끊지 않되, 등장 자체가 **연출**이 되도록.

## 설계 방향

### 1. 진입 연출 (Entrance)

```
트리거: AUG_SELECT 상태 진입 시
```

**페이즈 1 — 암전 페이드인 (0.0 ~ 0.18s)**

- 화면 전체에 반투명 다크 오버레이 페이드인 (alpha 0 → 0.72)
- 게임 월드는 그 아래에서 계속 보임 (완전 차단 아님)

**페이즈 2 — 카드 슬라이드인 (0.18s ~ 0.45s)**

- 카드 3장이 화면 아래에서 위로 슬라이드인
- 스태거: 카드 1 → 2 → 3, 각 0.06s 딜레이
- 이징: ease-out (빠르게 올라와서 제자리에서 살짝 바운스)
- 동시에 카드별 rarity 색 테두리가 페이드인

**페이즈 3 — 타이틀 표시 (0.35s)**

- "AUGMENT SELECT" 타이틀이 상단에서 페이드인

총 연출 시간: **~0.45s** (플레이 흐름 거의 안 끊김)

---

### 2. 카드 구조 (Card Layout)

게임의 **가짜 창** 스타일을 그대로 적용:

```
┌─────────────────────────────┐  ← 타이틀바 (rarity 색, WIN_TB 높이)
│  [COMMON]  child.exe        │
├─────────────────────────────┤
│                             │
│       [ICON 144×144]        │
│                             │
│       증강 이름             │
│                             │
├─────────────────────────────┤
│  설명 텍스트 (항상 표시)    │  ← 호버 불필요, 카드 안에 바로 표시
│                             │
│              [ 1 ]          │  ← 키 힌트
└─────────────────────────────┘
```

- 카드 배경: `drawRect` (rarity 색 × 0.12 밝기, alpha 0.92)
- 타이틀바: `DrawAppWindow` 스타일, rarity 색 기반
- 테두리: `drawNeonBorder` rarity 색
- 설명: 호버 없이도 카드 하단에 항상 표시 (2~3줄, 작은 폰트)
- 카드 크기: 280 × 420 (현재보다 20px 키움, 설명 영역 확보)

---

### 3. 호버 상태


| 항목      | Normal | Hovered      |
| ------- | ------ | ------------ |
| Y 오프셋   | 0      | -20px        |
| 테두리 밝기  | ×1.0   | ×1.6         |
| 배경 알파   | 0.92   | 0.96         |
| 타이틀바 알파 | 0.85   | 1.0          |
| 스케일     | 1.0    | 1.04 (중심 기준) |


스케일은 glm ortho 변환보다 카드 좌표 계산으로 근사 처리 (중심에서 w/h 각각 확장).

---

### 4. 선택 연출 (Select)

카드 선택 시:

1. 선택한 카드 **화이트 플래시** (TriggerFlash 사용)
2. 나머지 카드 빠르게 페이드아웃 (0.12s)
3. 선택 카드 0.08s 유지 후 전체 오버레이 페이드아웃
4. 게임 상태 복귀

총 퇴장 시간: **~0.22s**

---

### 5. 배경 오버레이

- `drawRect(0, 0, sw, sh, 0.02, 0.02, 0.06, overlayAlpha)`
- `overlayAlpha`: 진입 시 0 → 0.72 애니메이션, 퇴장 시 역방향

DEBUFF_SELECT는 오버레이 색을 붉은 계열로 변경:

- `drawRect(0, 0, sw, sh, 0.10, 0.01, 0.01, overlayAlpha)`

## 구현 계획

### 추가할 상태 변수 (static, Scene_AugSelect 내부)

```cpp
static float s_enterT  = 0.0f;   // 진입 애니메이션 타이머 (0→1)
static float s_exitT   = 0.0f;   // 퇴장 애니메이션 타이머 (0→1)
static bool  s_exiting = false;  // 퇴장 중 플래그
static int   s_picked  = -1;     // 선택된 카드 인덱스
```

### 진입 타이머 업데이트

```cpp
const float ENTER_DUR = 0.45f;
const float EXIT_DUR  = 0.22f;
if (!s_exiting) s_enterT = std::min(s_enterT + delta / ENTER_DUR, 1.0f);
if (s_exiting)  s_exitT  = std::min(s_exitT  + delta / EXIT_DUR,  1.0f);
```

### 카드 슬라이드 오프셋

```cpp
// 카드 i의 슬라이드 진행도 (스태거 0.06s per card)
float stagger = (float)i * 0.06f / ENTER_DUR;
float cardT   = std::min(std::max((s_enterT - stagger) / (1.0f - stagger), 0.0f), 1.0f);
// ease-out cubic
float ease    = 1.0f - (1.0f - cardT) * (1.0f - cardT) * (1.0f - cardT);
float slideY  = (1.0f - ease) * 120.0f;   // 120px 아래에서 올라옴
```
