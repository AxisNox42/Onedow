## 0. 핵심 방향 (한 줄 요약)

**PLAY 화면은 좌측 패널 없이, 중앙 성도(星圖) 캔버스 + 우측 정보 패널 + 하단 컨텍스트 바 3분할. 하단 바에는 BACK, 모드(WEAPONS/TRIALS), 모드 내 직접 선택지(RIFLE/FIELD, 군혜 칩), LAUNCH을 한 줄에 배치. 별자리 테마 + 무채움 라인 디자인, 배경화면이 잔잔하게 비치되 가시성 규칙으로 읽기를 보장.**

## 1. 구조 결정: 하단 컨텍스트 바 + 성도 캔버스 + 우측 정보 패널

### 왜 하단 바인가 (공간 효율)

- 기존 좌측 패널: 폭 ~320~380px × 높이 전체 소비 → 콘텐츠는 나머지 폭만 사용.
- 하단 바: 높이 ~85px만 소비 → **성도 콘텐츠가 거의 전체 폭(1640px 기준 ~1500px+)을 사용 가능**.
- PLAY 페이지 성격상 성도(가로형 별자리 캔버스)가 주인공이므로 하단 배치가 압도적으로 유리.
- 다른 페이지(ARMORY, ASTRAL_LOG 등)는 **좌측 패널 유지** — PLAY만 콘텐츠 성격이 다르다는 점에서 예외. (향후 다른 페이지들은 좌측 패널에 카테고리 추가, 검색 기능 등을 붙이는 방향으로 확장.)

### 하단 바 = "컨텍스트 바" (선택지를 바로 담는다)

무기가 2종(RIFLE / FIELD)뿐이라 모드 전환 없이 **바에 선택지를 직접 배치**한다:

```
◀ BACK │ WEAPONS ▾ │ ✦ RIFLE │ ✧ FIELD │ ✧ TRIALS(+3) ▾ │ ▶ LAUNCH (+3)
```

- 좌측 끝 `◀ BACK` — 메인메뉴 복귀 (보조 액션, 소규모).
- `WEAPONS` / `TRIALS` — 그룹 라벨 겸 모드 표시. 클릭 시 중앙 성도가 해당 그룹 위주로 포커스(칸 배치 강조), 선택지는 바에 상시 노출.
- 그룹 내 선택지 — WEAPONS 그룹: `✦ RIFLE` / `✧ FIELD` (클릭으로 바로 선택/해제, 선택 시 점등). TRIALS 그룹: `✧ TRIALS (+3)` 클릭으로 군혜 칩 레이어 토글 또는 `Scene_TrialSelectInline` 진입 (기존 경로 유지).
- 우측 끝 `▶ LAUNCH (+N)` — 실행 (주 액션, 강조). 선택 완성 시 점등.

### 3분할 역할

| 영역 | 역할 |
|---|---|
| **중앙 — 성도 캔버스** | 화면의 주인공. 바에서 선택할 때마다 별이 점등·연결되어 런 별자리가 완성되는 공간. 배경 별하늘 + 바탕화면이 그대로 비침. |
| **우측 — 정보 패널** | "진짜 정보" 전담. 선택된 무기의 6축 스탯 수치, 선택된 군혜 목록/설명, 런 요약(WEAPON / SHACKLES +N). 면 없이 코너 브라켓 + 문자로만. |
| **하단 — 컨텍스트 바** | BACK / 모드+선택지 / LAUNCH. 얇은 라인 + 문자 + 별 노드 아이콘. `bg_linear.png` 회전 레일이 뒤를 받침. |

## 2. 디자인 원칙: "무채움(無面) 3원칙"

1. **면 대신 선** — 구역 구분은 사각 패널/딤 없이 코너 브라켓, 얇은 가이드 라인, 별자리 연결선으로만.
2. **면 대신 점** — 선택 요소는 버튼 박스 대신 별 노드의 점등 상태(흐림 → 호버 → 점등+연결)로 표현.
3. **면 대신 문자** — 계층·구분은 문자 크기/자간/명도/정렬로. 구분선은 필요한 최소한만.

즉 화면 전체에 렌더되는 건 오직: **문자, 1px 선, 점(별), 텍스처 대비 필드, 그리고 플레이어의 바탕화면** 뿐이다.

---

## 3. 컨셉: "STAR CHART 위에서 그려지는 런 별자리"

- 이 게임은 **데스크탑 위 투명 오버레이**에서 돌아간다. PLAY 화면은 배경을 덮는 설정창이 아니라, **플레이어 화면 위에 떠 있는 밤하늘 성도(星圖)**.
- 메인메뉴와 시각적 연속: 메인메뉴의 별하늘 "다른 구역"을 확대해 들어온 느낌.
- 무기 + 군혜(Shackle) 선택이 별을 찍어 하나의 별자리를 완성하는 의식. 완성된 별자리는 해당 런의 상징.

## 4. 화면 구성: 면 없이 층을 만드는 법

면(차폐/딤)을 쓰지 않으므로, 층위(depth)와 구역(zone)은 아래 수단으로만 표현한다.

| 목적 | 면 없이 쓰는 수단 |
|---|---|
| 구역 경계 | 코너 브라켓 4개 + (필요 시) 얇은 상단 헤더 라인 1px |
| 시각적 층위 | 명도·선 굵기·점 크기 단계화 (배경 별 < 장식 선 < 정보 선 < 선택 노드) |
| 텍스트 가독성 | **1px 다크 아웃라인 + 소프트 섀도** (메인메뉴 텍스트 섀도 패스 재사용), 명도 ≥ 0.8 |
| 노드 강조 | 코어 점 `alpha ≥ 0.9` (사실상 불투명 점), 선택 시 제한적 글로우 — 글로우는 "점의 발광"이지 면이 아니므로 허용 |
| 연결선 | 1px + 느린 파동 알파 (`0.5 ~ 0.7`), 완성 순간 한 번 밝아졌다 안정 |

배경 처리:

- **전체 화면 딤/밴드/차폐 "면" 금지.** 바탕화면과 별 파티클이 그대로 비친다.
- 대신 **기존 그라디언트 텍스처를 이용한 국소 대비 필드**를 사용한다 — 딱딱한 사각 면이 아니라 부드럽게 흐려지는 텍스처 기반이므로 무채움 원칙과 충돌하지 않는다.
  - `bg_linear.png` 계열 (`DrawPersistentSceneLeftVignette`/`DrawSceneLeftVignette`, `Scenes.cpp:258-270`) — PLAY에서는 **90도 회전해 하단 바 뒤 대비 레일**로 사용. 다른 페이지는 좌측 레일 그대로.
  - `CircleTexture.png` 계열 — 우측 정보 패널의 텍스트 블록 뒤, 성도의 선택 노드 뒤 작은 원형 대비 필드 (메인메뉴의 bounded radial contrast field와 같은 기법).
  - `LeftGradient.png` / `LineTexture.png` — 구역 경계의 얇은 선·그라디언트 표현에 활용. 카드 박스 대체 재료.
  - `PanelTexture.png` — 면 없이 갈 때는 사용하지 않되, 극단적 배경 fallback(§5) 시에만 제한적으로 검토.
- 유일하게 허용되는 발광은 **선택된 별 노드와 LAUNCH의 로컬 글로우** (반경 작게, 노드 주변만).
- 스캔라인/CRT 효과는 메인메뉴와 동일 정책 (CRT ON 시 메뉴 자체 스캔라인 스킵 — MM-11 결정 계승).

텍스처 사용 규칙:

- 텍스처 대비 필드는 **"문자를 읽게 하는 도구"**이지 장식이 아니다. 정보가 없는 빈 공간에는 깔지 않는다.
- 알파는 낮게 (하단 레일 `0.15 ~ 0.30`, 노드/텍스트 뒤 원형 필드 `0.2 ~ 0.35` 시작값) — 스크린샷 3종으로 확정 (§5).
- 페이지 전환 시 깜빡임/노출 방지를 위해 대비 필드는 콘텐츠 reveal 게이트 밖에서 그린다 (기존 `bg_linear.png` 주석 정책, `Scenes.cpp:265-267` 계승).

## 5. 가시성 규칙 (무채움 전제)

면 없이 읽히게 만드는 장치들:

1. **문자에 아웃라인·섀도 의무화** — 모든 라벨/수치에 1px 다크 아웃라인. 이게 유일한 "보조 레이어"이며, 이조차 사각 면이 아니라 글리프 주변만 처리.
2. **노드 코어 불투명화** — 별의 중심 점은 `alpha ≥ 0.9`로 찍어 어떤 바탕 위에서도 점 자체는 항상 보이게.
3. **상태 기반 알파 3단계** (메인메뉴 결정 계승): Idle 흐림 → 호버 미세 점등 → 선택 점등+연결. 별자리 선은 "텍스트보다 낮은 시각 우선순위, 그러나 Idle에서도 구조 추적 가능" 수준.
4. **선택 시에만 글로우** — 글로우 범위는 노드에서 연결선 방향으로만 살짝. 전체 화면 블룸 금지 (`UI_RunConfig_Unification_Plan.md` 준수).
5. **텍스처 대비 필드** (§4) — `bg_linear.png` 하단 레일 + `CircleTexture.png` 국소 필드. 문자 아웃라인과 병용: 아웃라인이 점 수준의 보장, 텍스처 필드가 구역 수준의 보장.

### 밝은/움직이는 바탕 대응 (fallback 단계)

면 없이 가는 만큼 극단적 배경에서의 fallback을 단계적으로 정의:

1. (기본) 문자 아웃라인 + 노드 코어 불투명 + 텍스처 대비 필드 기본 알파.
2. 가독성 붕괴 시 → **문자 아웃라인을 2px/더 진하게** + 하단 레일/국소 필드 알파 상승 (`0.3 → 0.45` 범위).
3. 그래도 안 될 시 → 선택 노드 글로우 반경 확대, `CircleTexture.png` 필드 반경 확대.
4. **전역 딤 면 도입은 최후의 수단**으로만 검토 — 도입하더라도 `PanelTexture.png`/radial 그라디언트 같은 부드러운 텍스처 기반 국소 필드로 한정. 가능하면 1~3단계로 커버하는 것이 목표.

검증 시나리오 (반드시): **어두운 바탕 / 밝은 바탕 / 움직이는(동영상) 바탕** 3종 × 상태(Idle/호버/선택/완성) 조합 런타임 스크린샷.

## 6. 레이아웃 (1640×910 기준, `uiS` 비례)

```
┌─                                                                    ─┐ ← 코너 브라켓만
  PLAY // RUN PREPARATION                                      [ESC]
                                                                         │
  ┌─ 중앙: STAR CHART 캔버스 ───────────────────────┐  ┌─ 우측: 정보 패널 ────────┐
  │                                                 │  │  WEAPON      RIFLE       │
  │        ✦ RIFLE 별 클러스터 (선택 시 점등)        │  │  ─────────────────────   │
  │        ✧ FIELD 별 클러스터                       │  │  6축 스탯 수치 바          │
  │                                                 │  │  DMG ██░░░  SPD ██░…     │
  │        ◇◇◇ 군혜 궤도 띠 (TRIALS 포커스 시 강조) ◇◇◇│  │                          │
  │                                                 │  │  SHACKLES  +3            │
  │   (선택할 때마다 별이 연결되며 런 별자리 완성)     │  │  · S1  · S2  · S3        │
  │                                                 │  │  (각 군혜 설명 한 줄)     │
  └─────────────────────────────────────────────────┘  │                          │
                                                         │  ────────────────        │
                                                         │  RUN READY ✦            │
                                                         └──────────────────────────┘
  ◀ BACK ┆ WEAPONS ▾ ┆ ✦ RIFLE ┆ ✧ FIELD ┆ ✧ TRIALS (+3) ┆ ············· ▶ LAUNCH (+3)
     ↑ BACK 좌측 끝 / LAUNCH 우측 끝 강조 / 그룹 사이 얇은 구분선(┆) / bg_linear 회전 레일
└─                                                                    ─┘
   ↑ 모든 빈 공간은 바탕화면 + 별하늘 그대로 비침
```

- **중앙 성도 캔버스** — 무기별 별 클러스터(RIFLE/FIELD 각각 별 그룹), 군혜는 궤도 띠(가로 스크롤, 화살표+휠/드래그, `WorldScissor` 클리핑). 바에서 선택할 때마다 해당 별이 점등되고 연결선이 생기며, 전부 유효하면 하나의 별자리가 완성되는 연출. 칩/노드 경계도 면 없이 점/선으로.
- **우측 정보 패널** — 현재 선택 상태를 "읽는" 공간. 무기 6축 스탯 수치, 군혜 목록+설명, 런 요약, 준비 완료 표시. 이 패널 덕에 중앙 성도는 장식 없이 정보 표현에만 집중 가능. 코너 브라켓 + 문자 + 얇은 구분선만.
- **하단 컨텍스트 바** — `◀ BACK`(좌측 끝, 보조) / `WEAPONS`(그룹 라벨, 클릭 시 중앙 성도가 무기 그룹 포커스) / `✦ RIFLE` `✧ FIELD`(직접 선택·해제, 점등) / `✧ TRIALS (+3)`(클릭 시 성도 군혜 포커스, 롱클릭 또는 서브 진입으로 `Scene_TrialSelectInline`) / `▶ LAUNCH (+3)`(우측 끝, 주 액션, 완성 시 점등). 그룹 사이는 얇은 구분선(`┆`), 버튼은 라인+문자+작은 별 노드 아이콘. `bg_linear.png` 회전 레일이 뒤를 받쳐 하단 문자 가독성 확보.
- 헤더 우측에는 `[ESC]` 힌트만 (BACK이 하단에 있으므로 중복 배치 금지). ESC/우클릭 뒤로가기 단축키 유지.

## 7. 상호작용 흐름

1. 메인메뉴 PLAY → STAR CHART 펼침 (기존 `s_MainMenuRunConfigPanel` / `playExit` 진출입 구조 유지).
2. 하단 `✦ RIFLE` / `✧ FIELD` 클릭 → 중앙 해당 별 점등 + 우측 정보 패널에 6축 스탯 표시. 재클릭으로 해제.
3. `✧ TRIALS (+N)` 클릭 → 중앙 성도의 군혜 궤도 띠 포커스 → 칩 선택/해제, 서브 진입 시 `Scene_TrialSelectInline` (기존 경로 유지).
4. 선택할 때마다 중앙 성도에 별/연결선 갱신, 우측 요약 실시간 갱신.
5. `▶ LAUNCH (+N)` → collapse + 별자리 점등 연출 → 군혜 있으면 무작위 배정 후 TrialSelect, 없으면 `FinalizeLoadout` → READY.
6. 하단 `◀ BACK` 또는 ESC/우클릭으로 메인메뉴 복귀.

## 9. 리스크 / 주의

- **최대 리스크 = 가독성.** 면 없이 가는 만큼, 어두운 바탕에서는 글자가 번지고 밝은 바탕에서는 흐려질 수 있음. §5 fallback 단계(문자 아웃라인 → 텍스처 필드 알파 상승 → 글로우 확대 → 국소 radial)를 코드 상수로 미리 분리필 것.
- 텍스처 필드도 과용하면 "면"과 다를 바 없어짐 — 정보가 있는 위치(하단 바, 우측 패널, 선택 노드)에만 배치하고, 빈 공간 깔지 않기.
- 하단 바 버튼이 6개 그룹(BACK/WEAPONS/RIFLE/FIELD/TRIALS/LAUNCH)으로 늘어남 — 폭 부족 시 그룹 라벨(WEAPONS)은 생략하고 선택지만 노출, 라벨은 툴팁/포커스 시 표시. 1640px 기준으로는 여유 있음.
- PLAY만 다른 페이지와 배치가 다름(하단 바) — 진입 시 한눈에 구조가 파악되는지 테스트. 하단 바 버튼이 직관적이므로 리스크 낮음으로 예상.
- `Scenes.cpp` 11k+ 라인 단일 파일 + CRLF 혼합 → 구간 단위 편집, 빌드 즉시 검증.
