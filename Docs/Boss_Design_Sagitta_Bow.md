# 보스 기획안: SAGITTA.trace / Constellation Archer

**내부 클래스명:** `SagittaBowBoss`  
**보스 픽 번호:** `21` (문서상 임시 예약, 코드 미등록)  
**역할:** 특별 캠페인 보스  
**태그라인:** `You moved exactly where the stars expected.`  
**경고 색상:** `{ 0.36f, 0.78f, 1.0f }` (청록 + 별빛 흰색)

---

## 1. 보스 아이덴티티

SAGITTA.trace는 검 보스와 반대 방향의 도파민을 노린다.

검 보스가 좁은 공간에서 한 끗 차이로 베기를 피하는 보스라면, SAGITTA는 넓은 공간에서 플레이어가 "어디로 움직일지"를 읽고 압박하는 장거리 심리전 보스다.

핵심 이미지는 활, 별자리, 예측 사격, 가짜 조준선이다. 플레이어는 탄속 자체보다 예고선, 별점, 연결 순서, 가짜 별자리의 규칙을 읽어야 한다.

전투 감각:

- 넓은 공간을 쓰게 만든다.
- 플레이어가 안전하다고 느낀 이동 경로를 뒤늦게 봉쇄한다.
- 즉사보다 누적 압박이 중심이다.
- 보스는 플레이어를 직접 몰아붙이기보다, 플레이어가 스스로 나쁜 위치를 고르게 만든다.

---

## 2. 금지 요소

- 좁은 공간 근접 회피 중심 설계 금지
- 즉사기 또는 Task Kill 계열 최종보스 연출 금지
- 경고 없이 날아오는 저격 화살 금지
- 화면 전체를 막는 불투명 별자리 선 금지
- 한 번 피한 뒤에도 계속 따라오는 강유도 화살 금지
- TESS의 브레스처럼 중심에서 전방위 난사하는 패턴 금지
- Ether Sword의 검 돌진처럼 한 번 맞으면 전투가 터지는 고정 30 이상 피해 금지

SAGITTA의 난이도는 "피할 수 없어서 어렵다"가 아니라 "읽어야 할 정보가 많아서 어렵다"여야 한다.

| 항목 | 값 |

보스 본체는 강하게 쫓아오지 않는다. 대신 맵 전체에 별점과 조준선을 깔아 플레이어 이동 방향을 제어한다.

## 4. 전투 핵심 규칙

### 별점과 별자리 선

대부분의 패턴은 `StarNode`를 먼저 찍고, 이후 노드끼리 선이 연결되면서 공격이 발생한다.

권장 구조:

```cpp
struct StarNode {
    float x, y;
    float t;
    float warn;
    float life;
    int group;
    bool fake;
    bool armed;
};
```

색상 규칙:

- 청록 별점: 실제 공격
- 흰색 별점: 연결 예고
- 흐린 보라 별점: 가짜 예고
- 금색 별점: 지연 발사 또는 강화 화살

가짜 별점은 완전히 랜덤이면 안 된다. 가짜는 실제 별보다 알파가 낮고, 깜빡임 주기가 약간 느리다.

### 예측 사격

SAGITTA는 플레이어 현재 위치가 아니라 플레이어의 최근 이동 방향을 기준으로 조준한다.

예측은 과도하면 불쾌하므로 발사 직전에는 보정을 멈춘다.

권장 방식:

- 경고 시작: 플레이어 위치 + 최근 속도 0.55초 예측
- 경고 중반: 예측 방향 고정
- 발사 직전 0.18초: 조준선 고정, 더 이상 추적하지 않음

## 5. 페이즈 구조

### Phase 1: Star Reading

목표는 규칙 학습이다. 플레이어가 별점, 선 연결, 조준선 고정을 이해하게 만든다.

사용 패턴:

- Star Mark
- Hunter Line
- Sagitta Rain 소형

감각:

- 넓은 공간을 천천히 읽는다.
- 조준선이 완전히 추적하지 않는다는 것을 배운다.
- 가짜 별자리는 아직 거의 나오지 않는다.

### Phase 2: Constellation Hunt

가짜 별자리와 경로 봉쇄가 시작된다.

사용 패턴:

- Star Mark 강화
- Hunter Line 2연속
- False Constellation
- Orion Net
- Sagitta Rain

감각:

- 안전한 방향처럼 보이는 곳이 1초 뒤 막힌다.
- 플레이어는 단순 반사신경보다 이동 계획을 요구받는다.
- 가짜/진짜 예고를 구분해야 한다.

### Phase 3: Parallax Eclipse

보스가 잔상과 시차를 사용한다. 실제 발사 위치와 가짜 발사 위치를 구분하는 단계다.

사용 패턴:

- 모든 기본 패턴 강화
- Parallax Hunt
- Orion Net + Hunter Line 연계
- Eclipse Draw

감각:

- 화면은 넓지만 압박감은 강하다.
- 플레이어는 "지금 안전한 곳"보다 "곧 안전해질 곳"으로 이동해야 한다.
- 최종보스급 즉사는 없지만, 판단 실수가 누적 피해로 크게 돌아온다.

## 6. 기본 스킬

### Star Mark

플레이어 주변과 이동 예상 경로에 별점 3~5개를 찍고, 짧은 지연 후 별점끼리 선을 연결한다.

동작:

1. 별점 생성
2. 0.75~1.05초 경고
3. 별점끼리 선 연결
4. 연결선 위에 짧은 피해 판정 발생
5. 선 방향을 따라 작은 화살 1~2발 발사

수치:

| 난이도 | 별점 수 | 경고 | 선 피해 | 화살 피해 |
|--------|---------|------|---------|-----------|
| 쉬움 | 3 | 1.10s | 4 | 6 |
| 보통 | 4 | 0.92s | 6 | 8 |
| 어려움 | 5 | 0.74s | 8 | 10 |

의도:

- 플레이어가 별점의 연결 순서를 읽도록 한다.
- 넓은 공간을 쓰지만 무작정 도망가면 선에 막히게 만든다.

### Hunter Line

활 보스의 기본 저격 패턴이다. 긴 조준선이 플레이어의 예상 이동 경로를 겨눈다.

동작:

1. 보스가 활시위를 당김
2. 플레이어 예상 위치에 조준선 생성
3. 0.55~0.85초 동안 조준선이 천천히 보정
4. 발사 직전 0.18초 동안 조준선 고정
5. 빠른 화살 1발 발사

수치:

- 화살 속도: 쉬움 720 / 보통 860 / 어려움 980
- 피해: 쉬움 9 / 보통 12 / 어려움 14
- 화살 크기: 작음, 명확한 꼬리 이펙트
- 관통 없음

의도:

- 보고 피할 수 있는 저격.
- 마지막 순간 방향 전환보다, 조준 고정 타이밍을 읽는 패턴.

### Sagitta Rain

하늘에서 낙하 화살이 떨어진다. 낙하지점은 별빛 원으로 먼저 표시된다.

동작:

1. 맵 위쪽에 흐린 별무리 생성
2. 낙하지점 6~14개 표시
3. 0.70초 후 화살 낙하
4. 일부 화살은 착탄 후 짧은 별먼지 장판 생성

수치:

- 낙하 피해: 9~13
- 별먼지 장판: 1.2초, 2 HP/s
- 쉬움에서는 장판 없음

의도:

- 넓은 공간에서 이동 루트를 계속 바꾸게 한다.
- Hunter Line과 겹치면 지나치게 어려워지므로 같은 순간 완전 중첩 금지.

## 7. 특수 스킬

### False Constellation

가짜 별자리와 진짜 별자리를 동시에 보여준다.

동작:

1. 별점 6~9개 생성
2. 그중 30~45%는 가짜
3. 실제 별점은 깜빡임이 빠르고 중심부가 선명함
4. 가짜 별점은 연결 직전 사라짐
5. 진짜 별점끼리 선이 연결되며 화살 발사

난이도 조정:

- 쉬움: 가짜 별점 없음
- 보통: P2부터 가짜 2개
- 어려움: P2부터 가짜 3~4개, P3에서 가짜 연결선도 잠깐 표시

의도:

- 플레이어가 색과 깜빡임 규칙을 학습하면 대응 가능해야 한다.
- 완전 랜덤 심리전이 아니라 정보 판독 심리전이어야 한다.

### Orion Net

맵 전체에 별자리 그물을 만든다. 즉시 막는 장벽이 아니라, 곧 위험해질 선을 미리 보여준다.

동작:

1. 화면 외곽과 중앙 사이에 별점 8~12개 배치
2. 별점끼리 5~8개의 선 연결 예고
3. 선이 순차적으로 활성화
4. 활성화된 선은 0.45초 동안 피해 판정
5. 마지막에 보스가 가장 넓은 빈 공간을 향해 Hunter Line 발사

수치:

- 선 피해: 쉬움 4 / 보통 6 / 어려움 8
- 선 활성 간격: 쉬움 0.32s / 보통 0.25s / 어려움 0.20s
- 마지막 Hunter Line 피해는 기본값보다 20% 낮춤

의도:

- "넓은 공간인데 숨 막히는" 핵심 패턴.
- 플레이어가 빈 공간을 찾는 동안 보스가 그 빈 공간을 읽고 저격한다.

### Parallax Hunt

P3 전용. 보스 잔상이 여러 개 생기고, 그중 하나만 실제 발사 위치가 된다.

동작:

1. 보스 주변에 잔상 3개 생성
2. 잔상마다 조준선을 짧게 표시
3. 실제 보스의 조준선만 끝부분 별빛이 더 밝음
4. 0.70초 후 실제 위치에서 화살 발사
5. 가짜 조준선은 작은 별먼지만 남기고 사라짐

수치:

- 피해: 13
- 어려움에서는 2연속 사용 가능
- 연속 사용 시 두 번째 화살 피해 20% 감소

의도:

- 화면을 화려하게 만들되, 판별 규칙은 남긴다.
- 최종보스급 즉사 대신 집중력 테스트로 설계한다.

### Eclipse Draw

P3 특수 패턴. 보스가 화면 상단에서 거대한 별빛 활을 당기고, 별자리 선들이 안전 루트를 만든다.

동작:

1. 보스가 화면 상단 중앙으로 이동
2. 1.15초 동안 거대한 활시위 연출
3. 화면에 별자리 선 10~14개 표시
4. 안전 루트 2~3개는 선이 끊겨 있음
5. 보스가 넓은 부채꼴 화살비를 발사

수치:

- 화살비 피해: 탄당 5~7
- 지속 시간: 1.0초
- 쉬움: 안전 루트 3개
- 보통: 안전 루트 3개
- 어려움: 안전 루트 2개

의도:

- 최종보스 즉사기처럼 보이지만 실제로는 누적 피해 패턴.
- 특별 캠페인 보스의 클라이맥스 역할.

## 8. 난이도별 조정

### 쉬움

- 경고 시간이 18~25% 길다.
- 가짜 별자리 사용을 P3로 제한한다.
- Sagitta Rain의 별먼지 장판을 제거한다.
- Hunter Line은 발사 직전 조준 고정 시간이 더 길다.
- Orion Net 선 수를 줄인다.

### 보통

- 기본 수치를 사용한다.
- P2부터 False Constellation 사용.
- P3에서 Parallax Hunt와 Eclipse Draw 사용.

### 어려움

- 경고 시간이 12~18% 짧다.
- 예측 사격 보정이 더 정확하다.
- False Constellation의 가짜 별점 수가 증가한다.
- P3에서 Parallax Hunt 2연속 가능.
- Eclipse Draw의 안전 루트가 2개로 감소한다.

어려움에서도 경고 없이 맞는 공격은 없어야 한다.

## 9. 렌더링/연출 메모

### 보스 외형

- 코어는 작은 별 또는 조준 렌즈처럼 보이게 한다.
- 활은 물리적인 나무 활보다 빛의 활에 가깝다.
- 활시위는 얇은 청록 선으로 표현하고, 차징 중 떨림을 준다.
- P3에서는 보스 주변에 별자리 원반과 잔상 3개가 생긴다.

### 공격 예고

- 실제 조준선: 청록 + 중심부 선명
- 가짜 조준선: 보라 + 알파 낮음
- 강화 화살: 금색 별점이 섞임
- 위험 선은 너무 두껍지 않게 하고, 실제 판정 폭보다 약간 넓게 보이게 한다.

### 배경

- 별무리 배경은 낮은 알파로만 사용한다.
- 화면이 어두워져 플레이어 탄과 적탄 판독이 어려워지면 안 된다.
- P3에서는 별자리 선이 배경에도 얇게 생기지만, 실제 공격선과 색을 분리한다.

## 10. 구현 메모

권장 컨테이너:

```cpp
std::vector<StarNode> stars;
std::vector<ConstellationLine> lines;
std::vector<ArrowShot> arrows;
std::vector<SagittaFx> fx;
```

권장 스킬 enum:

```cpp
enum class SkillType {
    StarMark,
    HunterLine,
    SagittaRain,
    FalseConstellation,
    OrionNet,
    ParallaxHunt,
    EclipseDraw
};
```

구현 원칙:

- 별자리 선 피해는 `line segment distance`로 판정한다.
- 화살은 필요하면 `Bullet`을 재사용해도 되지만, 조준선/별자리 판정은 보스 내부 전용 구조로 관리한다.
- 모든 공격은 `warn -> active -> fade` 상태를 가진다.
- 플레이어 예측 위치는 최근 0.25~0.40초 이동 벡터를 기반으로 계산한다.
- 조준선은 발사 직전 고정되어야 한다.
- 가짜 예고는 렌더링만 하고 피해 판정을 만들지 않는다.

성능 주의:

- 별자리 선은 한 번에 12개 이하로 제한한다.
- 배경 별무리는 실제 판정 객체와 분리한다.
- P3 잔상은 공격 판정 없이 렌더링 전용으로 둔다.

## 11. 다른 보스와의 역할 차이

### Ether Sword와 차이

ETHER_SWORD는 좁은 공간, 돌진, 즉사기, 최종 선택지를 담당한다. SAGITTA는 넓은 공간, 예측 사격, 가짜 정보 판독, 누적 압박을 담당한다.

검:

- 가까움
- 빠른 반응
- 한 끗 회피
- 큰 피해와 즉사 위협

활:

- 멂
- 이동 계획
- 정보 판독
- 심리전과 누적 피해

### TESS와 차이

TESS는 중력과 화면 장악이 핵심이다. SAGITTA는 화면을 직접 장악하기보다, 플레이어가 선택한 경로를 별자리로 처벌한다.

TESS:

- 중력장
- 블랙홀
- 중심부 브레스

## 13. 의도 요약

SAGITTA.trace는 플레이어를 빠르게 죽이는 보스가 아니라, 플레이어가 스스로 안전하다고 판단한 공간을 의심하게 만드는 보스다.

좋은 플레이 감각:

- "지금 피하는 게 아니라 다음 선을 보고 움직여야 한다."
- "저 조준선은 나를 따라오는 게 아니라 내가 갈 곳을 보고 있다."
- "가짜 별자리를 구분하면 숨 쉴 공간이 보인다."

실패한 플레이 감각:

- "어디서 맞았는지 모르겠다."
- "조준선이 너무 많아서 그냥 랜덤 같다."
- "넓은 맵인데 갈 곳이 없다."

구현 시에는 반드시 성공한 플레이 감각 쪽을 우선한다.
