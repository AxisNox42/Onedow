# 엘리트 몹 공통 규칙

작성일: 2026-10-17

엘리트는 기존 몹을 강화한 형태로 만든다. 기존 몹의 본체와 정체성을 출발점으로 삼는다.

## 확정 규칙

1. **엘리트 몹은 전투 패턴이 2가지 이상이다.**
2. **각 패턴은 플레이어가 같은 패턴이라고 받아들이지 않도록 시각적으로 구별된다.**
3. **각 패턴은 근거리·원거리 빌드 모두에게 대응을 요구한다.** 거리가 멀다는 이유로 한 패턴을 계속 무시할 수 있게 만들지 않는다. 빌드별 회피 방식과 난이도까지 같아야 한다는 뜻은 아니다.

## 규칙을 판정하는 방법 — 제안

아래는 위 세 규칙을 검토하기 위한 기준이며, 별도로 확정된 추가 규칙은 아니다.

- 패턴은 플레이어가 예고를 읽고 대응하는 하나의 공격 단위로 센다. 충전·발사·회복은 한 패턴의 단계다. 사망 연출은 전투 패턴 수에서 제외한다.
- 색·피해량·속도·발사 횟수만 바꾼 공격은 별도 패턴으로 인정하지 않는다. 빔을 두껍게 하거나 여러 갈래로 늘리는 것만으로는 시각적 구별이 충분하지 않다.
- 예고 단계에서 다른 패턴임을 알 수 있어야 한다. 본체의 자세, 예고 도형, 위험 영역의 모양, 움직임을 나란히 비교한다.
- 색과 설명을 가린 상태에서도 두 공격을 구별할 수 있는지 확인한다. 실제 플레이 크기와 다른 적이 섞인 화면에서도 확인한다.
- 회피 행동까지 달라지면 구별이 더 분명해진다. 이는 설계 권장 사항이다.

## 첫 적용: 퀘이사

기존 양방향 빔을 패턴 1로 유지하고, 패턴 2로 **강착 파편 연속 폭격**을 적용했다. 플레이어 주변에 0.2초 간격으로 18발을 발사하며 각 발은 고정 범위를 예고한 뒤 착탄한다. 피해와 난이도는 플레이 검증 대상이다.

상세: [퀘이사 엘리트 설계](Quasar_Elite_Design.md)

## 제네시스 — 로터 연속 출격

기존 SWARM 투척은 유지하고, 이전 협공을 **로터 연속 출격**으로 교체했다. 투척은 삼각 SWARM·착지 원이고, 로터 출격은 후방 생산 1외피·전방 가이드 2외피를 쓰는 큰 사각형의 고속 연사다. 0.4초마다 현재 위치를 조준하며 발사 후에는 고정 착탄점으로 직진한다. 사거리 제한 없이 일반 로터를 출격시킨다. 로터가 도착하면 예고한 반경 80px 안에 1회 범위 피해를 준다.

상세: [제네시스 로터 출격 구현](Genesis_Elite_Rotor_Design.md). [이전 협공 기록](Genesis_Elite_Design.md)은 과정 자료로 보관한다.

## 그라비스 — 궤도 투석 / 압축 활강 (시안)

이전 장판형 안이 반려·철회되어 새로 적용했다. 패턴 1은 궤도의 위성을 한 점으로 쏘고 곡선으로 회수하는 **궤도 투석**, 패턴 2는 노드를 압축한 본체가 고정된 도착점으로 활강해 원 안의 플레이어에게 피해와 슬로우를 주는 **압축 활강**(밀치지 않아 중력장이 그대로 붙잡는다)이다. 기존 중력장은 끌어당기기만 하며, 활강의 압축·활강·폭발 동안만 정지한다. 본체와 투석은 따로 돌아서, 투석 중에도 투석을 제외한 모든 행동(표류·중력장·활강)이 가능하다. 소환·장판·탄막·필드 강화는 쓰지 않는다. 피해와 시간은 플레이 검증 대상이다.

상세: [그라비스 궤도 투석·압축 활강](Gravis_Elite_Orbit_Design.md)
