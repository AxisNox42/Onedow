## 1. 점선 제거 (QA 1)

### 원칙

- 점선은 모두 **연속 실선**으로 바꾼다.
- 점선이 "꺼짐·깨짐·대기" 같은 **상태**를 뜻하던 곳은 점선 대신 **어둡고 가는 실선**으로 표현하고, 회복될 때 밝기와 굵기로 돌아온다.
- 점선은 둘레의 절반 정도만 그려졌으므로, 실선으로 바꿀 때 투명도를 약 0.65배로 낮춰 시각적 무게를 유지한다 (UI 작업과 같은 기준).

### 대상

| 몹 | 현재 점선 | 바뀔 모습 |
| --- | --- | --- |
| GENESIS | 조준선 (조준 중 점선 → 발사 직전 실선) | 처음부터 실선. 조준 진행에 따라 **투명도와 굵기**가 올라가며 발사 직전에 가장 진함 |
| GENESIS | 착지 피해 범위 원 (점선 고리) | 얇은 실선 고리 + 기존 붉은 면. 비행 중 안쪽 채움(착지 타이머)은 유지 |
| QUASAR | 원반 뒤쪽 절반 (짧은 호 9개) | 연속된 어두운 호. 앞쪽 절반보다 얇고 어둡게 해서 앞뒤 깊이는 유지 |
| QUASAR | 축받이 링 (짧은 호 18개) | 얇은 연속 고리. 열기에 따라 밝기만 변함 |
| QUASAR | 발사 순간 방출 링 (안쪽 점선) | 안쪽 고리도 실선 |
| GRAVIS | 중력장 경계 (짧은 호 24개) | 아주 옅은 연속 고리. 기존 원형 면은 유지 |
| REGULUS | 깨진 보호막 판 (점선) | 어두운 얇은 실선 판. 재생 8초 동안 굵기·밝기가 원래대로 회복 |

### 검증

- 스모크로 몹별 정지 캡처 전후 비교.
- 점선 패턴(`dashed=true`, 일정 간격 `continue`) 검색 결과가 몹 렌더링에서 0건인지 확인.

## 2. GENESIS 투척 속도 (QA 3) — 완료 (2026-10-11)

출발점에서 목적지까지 거리 비율로 속도가 바뀐다.

| 구간 (거리 기준) | 속도 |
| --- | --- |
| 0 ~ 60% | 1400 px/s |
| 60 ~ 80% | 1100 px/s |
| 80 ~ 100% | 600 px/s |

- 600px 거리 비행 시간: 약 0.57초 (이전 고정 1100 px/s 기준 0.55초).
- 착지 범위 원의 안쪽 채움은 실제 남은 비행 시간 기준이라 그대로 맞는다.
- 회귀 테스트: 구간별 실측 속도 1400 / 1106 / 603 px/s, 서 있는 플레이어 기준 투척 1회당 평균 피해 17.1 (이전 15.0).

## 3. MAGNETAR 튕겨내기 연출 (QA 4)

### 목표

탄이 "사라지는" 것이 아니라 **필드 고리에 맞고 튕겨 나가는** 것으로 보이게 한다. 막기 판정과 막는 횟수는 그대로이며 **연출만** 바꾼다.

### 연출

| 요소 | 내용 |
| --- | --- |
| 반사 잔상 | 탄이 필드 고리와 만난 지점에서 **입사각 그대로 반사된 방향**으로 짧게(약 0.25초) 날아가며 사라지는 금빛 잔상. 피해 판정 없음 |
| 고리 출렁임 | 부딪힌 지점의 필드 고리가 바깥으로 살짝 부풀었다가 돌아오고, 좌우로 퍼지는 밝은 파동 |
| 극 셀 | 가장 바깥 셀이 꺼지는 기존 연출 유지 |
| 번개 | **제거** (셀에서 흡수 지점으로 튀던 지그재그) |

### 구현 메모

- 지금은 막은 지점만 기록한다. 반사 방향을 그리려면 **탄의 진행 방향**도 함께 기록해야 한다.
- 한 프레임에 여러 발을 막을 수 있으므로 최근 막기 기록을 4개 정도의 작은 배열로 둔다.

## 4. MAGNETAR 가득 충전 (QA 5)

### 현재

스택이 초당 0.3~1.2개(주변 2티어 이상 아군 수에 따라)씩 1개 단위로 차오른다.

### 제안 규칙 (택1, 추천 **가**)

| 안 | 규칙 | 플레이 감각 |
| --- | --- | --- |
| **가 (추천)** | 일부만 깎인 상태에서는 **회복하지 않는다**. 스택이 0이 되면 필드가 꺼지고, **재충전 시간** 뒤 8개가 한 번에 가득 찬다 | "다 깎아서 깨야 한다". 깨면 확실한 공격 기회(재충전 시간 동안 무방비) |
| 나 | 마지막으로 막은 뒤 **일정 시간 안 맞으면** 8개가 한 번에 가득 찬다 | 사격을 멈추면 바로 복구. 압박을 계속 유지해야 함 |

### "가"안 세부

- 재충전 시간: 기본 **6초**. 기존처럼 주변 아군 지원을 반영해 최대 **3초**까지 짧아진다 (기존 회복 속도 0.3~1.2 비율을 그대로 사용).
- 재충전 중 극 셀: 8칸 전부 회색에서, **진행도만큼 동시에 은은하게 차오르는 빛**(개별 칸이 하나씩 켜지는 게 아님)으로 "곧 가득 찬다"를 예고한다.
- 가득 차는 순간: 극 셀 8칸이 동시에 켜지고 필드가 본체에서 펼쳐진다 (기존 0.35초 펼침 재사용).
- 도감 문구의 "초당 0.3~1.2 회복"을 새 규칙으로 갱신한다.

## 6. GENESIS 리디자인 (QA 7) — 구조 유지, 완성도 보강

QA 확인: **구조는 좋고 디자인이 부족하다.** 육각 선체, 정면 포구, 후미 반동 판, 삼각 약실, 투척 규칙은 유지한다.

진단: 얇은 외곽선 위주라 속이 비어 보이고, 모듈·후미 판이 작아 REGULUS·MAGNETAR에 비해 마감이 약하다.

시안 ([`Concepts/Redesign_Genesis_Quasar_v3_1.png`](../Concepts/Redesign_Genesis_Quasar_v3_1.png)):

| 안 | 내용 |
| --- | --- |
| A. 장갑판 선체 | 선체 각 변을 면이 있는 사다리꼴 장갑판으로, 포구 양옆에 턱판, 약실 꼭짓점에서 선체로 이어지는 갈비살, 후미 판 확대 |
| B. 공학 프레임 | 이중 벽 사이 버팀대, 꼭짓점의 각진 모듈, 포구 레일에 눈금 |
| C. 반응로 코어 | 선체는 가볍게 두고 약실을 키우고, 코어 둘레 고리로 생산 기관을 강조 |

## 7. GENESIS·QUASAR 처음부터 리디자인 (2026-10-11 방향 확정)

이전 시안(장갑판·공학 프레임·반응로 / 강착 띠·다층 원반)은 기존 외형의 보강이라 폐기한다. 두 몹 모두 외형을 처음부터 다시 만든다.
게임 규칙(GENESIS 투척 주기·속도·착지 충격파, QUASAR 양방향 빔·상태 흐름)은 유지한다.

### 공통 원칙

1. **점선 없음** — 모든 선은 실선.
2. **면 없음, 그래도 비어 보이지 않게** — 채움은 쓰지 않는다. 바깥 윤곽 안쪽에 안쪽 윤곽을 한 겹 더 두고, 패널 선을 새겨 밀도를 만든다. 상태(약실 충전 등)는 겹친 밝은 선으로 표현한다.
3. **한 유닛** — 바깥 윤곽이 하나로 이어지고, 포구·약실·원반·방출구 같은 기능 부품은 본체에 박혀 있거나 지지대로 연결된다. 떠다니는 별개 부품이 없다.

### 시안 ([`Concepts/Redesign_Genesis_Quasar_v4.png`](../Concepts/Redesign_Genesis_Quasar_v4.png))

| 안 | 콘셉트 |
| --- | --- |
| G1. 함수형 선체 | 하나의 선체, 앞머리 홈이 포구, 계단형 꼬리 안에 반동 살, 중앙에 삼각 약실 |
| G2. 삼각 요새 | 모서리를 자른 큰 삼각 본체 자체가 약실 구조, 앞 모서리 포구, 뒷변 반동 살 |
| G3. 포탑 | 육각 장갑과 앞 포신 블록이 한 몸, 꼬리 지느러미 |
| Q1. 렌즈 선체 | 렌즈 모양 몸체 안에 원반 고리, 양 끝 방출구, 코어와 지지대 연결 |
| Q2. 자이로 구체 | 이중 구체 윤곽 + 감긴 띠 2개 + 두른 적도 플랜지, 플랜지 끝 방출구 |
| Q3. 고리 성채 | 두꺼운 고리 몸체와 허브를 지지대 4개로 연결, 허브 양쪽 방출구 |

### 결정 (2026-10-11)

- **QUASAR: Q2 자이로 구체**로 확정.
- **GENESIS: G1~G3 폐기** ("구조가 너무 단순하고 밤티"). 탄창(스택)은 **포구 반대편(선미)**에 둔다.

| 안 | 콘셉트 |
| --- | --- |
| V1. 레일 프리깃 | 깎은 면 화살촉 선체, 홈 포구, 쌍 레일, 선미에 파인 탄창 칸(세로 3칸) |
