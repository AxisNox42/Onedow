# 웨이브 적 출현 설계

2026-10-13 기준. [웨이브 리팩터링 계획](Wave_Refactor_Plan_2026-10-13.md)의 WAVE-07 단계이며, [경험치 리팩터링 계획](Experience_Refactor_Plan_2026-10-13.md)의 XP 단계와 섞지 않는다. 현재 게임은 난이도 선택 없이 보통으로 시작하므로, 이번 코드 적용 범위는 보통 난이도다. 쉬움·어려움과 5티어는 향후 적용할 설계로 남긴다.

## 전투 규칙

- 각 웨이브는 전투 시간 180초다. 0~60초에 등장 구성을 소개하고, 60~120초에 수를 늘리며, 120~180초에 가장 높은 밀도를 유지한다. 웨이브 경계에서 적을 지우거나 전투를 멈추지 않는다.
- 웨이브 번호는 출현 밀도와 일반 몹의 티어 해금을 정한다. 쉬움·보통·어려움은 각각 일반 몹의 **최대 티어 2·3·4**, 정기 엘리트의 **목표 티어 3·4·5**를 정한다. 최대 티어는 모든 웨이브에서 그 티어가 즉시 나온다는 뜻이 아니다.
- 정기 엘리트는 **5의 배수 웨이브**에서 출현한다. 현재 10웨이브 런에서는 5·10웨이브다. 최종 웨이브 수가 난이도별로 바뀌어도 같은 규칙을 적용한다. 출현 시점은 대상 웨이브 시작 후 90초를 기본안으로 둔다.
- 정기 엘리트는 해당 난이도의 목표 티어에서 1종을 선택하는 별도 출현 이벤트로 설계한다. 기존 일반 스폰의 무작위 고티어 출현은 정기 엘리트 횟수에 포함하지 않는다. 기존 적의 종류별 동시 출현 상한은 유지하고, 이벤트용 자리를 예약해 정기 출현이 일반 스폰에 막히지 않게 한다.
- 5티어 적은 현재 존재하지 않는다. 어려움의 5티어 엘리트 출현 자리는 설계에만 예약한다. 5티어가 없는 동안에는 기존 4티어 적 1종을 임시 후보로 배치하고, 실제 적을 가짜 5티어로 표시하거나 5티어 보상을 지급하지 않는다. 5티어 몹이 추가되면 이 자리의 후보만 교체한다.

## 현재 몹과 출현 티어

| 출현 티어 | 현재 후보 | 정책 |
|---|---|---|
| 1 | 로터, 스웜 | 모든 난이도의 기본 물량. 스웜은 제네시스가 던진 개체와 자연 출현 개체의 상한을 구분한다. |
| 2 | 짐벌, 스코프, 안타레스 | 일반 풀에 단계적으로 추가한다. 스코프는 별도 원거리 스폰 경로에 같은 티어 상한을 적용한다. |
| 3 | 그라비스, 레굴루스, 마그네타 | 쉬움의 정기 엘리트 후보, 보통·어려움의 후반 일반 후보. |
| 4 | 제네시스, 퀘이사 | 보통의 정기 엘리트 후보, 어려움의 후반 일반 후보. |
| 5 | 미구현 | 어려움의 정기 엘리트용 예약 티어. 실제 종류·패턴·보상은 별도 설계 후 추가한다. |

출현 티어는 적 배치의 분류다. `MonsterManager::CollisionTier`는 충돌 우선순위이며 출현 티어의 근거로 사용하지 않는다. 현재 `Codex.h`의 제네시스·퀘이사 표기는 2티어, 레굴루스는 2.5티어지만 전투 구현과 `Astral_Enemy_Blueprints_v3.md`에서는 제네시스·퀘이사를 4티어로 취급한다. 코드 적용 단계에서 도감 표기와 출현 분류를 함께 확정해 플레이어에게 서로 다른 티어가 보이지 않도록 한다.

| 웨이브 | 일반 몹 해금 상한: 쉬움 / 보통 / 어려움 | 정기 엘리트 목표: 쉬움 / 보통 / 어려움 |

| 2 | 2 / 2 / 2 | 없음 |

새 티어는 해금 웨이브의 출현 풀에 소량만 섞고, 뒤의 웨이브에서 비중을 늘린다. 낮은 티어의 물량은 남겨 각 난이도에서 상위 티어만으로 화면이 채워지지 않게 한다. 정기 엘리트는 일반 몹 해금 상한을 넘을 수 있지만 난이도별 **엘리트 목표 티어**를 넘지 않는다.

## 밀도 초깃값과 안전 상한

아래 값은 플레이테스트 시작점이다. 3분 동안의 압박과 성능을 확인한 뒤 조정한다.

| 항목 | 기본안 |
|---|---|
| 웨이브 압박 배율 | `1 + 0.10 × (웨이브 - 1)` (1웨이브 1.0, 10웨이브 1.9) |
| 3분 구간 배율 | 0~60초 1.0, 60~120초 1.15, 120~180초 1.3 |
| 난이도별 출현량 배율 | 현재 보통 1.0. 쉬움 0.85·어려움 1.15는 난이도 선택 구현 이후 적용할 설계값 |
| 일반 몹 동시 상한 | 보통 기준 `24 + 8 × (웨이브 - 1)`; 쉬움 0.85배, 어려움 1.15배, 최종 160 이하 |
| 고위험 종류별 동시 상한 | 현행 제네시스 2, 퀘이사 2, 그라비스 1, 레굴루스 1, 마그네타 1 등 유지 |

출현량 배율은 기본 스폰 주기에 적용한다. 스폰 주기·한 번에 나오는 수·동시 상한을 동시에 키우면 압박이 과하게 중첩되므로, 우선 스폰 주기와 동시 상한만 조정한다. 3분 구간이 바뀌는 순간 일회성 폭증을 만들지 않고 다음 스폰부터 새 배율을 적용한다. 적이 상한에 닿으면 스폰을 건너뛰며 밀린 개체를 나중에 한꺼번에 생성하지 않는다.

## 코드 적용 순서와 완료 조건

| 단계 | 작업 | 완료 조건 |
|---|---|---|
| SPAWN-01 | 현재 `EnemySpawner`의 점수·누적 시간 조건, `GetDifficultyParams(NORMAL)` 고정 호출, 런 설정의 `Difficulty::NORMAL` 초기화 경로를 기준 기록으로 남긴다. | 현재 세 난이도를 선택할 수 없는 상태와 티어 표기 불일치가 확인된다. |
| SPAWN-02 | 보통 난이도의 출현 티어 상한과 웨이브별 해금표를 일반·원거리 스폰에 적용한다. | 보통의 일반 몹은 1웨이브에 1티어, 2~3웨이브에 최대 2티어, 4웨이브부터 최대 3티어다. 점수·누적 시간의 기존 특수 변환이 4티어를 우회 출현시키지 않는다. |
| SPAWN-03 | 보통 난이도에서 웨이브 내부 3구간 밀도와 동시 상한을 적용한다. | 후반 60초가 초반보다 빽빽하고, 웨이브가 진행될수록 출현 주기와 동시 상한이 증가한다. |
| SPAWN-04 | 5의 배수 웨이브에서 기존 4티어 몹을 한 번 출현시킨다. | 현재 10웨이브에서 5·10웨이브의 90초 지점에 각각 한 번만 출현하고, 일시정지·레벨업 화면에서 시간이 흐르지 않아 중복되지 않는다. |
| SPAWN-05 | 출현 기록과 플레이테스트로 3분 밀도, 종류별 동시 상한, FPS·생존 시간·XP 획득을 확인해 조정한다. | 보통 난이도 1/5/10웨이브의 실제 출현 종류와 수가 정책에 맞고, 화면 과밀이나 처리 지연이 없다. |
| SPAWN-FUTURE | 난이도 선택이 생기면 쉬움·어려움의 티어 상한과 밀도를 적용한다. 어려움은 5티어 몹이 만들어질 때까지 기존 4티어를 정기 엘리트 임시 후보로 쓴다. | 선택한 난이도가 런 종료까지 유지되고, 쉬움·보통·어려움의 일반 상한 2·3·4 및 엘리트 목표 3·4·5가 맞는다. |

SPAWN-01 조사 당시 `EnemySpawner.cpp`는 누적 전투 시간·점수로 물량과 고티어 몹 변환을 결정했다. 현재 런 설정은 여전히 난이도를 보통으로 초기화하며, 원거리 스폰도 `GetDifficultyParams(Difficulty::NORMAL)`을 사용한다. 난이도 선택이 도입될 때에는 스폰 경로와 실제 런 난이도 전달을 함께 바꿔야 한다.

## 보통 난이도 코드 적용·확인 (2026-10-13)

- `EnemySpawner.cpp`의 자연 출현은 1웨이브에 로터·스웜, 2웨이브부터 짐벌·안타레스·스코프, 4웨이브부터 그라비스·레굴루스·마그네타가 후보가 되도록 바꿨다. 제네시스·퀘이사는 자연 출현 풀에서 제외했다. 높은 티어의 종류별 동시 상한은 유지한다.
- 기본 출현 주기에는 웨이브 배율 `1 + 0.10 × (웨이브 - 1)`과 60초 단위 배율 `1.0 / 1.15 / 1.30`을 적용한다. 한 번에 나오는 일반 몹은 2마리로 고정하고, 동시 상한은 `24 + 8 × (웨이브 - 1) + mobCapBonus`, 최대 160이다. 기존 시간·점수 기반 체력 배율과 시련 보정은 유지한다.
- 5·10웨이브 시작 후 90초에 제네시스 또는 퀘이사 한 마리를 출현시킨다. 일반 몹 동시 상한과 별도의 한 자리를 쓰고, 한 웨이브에서는 성공한 이벤트를 다시 실행하지 않는다.
- Windows x64 Release 빌드와 1280×720 스모크를 통과했다. 스모크 시각 지정으로 4웨이브와 5웨이브 90초 이전에는 4티어가 0마리임을 확인했다. 5웨이브 90초 뒤 1마리, 같은 시각 반복 후에도 1마리, 10웨이브 90초 뒤에는 누적 2마리였다. 이는 시간 점프를 이용한 출현 규칙 확인이며, 3분 전체 플레이 밸런스 검증은 SPAWN-05에 남긴다.
