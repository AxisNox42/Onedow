# 퀘이사 동작 v4 — 실제 렌더링 미리보기

1200×800, 한국어, 블러 끔. 고정 초기 시드로 각 지정 시점까지 게임 업데이트를 실행한 뒤 캡처했다.

- `Barrage_Preview.gif`: 폭격 준비 시작 0.00–3.12초, 0.08초 간격 40프레임. 수축·감속 → 전개·가속 → 회전하며 휘어지는 파편 궤적.
- `Beam_Preview.gif`: 빔 준비 시작 0.00–2.48초, 0.08초 간격 32프레임. 감속·압축 → 잠금·가속 → 발사.
- `01_Gather.png`, `02_Open.png`, `03_CurvedFlight.png`, `04_BeamLock.png`: 원본 해상도의 대표 프레임.

GIF는 원본 캡처를 팔레트로 압축해 80ms 간격으로 묶은 QA 자료다. 마지막에서 처음으로 돌아가는 순간은 미리보기의 반복이며 실제 공격의 상태 전환이 아니다. 화면의 FPS 값은 캡처 실행 중의 값이며 GIF의 프레임 간격과는 별개다.

재현: 스모크 단계 `QUASARFALL=<초>~0.03`, `QUASARBEAM=<초>~0.03`. 첫 번째는 폭격 준비 시작, 두 번째는 빔 준비 1초 구간의 시작을 기준으로 한다. 예: `QUASARFALL=0.320`, `QUASARFALL=0.960`, `QUASARFALL=2.640`, `QUASARBEAM=1.600`.

검증: Windows x64 Release 빌드, `test_quasar_fall.ps1`, `test_quasar_beam.ps1`, `test_quasar_nova.ps1` 통과. 난사 검사는 곡선 휘어짐·경로의 속도 연속성·고정 착탄점·준비와 회복의 연결·프레임당 회전 속도 변화도 확인한다.
