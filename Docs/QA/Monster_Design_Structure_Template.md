# 몬스터 디자인 구조 양식

> 몬스터의 **디자인 요소만** 정리하는 간단한 양식이다.  
> 게임 수치, 공격 방식, 스폰 조건, C++ 구현 방법은 적지 않는다.

## 1. 기본 콘셉트

```text
몬스터 이름:
한 줄 콘셉트:
느낌 / 분위기:
연상되는 이미지:
```

### 레퍼런스 이미지 — 선택 사항

이미지가 없어도 작성할 수 있다. 이미지가 있다면 “무엇을 참고했는지”를 짧게 적는다.

```text
레퍼런스 이미지:
- [이미지 붙여넣기 또는 파일 링크]
- [이미지 붙여넣기 또는 파일 링크]

참고한 부분:
- 실루엣:
- 색 / 빛:
- 움직임:
```

## 2. 전체 실루엣

몬스터를 멀리서 봤을 때 어떤 모양으로 읽히는지 적는다.

```text
전체 형태: 원형 / 삼각형 / 사각형 / 길쭉한 형태 / 비대칭 / 기타
크기 느낌: 작음 / 보통 / 큼 / 매우 큼
실루엣 설명:
```

```text
       [전체 실루엣 스케치 삽입] | [ 이미지 ]
```

---

## 3. 이동 방식

게임 수치가 아니라, 화면에서 몬스터가 어떤 생명체처럼 움직이는지 적는다.

```text
기본 이동: 추적 / 부유 / 공전 / 지그재그 / 고정 / 순간이동 / 기타
이동 방향: 플레이어를 향함 / 플레이어 주변 / 일정한 방향 / 무작위
움직임의 느낌: 무거움 / 가벼움 / 불안정함 / 기계적임 / 유기적임
몸체 움직임: 회전 / 흔들림 / 늘어남 / 수축 / 분리 / 없음
노드 움직임: 몸체와 함께 / 각자 회전 / 뒤따라 움직임 / 깜빡임
잔상: 없음 / 희미한 선 / 점 조각 / 원형 파동 / 기타
```

```text
이동 모습 설명:
```

## 4. 디자인 파츠 구조

몬스터를 아래 다섯 가지 파츠로 나누어 작성한다.

```text
MonsterDesign {
    Core;           // 중심
    Node[];         // 별, 점, 모듈
    Link[];         // 노드 사이 연결선
    CircleTexture;  // 주변의 원형 시야/빛
    Effect[];       // 회전, 맥동, 잔상, 파편 등
}
```

### 4.1 Core — 중심

```text
Core {
    이름 [ CORE_MAIN ]
    모양: 원 / 마름모 / 빈 원 / 작은 별 / 기타
    크기: 전체 크기 대비 작음 / 보통 / 큼
    색상:
    중심의 의미: 생명 / 에너지 / 눈 / 포털 / 알 수 없음
    특징:
}
```

### 4.2 Node — 노드

노드는 몬스터의 외곽을 만드는 별이나 점이다. 각 노드에 고유한 이름을 붙인다.

```text
Node {
    이름:
    위치: 중심 기준 위 / 아래 / 왼쪽 / 오른쪽 / 대각선
    모양: 점 / 별 / 마름모 / 작은 원 / 기타
    크기:
    색상:
    역할: 장식 / 감각기관 / 무기처럼 보이는 부분 / 연결 지점
}
```

```text
노드 목록:
-
-
-
-
```

### 4.3 Link — 연결선

노드와 노드, 또는 코어와 노드를 연결하는 선이다.

```text
Link {
    연결:
    선의 느낌: 얇음 / 굵음 / 끊김 / 이중선 / 맥동
    색상:
    의미: 구조물 / 에너지 흐름 / 보호막 / 단순 장식
}
```

```text
연결 구조:
-
-
-
```

### 4.4 CircleTexture — 주변 원형 영역

몬스터 주변에 보이는 희미한 원형 빛 또는 시야 영역이다.

```text
CircleTexture {
    보이는가: 있음 / 없음
    크기: 본체보다 작음 / 비슷함 / 큼 / 매우 큼
    색상:
    밝기: 희미함 / 보통 / 강함
    느낌: 빛 / 그림자 / 파동 / 경고 영역 / 안개
    모양 변화: 고정 / 천천히 맥동 / 회전 / 공격 때 확장
}
```

### 4.5 Effect — 움직임과 강조

```text
Effect {
    이름:
    대상: Core / Node / Link / CircleTexture / 전체
    움직임: 회전 / 깜빡임 / 맥동 / 흔들림 / 분리 / 수축
    속도 느낌: 느림 / 보통 / 빠름
    언제 보이는가: 항상 / 특정 상태 / 피격 시 / 사라질 때
}
```

## 5. 색과 빛

```text
주 색상:
보조 색상:
강조 색상:
위험하거나 불안한 순간의 색:
전체 밝기: 어두움 / 중간 / 밝음
빛의 방향: 중심에서 바깥 / 바깥에서 중심 / 일정하지 않음
```

색상은 최대 3\~4개만 사용한다.

## 6. 상태별 디자인 변화

행동을 설계하는 것이 아니라, 상태에 따라 **보이는 모습이 어떻게 달라지는지**만 적는다.

```text
기본 상태:
- 평소에 가장 먼저 보이는 형태

강조 상태:
- 빛나거나 커지거나 움직임이 강해지는 부분

위험 상태:
- 색상, 노드, 연결선, CircleTexture의 변화

피격 상태:
- 깜빡임, 파편, 색상 변화 등

사라지는 상태:
- 수축 / 분해 / 폭발 / 어두워짐 / 중심만 남음
```

간단한 표로 작성해도 된다.

```text
| 상태 | Core | Node | Link | CircleTexture |
|---|---|---|---|---|
| 기본 |  |  |  |  |
| 강조 |  |  |  |  |
| 위험 |  |  |  |  |
| 피격 |  |  |  |  |
| 소멸 |  |  |  |  |
```

## 8. 디자인 확인용 체크리스트

- [ ] 레퍼런스 이미지는 선택 사항이며, 참고한 부분이 적혀 있다.
- [ ] 멀리서 봐도 전체 실루엣이 구분된다.
- [ ] 이동 방식과 움직임의 느낌이 글로 설명된다.
- [ ] 중심인 Core가 어디인지 알 수 있다.
- [ ] Node와 Link의 배치 이유가 있다.
- [ ] CircleTexture가 본체를 가리지 않는다.
- [ ] 주 색상이 3\~4개 안에 정리되어 있다.
- [ ] 기본·강조·위험·소멸 상태의 변화가 구분된다.
- [ ] 다른 몬스터와 한 가지 이상 확실히 다르다.
