# UI 텍스트·배치 정합성 계획

작성일: 2026-09-29

## 목표와 기준

모든 게임 UI 텍스트를 역할별로 점검하고, 모든 버튼을 한 줄 라벨로 통일한다. 새 요청 기준으로 버튼 라벨은 제목 40px이다. 버튼의 기존 보조 줄은 제거한다. 화면의 보조 구획 제목은 부제목 36px, 본문·설정명·값은 설명 20px, 짧은 안내는 보조 설명 18px로 둔다. 글자 크기가 달라져도 화면 배치, 호버·클릭 영역, 화면 전환이 텍스트와 어긋나지 않게 확인한다. 게임 흐름과 시각적 분위기는 유지한다.

기존 `UiTextLevel`, `UiTextScale`, `MaxLocalizedTextWidth`와 `Docs/QA/Onedow.xlsx`를 재사용한다. 별도 글자 체계, 텍스트 레지스트리, 검사 프레임워크는 만들지 않는다.

## A–Z 실행 순서

우선순위 표기: `Low` < `Medium` < `High` < `ExtraHigh` < `Critical`.

| 단계 | 우선순위 | 작업 |
|---|---|---|
| A | Critical | 기존 작업 변경을 보존하고 이번 텍스트 작업 범위를 고정한다. |
| B | Critical | 공통 렌더러와 직접 `Draw` 호출을 검색해 텍스트 출력 지점을 찾는다. |
| C | Critical | 출력 지점을 QA 시트의 화면별 항목과 대조한다. 별도 목록 파일은 만들지 않는다. |
| D | Critical | 모든 문구를 제목·부제목·설명·보조 설명으로 분류한다. |
| E | ExtraHigh | 공통 버튼에서 보조 줄을 그리는 경로를 제거한다. |
| F | ExtraHigh | 각 버튼의 주 라벨을 한 줄 제목 40px로 통일한다. |
| G | ExtraHigh | 기존 두 번째 줄을 제거하고, 꼭 필요한 상태 정보만 버튼 밖 보조 문구로 둔다. |
| H | ExtraHigh | 기존 크기 헬퍼로 역할 크기와 화면 배율을 적용한다. |
| I | High | 한국어·영어·일본어 최장 문구로 버튼과 텍스트 폭을 확인한다. |
| J | High | 첨부 화면부터 설정 제목·항목명·선택값·저장/뒤로 버튼을 정리한다. |
| K | High | 메인 메뉴와 좌측 하단 내비게이션 버튼을 정리한다. |
| L | High | 일시정지 메뉴와 확인 대화상자를 정리한다. |
| M | High | 시작·튜토리얼·런 설정 화면을 정리한다. |
| N | High | 상점과 구매 상태 문구를 정리한다. |
| O | High | 도감·기록·아카이브의 제목, 항목, 검색 안내를 정리한다. |
| P | ExtraHigh | 증강 선택·상세·보상 화면의 이름과 효과 문구를 정리한다. |
| Q | ExtraHigh | 전투 HUD의 점수·레벨·콤보·체력 경고·쿨다운·전투 안내를 정리한다. |
| R | High | 토스트·오류·상태·디버그·창 장식 텍스트를 정리한다. |
| S | High | 글자가 잘리거나 겹치면 필요한 컨테이너와 간격만 조정한다. |
| T | High | 글자 위치와 실제 클릭·호버·포커스 영역을 맞추고, 영역끼리 겹치거나 글자에서 벗어나지 않는지 확인한다. |
| U | High | 페이드·슬라이드·페이지 이동 중 텍스트와 버튼 배경/입력 영역이 함께 움직이는지 확인한다. |
| V | High | 과한 빈 공간과 불필요하게 넓어진 행·패널을 줄이면서 1280×720, 1920×1080, 2560×1440에서 여백을 확인한다. |
| W | High | 세 언어에서 글꼴 대체·누락·잘림을 확인하고, 긴 문구가 위치나 호버 영역을 어긋나게 하지 않는지 점검한다. |
| X | Critical | Windows x64 Release 빌드를 `build/windows/x64/Release`에 생성한다. |
| Y | High | 메뉴 이동, 설정 저장, 구매, 런 시작/종료, 증강 선택을 호버·클릭·전환 상태까지 확인한다. |
| Z | Critical | QA 시트와 완료 보고를 갱신하고, 검증이 끝난 항목만 초록색 `Clear`로 표시한다. |

## 첨부 화면에서 우선 확인할 부분

- `설정`과 `시스템 보정`의 크기 관계가 제목/부제목 단계와 맞지 않아 보인다.
- `FPS 제한` 같은 항목명과 선택값의 크기 차이가 커서 설명 20px 기준으로 다시 맞춘다.
- `뒤로` 버튼 아래의 `설정`, 저장 버튼 아래의 `변경 없음`은 버튼에서 제거한다. 저장 상태가 필요하면 버튼 밖에 18px 안내로 둔다.
- 글자와 항목 사이의 여백, 선택값과 버튼 위치, 호버 반응 영역이 서로 맞는지도 측정한다.

## 완료 조건

- 전역 UI 텍스트 출력 지점이 QA 시트와 대조되어 각 역할을 가진다.
- 버튼은 한 줄 제목 라벨만 표시하고 두 번째 줄이 없다.
- 보이는 버튼·텍스트와 클릭·호버·포커스 영역 및 전환 애니메이션의 기준 위치가 서로 맞는다.
- 글자 크기에 맞는 공간을 쓰며 과한 빈 영역이나 불필요하게 큰 컨테이너가 남지 않는다.
- 세 언어와 세 기준 해상도에서 겹침·잘림이 없다.
- 게임 흐름과 입력 동작이 유지되고, QA 시트의 완료/미해결 상태가 실제 확인 결과와 일치한다.

## 해석 기준

“부제목이 있던 텍스트를 제목으로 분류”는 기존 버튼의 주 라벨을 제목 40px로 올린다는 뜻으로 해석했다. 버튼의 이전 두 번째 줄 문구 자체를 새 라벨로 바꾸려는 뜻이라면 그 문구 선택만 구현 전에 확정한다. 설정 토글/선택값도 버튼 라벨로 보아 40px를 적용한다. 공간이 부족하면 해당 선택 영역을 조정하고, 임의로 설명 크기로 낮추지 않는다.

## 구현 진행 상황 (2026-09-29)

- **코드 반영:** 공통 패널 버튼에서 두 번째 텍스트 줄을 그리는 경로를 없애고, 버튼 라벨을 제목 역할로 한 줄 렌더링한다. 기존 `UiTextScale`과 최장 번역 폭 계산을 재사용했다.
- **화면 반영:** 메인 메뉴, 일시정지 메뉴, 시작/튜토리얼, 런 설정, 상점/도감, 증강 선택 및 상세 화면의 텍스트 크기·줄 간격·일부 버튼 히트 영역을 조정했다. 설정 씬은 카테고리명을 부제목 36px, 하위 설정 목록을 설명 20px, 상세 항목명과 일반 값을 제목 40px, 켜짐/꺼짐 토글 문구를 부제목 36px로 분류했다. 우측 패널의 카테고리 머리말과 설정명·값 묶음은 글꼴 높이를 측정해 상하 중앙 정렬하고 행 높이도 맞췄다. 메인 메뉴의 이전 `Start`/`Armory` 보조 라벨 데이터도 제거하고 실제 표시되는 언어별 한 줄 라벨로 폭을 계산한다. 증강 선택 중앙의 `CONSTELLATION FIELD` 보조 문구는 제거하고 제목을 원형 UI 위로 옮겼다.
- **빌드:** `scripts/build_windows.ps1` Release 빌드 성공. 산출물은 `build/windows/x64/Release/WiNILL.exe`이다. 빌드 로그에는 기존 `APIENTRY` 매크로 재정의 경고가 남아 있다.
- **QA 갱신:** 코드와 빌드로 해결을 확인할 수 있는 항목만 `Clear` 처리한다. 겹침 및 호버 동작의 실제 화면 확인이 필요한 항목은 구현 메모를 남기고 미완료로 유지한다.
- **아직 필요한 확인:** 실행 중인 게임의 화면 캡처/입력 검증은 이 작업에서 수행하지 않았다. 설정·전투 HUD를 포함한 각 씬을 한국어·영어·일본어와 1280×720, 1920×1080, 2560×1440에서 열어 잘림/겹침, 호버·클릭·포커스 영역, 화면 전환을 확인한 뒤에만 시각 QA를 완료 처리한다.

현재 A–H 및 X/Z는 공통 버튼/텍스트 구현, Release 빌드, QA 시트 갱신까지 완료했다. I–W의 씬별 수정은 반영했지만 전체 문구 대조와 다국어·해상도 검증이 남아 있으며, Y의 인게임 호버·클릭·전환 검증도 필요하다.
