# ROTOR 몬스터 디자인 기획서

## 1. 기본 콘셉트

```text
몬스터 이름: ROTOR
분류명: NORMAL / 성진
한 줄 콘셉트: 중앙의 작은 별을 품은 기본형 회전 별자리 추적체
느낌 / 분위기: 단순함, 기계적임, 지속적으로 접근하는 압박감
연상되는 이미지: 회전하는 프레임, 작은 위성, 기본 신호점
```

### 레퍼런스 이미지

```text
레퍼런스 이미지:

참고한 부분:
- 실루엣: 얇은 선으로 이루어진 별자리형 프레임
- 색 / 빛: 어두운 화면 위에 떠 있는 주황-적색 광원과 흰색 중심점
- 움직임: 단순한 구조가 일정한 속도로 회전하는 느낌
```

## 2. 전체 실루엣

```text
전체 형태: 사각형 프레임
크기 느낌: 작음 — 기본 적 중 가장 단순하고 가벼운 실루엣
실루엣 설명: 중앙 Core를 감싼 얇은 사각형과 네 꼭짓점의 작은 Node로 구성한다.
              두 번째 프레임, 삼각형, 별도 궤도는 사용하지 않는다.
```

```text
             NODE_TOP_LEFT ───── NODE_TOP_RIGHT
                    │                 │
                    │    CORE_MAIN    │
                    │                 │
          NODE_BOTTOM_LEFT ── NODE_BOTTOM_RIGHT
```

## 3. 이동 방식

```text
기본 이동: 추적
이동 방향: 플레이어를 향함
움직임의 느낌: 기계적이고 단순함
몸체 움직임: 사각 프레임 전체가 천천히 회전함
노드 움직임: 프레임의 네 꼭짓점에 고정된 채 함께 회전함
잔상: 없음
```

```text
이동 모습 설명:
플레이어를 향해 직선적으로 접근한다. 이동 중에도 사각형 프레임은 일정하게 회전하며,
중앙 Core는 프레임 안에 안정적으로 남아 있다. 복잡한 흔들림이나 궤도 변화 없이
단순하고 꾸준한 접근 자체가 로터의 움직임 특징이다.
```

## 4. 디자인 파츠 구조

```text
MonsterDesign {
    Core;                 // 중앙의 밝은 핵
    Node[4];              // 사각 프레임의 네 꼭짓점
    Link[4];              // 하나의 닫힌 사각형 프레임
    CircleTexture;        // 본체 주변의 희미한 식별 광원
    Effect[1];            // 전체 프레임의 느린 회전
}
```

### 4.1 Core — 중심

```text
Core {
    이름: CORE_MAIN
    모양: 겹쳐진 원형 광원과 작은 흰색 중심점
    크기: 사각 프레임 안에서 가장 눈에 띄는 중간 크기
    색상: 주황-적색 외곽광 + 흰색 중심점
    중심의 의미: 몬스터의 생명과 방향성을 나타내는 중심 별
    특징: 외곽 프레임보다 안정적으로 밝고, 구조의 시선을 중앙에 모은다.
}
```

### 4.2 Node — 노드

```text

    이름: NODE_TOP_LEFT

    크기: Core보다 작음
    색상: 주황-적색 광원 + 흰색 중심점
    역할: 사각 프레임의 꼭짓점
}

Node {

    크기: Core보다 작음
    색상: 주황-적색 광원 + 흰색 중심점
    역할: 사각 프레임의 꼭짓점
```

### 4.4 CircleTexture — 주변 원형 영역

```text
CircleTexture {
    보이는가: 있음
    크기: 본체보다 큼
    색상: 낮은 채도의 주황-적색
    밝기: 희미함
    느낌: 본체를 둘러싼 약한 식별 광원
    모양 변화: 기본 상태에서는 고정
    뒤쪽 보조 영역: 더 넓은 검은색 대비 영역
}
```

CircleTexture는 공격 범위를 표현하지 않는다. 어두운 배경에서 로터의 위치와 실루엣을
읽게 해주는 배경 광원으로 사용한다.

### 4.5 Effect — 움직임과 강조

```text
Effect {
    이름: FRAME_ROTATION
    대상: Link와 Node 전체
    움직임: 하나의 사각 프레임으로 천천히 회전
    속도 느낌: 느림 / 일정함
    언제 보이는가: 항상
}
```

```text
추가 효과:
- 복잡한 파동 없음
- 노드별 독립 회전 없음
- 긴 잔상 없음
- 두 번째 프레임 없음
- 삼각형 또는 별도 궤도 없음
```

## 5. 색과 빛

```text
주 색상: 오렌지-레드 (#FF4500)
보조 색상: 따뜻한 주황빛
강조 색상: 흰색 (#FFFFFF)
위험하거나 불안한 순간의 색: 기본 디자인에서는 별도 색상 변화 없음
전체 밝기: 중간 이하
빛의 방향: Core와 Node의 중심에서 바깥으로 퍼짐
```

색의 우선순위는 다음과 같다.

```text
흰색 중심점 > 주황-적색 Node/Core 광원 > 얇은 주황-적색 프레임 > 희미한 CircleTexture
```

## 6. 상태별 디자인 변화

```text
기본 상태:
- 주황-적색 사각 프레임과 네 개의 Node가 보인다.
- Core의 흰색 중심점이 항상 가장 명확하게 보인다.
- 프레임은 느리게 회전하고 CircleTexture는 낮은 밝기로 유지된다.

강조 상태:
- 별도 형태를 추가하지 않는다.
- Core의 밝은 중심점과 네 Node의 점 형태가 강조 역할을 한다.

위험 상태:
- 로터 전용 변형은 없다.
- 단순한 사각 프레임이 계속 보이는 것이 기본 읽힘이다.

피격 상태:
- 사각 프레임과 네 Node의 구조는 유지한다.
- 외부 피격 효과가 본체의 간결한 실루엣을 가리지 않도록 한다.

사라지는 상태:
- 별도의 복잡한 분해 연출은 사용하지 않는다.
- 공통 사망 효과가 적용되더라도 Core와 사각 프레임의 인상이 먼저 읽힌다.
```

```text
| 상태 | Core | Node | Link | CircleTexture |
|---|---|---|---|---|
| 기본 | 흰색 중심점 유지 | 네 꼭짓점 고정 | 닫힌 사각형 | 희미한 주황-적색 광원 |
| 강조 | 중심점이 가장 밝음 | 형태 유지 | 형태 유지 | 낮은 밝기 유지 |
| 위험 | 별도 변화 없음 | 형태 유지 | 형태 유지 | 별도 변화 없음 |
| 피격 | 구조 유지 | 구조 유지 | 구조 유지 | 본체 가독성 우선 |
| 소멸 | 공통 효과에 따라 사라짐 | 공통 효과에 따라 사라짐 | 공통 효과에 따라 사라짐 | 마지막까지 약한 대비 유지 |
```

## 7. 최종 한 장 정리

```text
몬스터 이름: ROTOR
분류명: NORMAL / Process / 성진

레퍼런스 이미지:
- CircleTexture.png
- LineTexture.png

이동 방식:
- 기본 이동: 추적
- 움직임의 느낌: 단순하고 기계적인 직선 접근
- 몸체 / 노드 움직임: 하나의 사각 프레임으로 함께 회전
- 잔상: 없음

한 줄 콘셉트: 중앙의 작은 별을 품은 기본형 회전 별자리 추적체

전체 실루엣: 중앙 Core + 네 꼭짓점 Node + 하나의 얇은 사각 프레임

Core:
- 모양: 겹쳐진 원형 광원과 흰색 중심점
- 색상: 주황-적색과 흰색
- 의미: 중심 별이자 몬스터의 시선 집중점

Node:
- 개수: 4개
- 배치: 사각형의 네 꼭짓점
- 모양: 작은 원형 별점

Link:
- 연결 방식: 네 Node를 순서대로 연결한 닫힌 사각형
- 선의 느낌: 얇고 선명하며 단순함

CircleTexture:
- 크기: 본체보다 큼
- 색상: 낮은 밝기의 주황-적색
- 밝기: 희미함
- 변화: 기본 상태에서 고정

Effect:
- 회전: 전체 프레임의 느린 회전
- 맥동: 없음
- 잔상 또는 파편: 없음

가장 강조할 부분: 흰색 중심점과 네 꼭짓점의 규칙적인 사각 구조
플레이어가 한눈에 기억해야 할 모습: 작은 주황색 사각 별자리 하나
```

## 8. 디자인 확인용 체크리스트

- [x] 주 색상이 주황-적색, 흰색 중심점으로 정리되어 있다.
- [x] 기본·강조·위험·소멸 상태의 변화가 구분되어 있다.
