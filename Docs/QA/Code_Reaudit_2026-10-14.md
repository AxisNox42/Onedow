## 권장 작업 순서

1. 신규 웨이브·PLAY 변경을 별도 동작 항목으로 잠근다. 난이도 전달, 무기 표시 수치 의미, 승리 결과 1회 확정의 기대값/테스트를 확정한다. REG-05 소스 검사도 갱신한다.
2. GL 종료 순서 결함을 작은 독립 수정으로 처리한다. Windows 종료 테스트와 현재 macOS CI 빌드를 확인한다.
3. D01의 미사용 `creative` 필드를 먼저 제거하고, REG-01을 기준으로 처치 보상 5경로를 한 소유자에 순차 이관한다. 투척 스웜·흡혈마·지연 드롭 정책은 그대로 둔다.
4. D02~04 스탯 기본 단계/런 초기화, D10 무기 표시, D22 도감, D26 설정을 각각 작은 변경으로 진행한다. 완료 영역의 신규 콘텐츠는 공통 경로만 확장한다.
5. 마지막에 자동 중복 후보와 전역 쓰기·API clamp/무시 계약을 다시 조사한다. 후보마다 통합 완료 또는 정책 차이 보존 사유를 적고 Windows 전체 테스트·macOS CI·입력/화면 수동 검증을 마친다.
