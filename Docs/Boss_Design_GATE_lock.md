# 보스 기획안 : GATE.lock

**픽 번호:** 4  
**보스 이름:** `GATE.lock`  
**내부 클래스명:** `GateLockBoss`  
**태그라인:** `Access control — compress, drift, isolate`  
**HP 배율:** 1.15× (BossDir::HpMul)  
**경고 색상:** `{ 0.20f, 0.80f, 0.45f }` (차가운 초록 — 시스템 게이트 느낌)

---

## 보스 아이덴티티

이 게임의 핵심 메커니즘인 **플레이어 창(playerWin) 자체를 공격**하는 보스.  
다른 보스들은 창 안을 공격하지만, GATE.lock은 창을 **쪼이고, 밀고, 가두는** 방식으로 전투한다.  
플레이어는 적을 피하면서 동시에 자기 창이 망가지지 않게 관리해야 하는 이중 압박 구조.

**시각 컨셉:** Win32 다이얼로그 박스. 외형은 거대한 "ACCESS DENIED" 경고창 스타일.  
중앙 코어는 빛나는 네온 사각형, 주위로 회전하는 직사각형 링 4~5개가 겹겹이 감싸고 있음.  
링은 레이어별로 색상이 다름 (초록 → 노랑 → 빨강 순, 페이즈 진행에 따라 색 변화).

---

## 페이즈 구조

| 페이즈 | HP 구간 | 핵심 기믹 |
|--------|---------|-----------|
| 1 — SCAN | 100% → 60% | 스캔 탄막 + 창 압축 |
| 2 — PUSH | 60% → 25% | 강제 창 드리프트 + 링 회전 탄막 |
| 3 — LOCK | 25% → 0% | 최소 창 감금 + 반사 총알 + 데미지 바닥 |

---

## Phase 1 — SCAN (창 압축)

### 보스 행동
- 맵 중앙에 고정된 채 이동하지 않음. 포탑처럼 코어가 회전하며 탄막 발사.
- **패턴 A — 격자 스캔라인:**  
  수평 또는 수직 방향으로 두꺼운 빔 라인(LineWall 활용)이 느리게 슬라이드함.  
  3~5개가 일정 간격으로 이어지며, 사이 공간이 "안전 통로" 역할.  
  방향은 수평 → 수직 → 대각 순으로 번갈아 가며 패턴이 점점 겹침.
- **패턴 B — 방사형 버스트:**  
  격자 스캔 사이 쿨다운에 8방향 버스트 총알 1회 발사. 리듬 끊기 역할.

### 창 압축 기믹
- 보스가 살아있는 동안 `g_Stats.windowSize`가 **초당 14px** 속도로 줄어듦.  
  (기본 창 크기 ~400px → 1분이면 -~180px, 즉 자연히 압박이 생기는 속도)
- 창 크기는 **280px** 아래로 내려가지 않음 (Phase 1 하한).
- **카운터 — 잠금 노드(Lock Node):**  
  보스가 주기적(15초마다)으로 플레이어 창의 **4개 모서리**에 소형 노드를 하나씩 소환.  
  노드는 창 모서리에 붙어 있는 작은 발광 사각형(20×20px).  
  총알로 격파 시: **창 압축 3초 중단 + 창 크기 +25px 회복**.  
  노드를 무시하고 방치하면 15초 후 소멸하며 오히려 **창 -40px 패널티**.

### 연출
- 창 테두리가 보스 경고 색(차가운 초록)으로 서서히 물들어 가며 압축 진행도를 시각화.
- 노드 소환 시 짧은 경고음 + 모서리 깜빡임.

## Phase 2 — PUSH (강제 창 드리프트)

**전환:** HP 60% 도달 → 0.5초 빈틈(플래시 이펙트) → Phase 2 진입.  
창 압축은 **리셋하지 않음** — Phase 1에서 이미 깎인 상태 그대로 유지.

### 보스 행동
- 보스가 이동을 시작함. 화면 절반 범위 내에서 천천히 목표 지점으로 이동 후 정지 반복.
- **패턴 A — 동심원 링 회전탄:**  
  보스 주변에 반지름 다른 2~3개의 원형 레이어가 생성되고, 각 레이어에서 서로 다른 속도로 탄환이 회전하며 외부로 발사됨.  
  레이어별 회전 방향이 반대라 탄막 사이 "틈"이 주기적으로 맞아 탈출구가 생김.
- **패턴 B — 타겟 레이저:**  
  3초에 한 번, 플레이어 위치를 예측해 0.4초 선딜 후 빠른 관통 레이저 1발 (기존 LaserBullet 시스템 활용).

### 창 드리프트 기믹
- 보스가 **드리프트 포스**를 플레이어 창에 가함:  
  `playerWin.x += driftVX * delta`, `playerWin.y += driftVY * delta`  
  - 드리프트 방향: 보스가 화면 특정 방향을 "당기는" 방향으로 (보스 위치 반대 방향의 화면 엣지 쪽).
  - 드리프트 속도: **초당 80~120px** (플레이어 이동속도보다 약간 느려서 버텨볼 수 있는 수준).
  - 5초마다 방향을 전환. 전환 직전 0.5초 동안 방향 예고 화살표 표시.
- **카운터:**  
  플레이어가 **드리프트 반대 방향**으로 이동하면 상쇄 가능.  
  보스에게 단기간 일정 대미지(버스트 딜) 누적 시 → 1.5초 드리프트 스턴.  
  드리프트에 저항 못 하고 창이 화면 끝에 닿으면 → **경계 충돌 대미지 (0.5초마다 피해)**.
- **슬로우존과 연계:**  
  Phase 2에서 일반 몬스터 대신 SlowZone을 주기적으로 창 이동 경로에 배치.  
  슬로우존을 밟으면 드리프트 저항 능력이 떨어짐 → 더 빠르게 밀려남.

### 연출
- 드리프트 활성 중 창 테두리 한쪽 면이 당겨지는 방향으로 "늘어나는" 글로우 이펙트.
- 방향 전환 예고 시 반대 방향 엣지에 화살표 아이콘.

## Phase 3 — LOCK (격리 감금)

**전환:** HP 25% 도달 → 0.8초 중단(전체 화면 플래시) → Phase 3 진입.  
전환 연출: 창이 빠르게 화면 중앙으로 텔레포트되며 최소 크기로 즉시 고정.

### 창 감금
- `g_Stats.windowSize`가 강제로 **220px**로 고정. 변경 불가.  
  (Phase 1~2에서 캐릭터가 창 크기 증가 증강을 들었어도 이 페이즈에선 무효.)
- 창 이동은 가능하지만 화면 **중앙 60% 영역 안**으로 제한 — 바깥으로 나갈 수 없음.

### 보스 행동
- 보스는 창 밖에 고정 위치(창에서 200px 거리 원형 궤도)에서 이동.
- **패턴 A — 반사 총알(Bouncing Bullet):**  
  보스가 창 내부를 향해 총알을 발사하며, 총알은 `playerWin` 테두리에 닿으면 반사(속도 벡터 flip).  
  최대 반사 횟수: 4회. 반사할수록 살짝 가속.  
  좁은 창 안에서 여러 각도로 튕겨 다니며 처리 불가 탄막 구성.
- **패턴 B — 집중 포화:**  
  20초에 한 번, 8방향 고밀도 버스트. 이 동안 반사 총알 잠시 중단 (숨 돌릴 타이밍).

### 데미지 바닥(Damage Floor)
- Phase 3 진입 후 창 바닥(내부 하단 10px)이 지속적으로 대미지 영역이 됨.  
  (SlowZone과 유사한 구현: 일정 영역 내 플레이어가 있으면 틱 피해)  
  플레이어는 작은 창 안에서 공중에 떠 있듯(가능한 높이 유지) 움직여야 함.
- 보스 HP가 10% 아래로 내려가면 데미지 바닥이 **벽 전체**로 확장 — 최종 압박.

### 카운터
- Phase 3에는 별도 카운터 기믹 없음 — 순수 DPS 레이스.  
  반사 총알 패턴의 "집중 포화" 빈틈을 활용해 딜을 몰아넣는 구조.

### 연출
- 창 테두리 전체가 빨간 글리치로 진동.
- 반사 총알이 벽에 닿을 때마다 충돌 스파크 이펙트.
- 보스 코어가 과부하 상태로 팽창 애니메이션 반복.

## 증강/행동 편향 (BossDir)

```cpp
inline bool ActBiasCompressor() { return g_ActBossPick == 4; }
```

- `ActBiasSplitter()`: false
- `ActBiasSpawner()`: false  
- `ActBiasRanged()`: true (격자/링 탄막 위주)

이 보스가 선택된 런에서는:
- 창 크기 회복 증강이 가중치 상승 (카운터 빌드 유도).
- 이동속도 증강이 가중치 상승 (드리프트 저항에 유효).
- 실드 계열 증강 가중치 하락 (Phase 3 데미지 바닥을 실드로 무력화하는 것 방지).

## 구현 우선순위

```
[P0 - 핵심]
- 창 압축: g_Stats.windowSize에 매 틱 -rate 적용 + 하한 클램프
- Lock Node: 창 모서리 미니타겟 스폰 + 총알 충돌 + 크기 회복
- 창 드리프트: playerWin.x/y에 외부 velocity 주입

[P1 - 전투]
- 격자 스캔라인: LineWall 활용 수평/수직 슬라이드
- 링 회전 탄막: 원형 레이어별 발사 각도 회전
- 반사 총알: Bullet에 bounceCount + 경계 flip 로직

[P2 - 연출]
- 창 테두리 컬러 글로우 (압축 진행도)
- 드리프트 방향 예고 화살표
- Phase 3 진입 텔레포트 + 플래시
```

## 디자인 의도 요약

GATE.lock은 **"창이 내 전장이자 적의 무기"** 라는 이 게임의 테마를 가장 직접적으로 표현하는 보스.

- P1: 창이 쪼여드는 압박 속 탄막 회피 → **공간 관리**
- P2: 창 자체가 밀려나는 혼란 속 딜 유지 → **저항과 집중**
- P3: 탈출구 없는 좁은 공간에서의 순수 생존 → **극한 컨트롤**

각 페이즈가 같은 "창 조작"이라는 컨셉을 다른 방식으로 변주하며,  
플레이어가 이 보스를 클리어했을 때 "창을 지켜냈다"는 성취감을 주는 게 목표.
