# Astral Enemy Blueprints v2.0

## 0. 이번 개편의 기준

v1에서 확립한 기하학적 실루엣 언어를 유지하면서, 지원형·굴절형·포식형 역할군을 추가한다.

새로 추가되는 적들은 세 가지 역할 레이어를 채운다.

1. **지원 레이어**: 단독으로는 위협이 작지만 주변 적에게 오라를 부여해 집단 전체를 강하게 만든다.
2. **굴절·흡수 레이어**: 플레이어의 총알 전략을 직접 방해한다.
3. **포식 레이어**: 전장의 다른 적을 흡수하며 스스로 성장한다.

외형 규칙은 v1의 NodeAnchor 시스템을 그대로 따른다. 새로운 파티클 시스템을 추가하지 않는다.

| 내부 ID      | 역할               | 표시 이름      | 티어  |
| ---------- | ---------------- | ---------- | --- |
| `REGULUS`  | 피해 경감 오라 지원형     | `REGULUS`  | 2.5 |
| `ALCOR`    | 속도 증폭 오라 지원형     | `ALCOR`    | 2   |
| `MAGNETAR` | 총알 굴절 방어형        | `MAGNETAR` | 3   |
| `UMBRA`    | 총알 흡수 폭발형        | `UMBRA`    | 3   |
| `COLLAPSE` | 적 포식 성장형 (블랙홀)   | `COLLAPSE` | 2→4 |

---

## 1. 공통 외형 규칙

v1의 공통 외형 규칙을 그대로 적용한다. v2에서 추가되는 항목만 아래에 명시한다.

### 1.1 오라 표현 규칙

지원형·굴절형 적은 영향 범위를 시각적으로 표현해야 한다. 오라는 아래 기준을 따른다.

- 오라 경계는 닫힌 면이 아니라 **희미한 점선 또는 얇은 링**으로만 표시한다.
- 오라가 활성화된 상태에서만 링이 보이고, 비활성 시 즉시 사라진다.
- 오라 범위 안에 있는 아군 적에게는 가느다란 연결선이 잠깐 나타날 수 있으나 항상 코어보다 얇아야 한다.
- 오라 링의 알파값은 코어보다 반드시 낮게 유지한다.

### 1.2 중첩 제한 시각 표현

같은 종류의 오라가 여러 개 겹쳐도 효과는 중첩되지 않는다.
이미 오라를 받고 있는 적에게는 연결선을 그리지 않는다.

### 1.3 성장형 적의 크기 단계

`COLLAPSE`는 흡수 횟수에 따라 크기가 단계적으로 커진다.
크기 변화는 부드러운 선형 보간을 사용하며, 순간이동처럼 보이지 않는다.

## 2. 적별 디자인

### 2.1 `REGULUS` — REGULUS (티어 2.5)

**주변 적의 피해를 경감시키는 육각형 방어 지원체.**

- 중앙에 차갑고 밝은 청백색 코어 1개를 둔다.
- 코어를 감싸는 정육각형 프레임 1개를 사용한다.
- 육각형 꼭짓점 6개에 `CircleTexture` 노드를 배치한다.
- 오라 활성 시 육각형 바깥에 희미한 육각형 링 1개가 천천히 펄스한다.
- 스스로는 공격하지 않는다. 플레이어 반대 방향으로 느리게 후퇴한다.
- 오라 범위 내 아군 적이 피해를 받을 때 해당 적 방향으로 연결선이 잠깐 나타났다 사라진다.

**오라 효과**
- 반경 180px 내 적이 받는 피해 35% 경감.
- 같은 적에게는 가장 가까운 REGULUS 하나의 효과만 적용. 두 번째 이후는 무시.

**읽힘**: 청백색 육각형 + 외곽 펄스 링 = 아군을 보호하는 후방 지원체.

금지 사항:
- 육각형과 삼각형, 사각형을 동시에 사용하지 않는다.
- 공격 연출을 추가하지 않는다.
- 오라 링을 코어보다 밝게 만들지 않는다.

---

### 2.2 `ALCOR` — ALCOR (티어 2)

**주변 적의 이동속도를 끌어올리는 이중 링 가속체.**

- 중앙에 따뜻한 주황빛 코어 1개를 둔다.
- 코어 주위에 크기가 다른 원형 링 2개를 서로 반대 방향으로 회전시킨다. 링은 닫힌 면이 아니라 얇은 선으로만 그린다.
- 각 링에 `CircleTexture` 노드를 2개씩 배치한다 (총 4개).
- 오라 활성 시 링의 회전 속도가 빨라지고, 바깥 링에 짧은 방향성 마커가 나타난다.
- 스스로도 빠르게 이동하며 플레이어 주변을 원형으로 배회한다.

**오라 효과**
- 반경 150px 내 적 이동속도 +45%.
- 여러 ALCOR의 효과는 중첩되지 않으며 가장 높은 값 하나만 적용.

**읽힘**: 주황 이중 링 + 반대 방향 회전 = 주변을 가속시키는 기동 지원체.

금지 사항:
- 링을 3개 이상 사용하지 않는다.
- 링이 서로 같은 방향으로 회전하지 않는다.
- 코어보다 큰 노드 후광을 사용하지 않는다.

---

### 2.3 `MAGNETAR` — MAGNETAR (티어 3)

**자기장으로 총알을 굴절시키는 방어형 적. 과부하 시 일시적으로 무력화된다.**

- 중앙에 짙은 보라-파랑 코어 1개를 둔다.
- 코어에서 바깥으로 뻗는 곡선 자기장 라인 4개를 사용한다. 직선이 아니라 완만하게 구부러진 형태로 그린다.
- 라인 끝 또는 중간에 `CircleTexture` 노드를 배치한다.
- 오라 활성 시 자기장 라인이 천천히 흔들린다.
- **과부하 진입 시**: 라인이 직선으로 펴지고 주황빛으로 변하며 짧게 점멸한다.
- **과부하 중**: 라인과 오라가 모두 사라지고 코어만 희미하게 깜박인다. 이 상태에서 받는 피해 +60%.
- **재충전 완료 시**: 라인이 다시 구부러지며 원래 색으로 복귀한다.

**굴절 메카닉**
- `deflectHP = 18.0f`
- 총알이 오라에 접촉할 때마다 `deflectHP -= 총알 데미지`
- `deflectHP ≤ 0` → 과부하, 2.5초 비활성화 후 자동 재충전
- 여러 MAGNETAR의 오라가 겹쳐도 굴절 강도는 동일 (중복 처리 없음)

**읽힘**: 보라 코어 + 구부러진 자기장 라인 = 총알 경로를 방해하는 방어형.

금지 사항:
- 자기장 라인을 직선으로 그리지 않는다 (과부하 상태 제외).
- 라인을 5개 이상 사용하지 않는다.
- 과부하 상태를 색 변화 없이 표현하지 않는다.

---

### 2.4 `UMBRA` — UMBRA (티어 3)

**총알을 빨아들이다가 한도를 넘으면 폭발하는 흡수체.**

- 중앙 코어는 거의 검은색에 가까우며, 외곽만 희미하게 빛난다.
- 코어 주위에 안쪽으로 나선형으로 감기는 짧은 호 3개를 사용한다.
- 호의 끝부분에 `CircleTexture` 노드를 배치한다.
- 오라 활성 시 호들이 천천히 안쪽으로 회전한다. 총알을 흡수할 때마다 회전이 한 번 빨라졌다 돌아온다.
- **과부하 직전**: 코어가 붉게 팽창하기 시작하고 호들이 흔들린다.
- **폭발**: 흡수한 총알 수에 비례한 반경으로 폭발. 플레이어 피해 포함.
- **재충전 중**: 코어가 매우 작아지며 호들이 잠시 사라진다.

**흡수 메카닉**
- `absorbLimit = 20발` (총알 관통력·크기에 따라 가중치 다름)
- 한도 초과 시 즉시 폭발 후 3초 재충전
- 폭발 반경: 흡수된 총알 수 × 5px (최대 200px)

**읽힘**: 어두운 코어 + 안쪽으로 도는 나선 호 = 흡수 후 폭발하는 위험 지점.

금지 사항:
- 코어를 밝게 만들지 않는다 (과부하 직전 팽창 제외).
- 나선 호를 4개 이상 사용하지 않는다.
- 폭발 반경을 항상 최대로 고정하지 않는다.

---

### 2.5 `COLLAPSE` — COLLAPSE (티어 2→4)

**주변의 낮은 티어 적을 흡수하며 크기와 위협이 성장하는 포식형 블랙홀.**

처음 등장 시에는 작고 조용하지만, 전장에 오래 방치할수록 제거하기 어려워진다.

#### 외형 구조

- 중앙 코어는 완전한 검정. 빛을 내지 않고 배경을 가린다.
- 코어 바깥에 밝은 강착 링(accretion ring) 1개만 사용한다. 이 링이 COLLAPSE의 유일한 식별 요소다.
- 강착 링은 항상 코어보다 얇고, 한쪽이 조금 더 밝다 (회전하는 빛 효과).
- `CircleTexture` 노드는 강착 링 위에 2~3개 배치한다.

#### 크기 단계

| 흡수 횟수 | 단계   | 코어 반경 | 강착 링 반경 | 흡수 반경 |
| ----- | ---- | ----- | ------- | ----- |
| 0     | 1단계  | 14px  | 22px    | 80px  |
| 3     | 2단계  | 20px  | 32px    | 120px |
| 6     | 3단계  | 28px  | 44px    | 160px |
| 10    | 4단계 (최대) | 38px  | 58px    | 200px |

단계 사이의 크기 변화는 0.8초 선형 보간으로 처리한다.

#### 포식 메카닉

- 흡수 반경 내에 자신보다 낮은 티어의 적이 들어오면 천천히 당겨진다.
- 당겨지는 적은 이동 속도의 일부가 COLLAPSE 방향으로 치환된다.
- 흡수 완료 시 (거리 < 10px): 해당 적 즉시 제거, 흡수 횟수 +1, **XP 지급 없음**.
- 4단계 도달 후에는 흡수가 멈추고 최대 크기를 유지한다.
- COLLAPSE 자신은 이동하지 않는다. 위치가 고정된 위험 구역으로 설계한다.

#### 전략적 의도

플레이어는 두 가지 선택을 강요받는다.

1. 주변 잡몹을 먼저 처치해 COLLAPSE의 먹이를 차단한다.
2. COLLAPSE를 우선 제거해 성장 자체를 막는다.

흡수된 적은 XP를 주지 않으므로 방치는 단기적으로는 전장이 정리되는 것처럼 보이지만, 장기적으로 더 강한 COLLAPSE와 XP 손실이라는 이중 손해를 낳는다.

**읽힘**: 검은 코어 + 밝은 강착 링 + 주변 적이 빨려들어감 = 방치 불가 포식형 위협.

금지 사항:
- 코어를 밝게 만들지 않는다.
- 강착 링을 2개 이상 사용하지 않는다.
- 이동 능력을 부여하지 않는다.
- 최대 단계 이후에도 계속 성장하도록 만들지 않는다.
- 플레이어를 직접 흡수하지 않는다.

## 5. 구현 체크리스트

### 공통

- [ ] 오라 링의 알파값이 코어보다 낮다.
- [ ] 오라 비활성 시 링이 즉시 사라진다.
- [ ] 모든 노드가 동일한 `NodeAnchor`를 참조한다.
- [ ] 크기 변화는 선형 보간으로 처리한다.

### 적별

- [ ] `REGULUS`: 정육각형 프레임 1개 + 오라 활성 시 외곽 펄스 링 1개
- [ ] `ALCOR`: 반대 방향 이중 링 + 오라 활성 시 회전 가속 + 방향성 마커
- [ ] `MAGNETAR`: 구부러진 자기장 라인 4개 + 과부하 3단계 (정상→과부하→재충전)
- [ ] `UMBRA`: 나선 호 3개 + 흡수 카운터 + 폭발 반경 흡수량 비례 처리
- [ ] `COLLAPSE`: 단계별 크기 테이블 + 흡수 반경 + 흡수 시 XP 지급 없음 + 4단계 이후 성장 정지

### 금지 사항

- [ ] 지원형 적에게 직접 공격 능력을 추가하지 않는다.
- [ ] 오라 효과를 무한 중첩하지 않는다.
- [ ] `COLLAPSE`에 이동 능력을 부여하지 않는다.
- [ ] `COLLAPSE`가 플레이어를 직접 흡수하도록 만들지 않는다.
- [ ] `MAGNETAR` 과부하 상태를 색 변화 없이 처리하지 않는다.
- [ ] `UMBRA` 폭발 반경을 고정값으로 처리하지 않는다.

최종 기준은 다음과 같다.

> **REGULUS는 청백 육각형, ALCOR는 주황 이중 링, MAGNETAR는 구부러진 보라 라인, UMBRA는 어두운 나선 호, COLLAPSE는 검은 코어 + 밝은 강착 링으로 즉시 구분되는가?**
