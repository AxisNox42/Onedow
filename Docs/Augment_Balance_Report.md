- 대포 관련 증강 `CANNON`, `HE_SHELLS`, `HE_SHELLS_2`, `CB_TURRET`는 선택 풀/조합 결과에서 제외했다.

디버프 선행 조건/전체 디버프 재밸런스는 이후 작업으로 남겨둔다.

아래 점검 본문은 적용 전 코드 기준의 분석 기록이다. 현재 적용 상태는 위 적용 내역을 기준으로 본다.

## 총평

현재 증강 구조는 방향 자체는 좋다. 일반 증강은 고정 가산으로 초반 안정성을 주고, 희귀/에픽부터 플레이 방식이 바뀌며, 전설/신화/조합에서 빌드 완성감을 주는 구조다.

다만 실제 코드를 보면 밸런스 문제는 단순히 "어느 카드가 세다"보다 아래 4가지에서 더 크게 나온다.

1. 설명과 실제 효과가 다른 카드가 꽤 있다.
2. 시작 무기와 증강 보유 판정이 분리되어 일부 조합 루트가 막히거나 어색해진다.
3. 일부 증강은 초반 보정이나 보유 증강 수 스케일링 때문에 장기적으로 과성장한다.
4. 일부 전투 발동 로직은 특정 보스에게 적용되지 않아 빌드 가치가 보스마다 과하게 갈린다.

## P0: 버그성 또는 설명 불일치

### 1. 시작 무기와 조합 레시피 판정 불일치

현재 조합 레시피는 `g_TypeOwned`를 기준으로 판단한다. 문제는 시작 무기는 `g_Stats`에는 반영되지만 `g_TypeOwned`에는 반영되지 않는다는 점이다.

가장 큰 영향은 `Sniper`다.

- 시작 무기 `Sniper`는 이제 `g_Stats.sniper = true`가 된다.
- 그런데 `CB_RAILGUN` 조합은 `{ SNIPER, PIERCE, PIERCE_2 }` 보유를 요구한다.
- `SNIPER` 카드는 이미 저격 상태면 추첨에서 제외된다.
- 결과적으로 시작 `Sniper`가 가장 자연스럽게 가야 할 `Railgun` 조합을 오히려 못 탈 수 있다.

추천:

- 시작 무기 선택 시 해당 무기형 `g_TypeOwned`를 같이 켜거나,
- 조합 레시피 판정에서 무기형 재료는 `g_Stats.sniper`, `g_Stats.cannon` 같은 실제 상태도 인정한다.

`Railgun`은 저격 빌드의 최종 보상 느낌이 강하므로, 시작 저격총이 막히는 건 우선 수정하는 게 맞다.

### 2. Light Step 피격 후 이동속도

`Light Step`은 적용 시 `moveSpeedMult *= 1.30f`다. 그런데 피격 후 비활성 상태에서는 `GetMoveMultiplier()`에서 `m /= 1.50f`를 한다.

결과:

- 정상: `1.30x`
- 피격 후: `1.30 / 1.50 = 0.866x`

설명은 "피격 시 10초간 효과 정지"인데, 실제론 기본 이동속도보다 느려지는 페널티가 된다.

추천:

- `m /= 1.30f`로 바꿔서 정확히 기본값으로 돌아가게 한다.
- 또는 의도적으로 피격 페널티를 주려면 카드 설명을 "피격 시 10초간 감속"으로 바꾼다.

이건 밸런스 이전에 설명/동작 불일치라 바로 고치는 쪽이 좋다.

### 3. Drone Hive 설명과 실제 효과

`Drone Hive` 설명은 "드론 최대치 + 초고속 사격"인데 실제 적용은 `droneCount = 2`, `droneRapid = true`다. 현재 `MAX_DRONES`는 4라서 "최대치"가 아니다.

또한 `Drone II`도 이미 2기라서, `Drone Hive`의 실질 차이는 "2기 초고속 사격"에 가깝다.

추천:

- 밸런스를 우선하면 설명을 `드론 2기 고정 + 초고속 사격`으로 고친다.
- 판타지를 우선하면 `droneCount = 3` 정도로 올리고, rapid 드론 탄환 피해를 낮춘다.
- `droneCount = 4`와 초고속 사격을 동시에 주는 건 DPS가 너무 크게 뛸 가능성이 높다.

### 4. Bullet Rain Eternal 설명과 실제 쿨다운

`Bullet Rain III`는 쿨다운을 5초로 만든다. `Bullet Rain Eternal`은 코드상 `bulletRainCooldown > 8.0f`일 때만 8초로 낮춘다. 즉 III 이후에는 5초가 유지되고, 처치 가속으로 사실상 최소 3초 근처까지 내려갈 수 있다.

설명은 "쿨다운 8초로 단축"이라 실제보다 약해 보인다.

추천:

- 현재 성능을 유지한다면 설명을 `III 쿨다운 유지 · 처치마다 쿨다운 감소 · 최소 3초`로 바꾼다.
- 정말 8초 신화로 설계할 거면 코드가 `5초 -> 8초`가 되므로 너프가 아니라 이상한 후퇴가 된다. 이쪽은 추천하지 않는다.

현재 구조는 "III를 더 자주 굴리는 신화"라 이해하는 게 맞다.

### 5. Warlord / Soul Harvest 설명 불일치

`Soul Harvest` 설명은 100킬마다 성장이라고 되어 있고, `Warlord` 설명은 1000킬마다 최대 10스택이라고 되어 있다. 하지만 실제 `GetDamageMultiplier()`, `GetFireIntervalMult()`, `GetBulletSpeedBonus()`는 `killCount / 1500`, 최대 7스택을 사용한다.

현재 `Soul Harvest` 자체는 제거 목록에 있고, `Warlord`가 이 기능을 켠다. 따라서 실제 플레이 기준으로는 `Warlord` 설명이 더 중요하다.

추천:

- 코드 기준 유지: `1500킬마다 공격력 +5% · 연사/탄속 +2% · 최대 7스택`으로 설명 수정.
- 판타지 기준 강화: `1000킬마다`, 최대 7스택 정도로 코드 수정.

개인적으로는 후반 무한 모드까지 생각하면 1500킬/7스택 유지가 더 안전하다.

### 6. D_MOB_HP 설명과 실제 효과

카드 설명은 잡몹 체력 `+20%`인데, 실제 코드는 `monsterHpMult *= 1.45f`다. 즉 `+45%`다.

추천:

- 현재 난이도를 유지할 거면 설명을 `+45%`로 수정한다.
- 설명대로 약한 디버프를 원하면 코드를 `1.20f`로 되돌린다.

보상은 처치 EXP `+2`라서, 현재 `+45%`는 보상 대비 꽤 빡센 편이다.

### 7. Ether Sword 보스 대상 누락

일반 총알 충돌은 `Ether Sword`를 처리하지만, 일부 증강/스킬형 공격은 보스 히트 처리에서 `ReloadRunner`, `Centipede`, `Tesseract`만 처리하고 `Ether Sword`를 누락한다.

확인된 후보:

- `Scan Laser` / `Laser Convergence`
- `Close Window`
- `Purge Nova`는 현재 제거 목록이지만 코드상 잔존

추천:

- 증강/스킬 공격이 보스에게 통일되게 들어가야 한다면 `Ether Sword`도 같은 보스 히트 루트에 추가한다.
- `Ether Sword`만 특수하게 막을 의도라면 카드 설명 또는 보스 특성에 "일부 자동/스킬 피해 저항"을 명확히 둔다.

현재 상태는 플레이어 입장에서 버그처럼 느껴질 가능성이 높다.

### 8. 디버프 강화 카드의 선행 조건 누락

일반 증강 추첨 `RollOneAug()`에는 `D_SPLITTER_BOOST` 선행 조건이 있지만, 디버프 전용 추첨 `RollOneDebuff()`에는 선행 조건 검사가 거의 없다.

문제 예시:

- `D_TROJAN_BOOST`는 설명상 트로이목마 침투 보유 시 강화인데, 단독으로 나올 수 있다.
- 단독으로 나오면 `trojanBoost = true`만 켜지고, 실제 트로이목마가 없으면 체감 효과가 거의 없다.
- `D_SPLITTER_BOOST`도 디버프 선택에서 선행 없이 나올 수 있는지 확인이 필요하다.

추천:

- `RollOneDebuff()`에도 디버프 강화 카드 선행 조건을 넣는다.
- 또는 강화 디버프를 단독으로 뽑으면 기본 출현 디버프까지 같이 켜는 구조로 통일한다.

## P1: 과성장 또는 과안정 증강

### 1. Miniaturize

`Miniaturize`는 최대 체력 절반이라는 리스크가 있지만, 실제 성장식이 매우 강하다.

- `GetBaseDamage()`: 보유 증강당 공격력 `+10`
- `GetFireIntervalMult()`: 보유 증강당 연사 `+2%`
- `totalAugs`는 버프/디버프/랜덤 지급 증강까지 계속 증가

대략적인 위험도:

| 보유 증강 수 | 기본 피해량 변화 | 연사 보정 | 체감 |
|---:|---:|---:|---|
| 5개 | 50 -> 100 | 약 +10% | 이미 강함 |
| 10개 | 50 -> 150 | 약 +20% | 빌드 핵심급 |
| 15개 | 50 -> 200 | 약 +30% | 대부분의 공격 증강보다 강함 |
| 20개 | 50 -> 250 | 약 +40% | 후반 과성장 가능성 큼 |

추천:

- 공격력 `+10/증강`을 `+6/증강` 정도로 낮춘다.
- 또는 `+10`은 유지하되 최대 10~12스택까지만 적용한다.
- 연사 `+2%/증강`도 최대 `+25%` 정도로 캡을 두는 편이 안전하다.

`Miniaturize`는 "작고 빠른 고위험 딜러"라는 정체성은 좋지만, 지금은 장기전에서 모든 공격형 증강을 압도할 수 있다.

### 2. 첫 3개 일반 증강의 숨은 공격력 보정

일반 증강을 먹으면 처음 3회까지 `damageMultiplier *= 1.08`이 추가로 들어간다. 그래서 `Vision Up`, `Move Up`, `Regen` 같은 비공격 일반 증강도 실제론 숨은 공격력 증가를 준다.

예시:

- `DMG_UP` 첫 픽: 공격력 `+9`에 `x1.08`까지 붙어 실질 화력 상승폭이 크다.
- 일반 증강 3개를 먹으면 카드 종류와 무관하게 공격 배율이 `x1.26`까지 오른다.

이건 초반 안정화 장치로는 이해되지만, 카드 설명에는 없어서 플레이어가 빌드를 계산하기 어렵다.

추천:

- 유지할 거면 카드 선택 UI나 보고서/도감에 "초기 일반 증강 보정"을 표시한다.
- 숨은 보정이 부담이면 `x1.08`을 `x1.04~1.05`로 낮춘다.
- 더 깔끔하게는 `DMG_UP`, `RATE_UP`, `SPD_UP` 같은 공격 관련 일반 증강에만 보정을 준다.

### 3. Laser Convergence

레이저는 기본부터 관통 직선 정리 능력이 있고, 신화 `Convergence`는 발사 간격이 `0.18초`, 빔 폭이 2배다. 피해는 `기본 공격력 x1.4`라서 단일 보스 상대로도 안정적인 지속 DPS가 나온다.

문제는 이 화력이 조준만 맞추면 거의 리스크 없이 들어간다는 점이다.

추천:

- 신화니까 강해도 되지만, 보스 DPS가 너무 높으면 `tier3`에서만 피해 배율을 `1.4 -> 1.1~1.2`로 낮춘다.
- 또는 발사 간격을 `0.18 -> 0.24`로 늘린다.
- 대신 시각적 만족감은 유지해야 하므로 폭/연출은 건드리지 않는 쪽이 좋다.

### 4. Drone Hive

`Drone Hive`는 2기 기준으로도 초고속 사격 때문에 실전 DPS가 크게 오른다. 현재 드론 탄환은 속도만 50%고, 피해는 일반 탄환 계산을 그대로 탄다.

추천:

- rapid 상태의 드론 탄환에 `dmgMult 0.60~0.70`을 주면 안정적이다.
- 또는 2기 rapid를 유지하고 설명을 정확히 고친다.
- `MAX_DRONES=4`까지 올릴 경우, rapid와 동시에 주면 화력이 너무 많이 뛸 수 있으므로 반드시 탄환 피해 보정이 필요하다.

### 5. Chain II

`Chain`은 모든 탄환이 2회 튕기는 대신 총알 공격력 `-30%`다. 실제론 첫 타 포함 최대 3회 히트가 가능하므로 몹 밀도만 충분하면 총합 기대값은 꽤 높다.

`Chain II`는 튕김 3회, 총알 피해 `-20%`라서 최대 4회 히트 기준 총합 기대값이 더 크게 오른다.

판정:

- 보스 단일 DPS는 거의 늘지 않는다.
- 잡몹 정리력은 매우 크게 오른다.
- `Minigun`, `Twin`, `SMG`처럼 탄 수가 많은 빌드와 결합하면 화면 정리력이 급격히 올라간다.

추천:

- 당장 너프보다는 후반 잡몹 밀도 테스트 우선.
- 문제가 되면 `Chain II`를 `3회 / 피해 -30%`로 두거나, 리코셰 탄환에는 `Minigun Cyclone` 히트 가속이 덜 적용되게 한다.

## P2: 약하거나 애매한 증강

### 1. Light Ammo

`Light Ammo`는 연사 +10%, 탄속 +30%, 공격력 -20%다. 순수 DPS는 오히려 약 `-12%`이고, 탄속 보정이 실전 명중률을 올려주는 구조다.

판정:

- 느린 탄속 무기에는 체감이 있을 수 있다.
- Rifle/Revolver처럼 이미 안정적인 무기에는 선택 매력이 낮다.
- Sniper는 탄속이 이미 빠르고 한 발 가치가 중요해서 손해가 더 커질 수 있다.

추천:

- 공격력 패널티를 `-20% -> -15%`로 낮추거나,
- 탄속 외에 `탄 퍼짐 -10%` 같은 안정성 보너스를 붙인다.

### 2. Lifesteal 계열

`Lifesteal`은 처치당 HP `+0.06`, 최대 4중첩이다. `Vampire`, `Lifesteal II`, `Bloodlord`까지 가면 생존 안정성은 생기지만, 보스전에서는 잡몹 처치 빈도에 크게 의존한다.

판정:

- 무한 모드 잡몹전에서는 안정적이다.
- 보스전 단독 성능은 약하다.
- `Glass Cannon`의 리스크를 완화하는 용도로는 좋다.

추천:

- 보스전에서도 너무 죽는 느낌이면, 보스에게 일정 피해 누적 시 미량 회복 같은 별도 루프를 고려할 수 있다.
- 지금 당장은 큰 수정 필요성은 낮다.

### 3. Gigantify / Bastion

`Gigantify`는 체력 2배, 재생 강화, 이동속도 -40%, 크기 +50%다. `Bastion`까지 가면 더 튼튼해진다.

판정:

- 현재 보스들이 큰 히트박스를 강하게 처벌하면 리스크가 산다.
- 반대로 탄막 밀도가 낮은 보스전에서는 그냥 안정적인 탱커가 될 수 있다.

추천:

- 수치보다 보스 패턴과 함께 봐야 한다.
- 무한 모드에서는 괜찮지만, 메인 보스전에서 지나치게 안정적이면 `Gigantify`의 이동속도 패널티를 유지하고 회복량만 소폭 낮추는 쪽이 낫다.

## 대포 관련 잔존 이슈

대포는 삭제했다고 했지만 코드에는 아직 `CANNON`, `HE_SHELLS`, `HE_SHELLS_2`, `CB_TURRET`가 남아 있다.

특히 `HE_SHELLS`는 현재 충돌 코드 기준으로 발동 조건이 애매하다. `remainingDmg > 0.001f`면 관통으로 계속 살아남고, 관통이 끝나 비활성화될 때는 `remainingDmg`가 거의 남지 않기 때문에 폭발 조건이 사실상 잘 안 맞을 가능성이 있다.

추천:

- 대포 완전 삭제 방향이면 `CANNON`, `HE_SHELLS`, `HE_SHELLS_2`, `CB_TURRET`를 카드 풀/레시피/도감에서 정리한다.
- 대포를 부활시킬 계획이면 `HE_SHELLS`는 "관통 종료 시"가 아니라 "탄환 소멸 시 마지막 위치 폭발"로 명확히 다시 짜야 한다.

## 디버프 밸런스

디버프는 전반적으로 "경험치 보상"이 붙어 있어서 구조는 좋다. 하지만 보상 대비 체감 난이도가 고르지 않다.

위험도가 높은 디버프:

- `D_APPROACH`: 무적 추격 오브라 장기적으로 피로도가 매우 큼. EXP/sec 보상은 좋지만 여러 번 뜨면 스트레스가 높다.
- `D_MOB_HP`: 실제 +45%라 설명보다 훨씬 무겁다.
- `D_BULLET_STUCK`: 연사 -20%는 대부분의 무기에 직접적인 DPS 손실이라 체감이 큼.
- `D_BLEED`: 재생 빌드가 아니면 지속 압박이 크고, 보스전 대기 시간에도 부담이 된다.
- `D_TROJAN_BOOST`: 선행 없이 뜨면 무효 카드처럼 느껴질 수 있다.

상대적으로 약한 디버프:

- `D_GLASS_HEART`: 최대 체력 -20%에 EXP +5%라 고수에게는 거의 공짜일 수 있다.
- `D_SLOW_MOVE`: 이동 -5%에 전체 EXP +10%는 보상 쪽이 더 좋아 보인다.
- 일부 적 강화형 디버프는 해당 적이 충분히 나오지 않으면 체감이 낮다.

추천:

- 디버프는 "무조건 손해"보다 "플레이 스타일을 바꾸는 부담"이 좋다.
- 수치형 디버프보다 적 패턴 추가형 디버프가 게임 정체성에 더 잘 맞는다.
- 선행형 강화 디버프는 반드시 선행 조건을 체크하거나, 단독 획득 시 기본 적 출현까지 같이 켜야 한다.

## 추천 작업 순서

1. `Light Step` 비활성 이동속도 버그 수정.
2. 시작 무기와 조합 레시피 판정 통일. 특히 `Sniper -> Railgun`.
3. 설명 불일치 수정: `Drone Hive`, `Bullet Rain Eternal`, `Warlord`, `D_MOB_HP`, `Firewall`.
4. `Ether Sword`에 레이저/스킬형 보스 피해 적용 여부 통일.
5. `Miniaturize` 성장식 캡 또는 수치 하향.
6. 첫 3개 일반 증강 숨은 `x1.08` 보정 유지 여부 결정.
7. 대포 완전 삭제 여부에 맞춰 `CANNON/HE/Turret` 데이터 정리.
8. 신화 증강 6종을 무한 모드 기준으로 실전 테스트.

## 실전 테스트 추천 세트

수치만 보면 놓치는 게 많아서 아래 빌드로 실제 플레이 테스트를 권장한다.

| 테스트 빌드 | 확인할 것 |
|---|---|
| Rifle + `Rifle Stability` | 기준 무기 대비 너무 정답인지 |
| SMG + `SMG Compressor` + `Minigun` | 중거리 손해가 해결되는지, 탄 수가 과한지 |
| Shotgun + `Shotgun Spread` | 근접 전탄 명중이 보스전을 부수는지 |
| Sniper + `Sniper Amplifier` + `Railgun` | 시작 Sniper도 조합이 가능한지, 원거리 DPS가 과한지 |
| Bow + `Power Draw` + `Multishot` | 보조 화살 58%가 적당한지 |
| Miniaturize 10/15/20증강 | 후반 과성장 여부 |
| Drone II + `Hive Mind` | 2기 rapid가 신화답지만 과하지 않은지 |
| Laser II + `Convergence` | 보스 DPS와 잡몹 정리력이 동시에 과한지 |
| Gigantify + MK2 + Firewall + Bastion | 탱커 빌드가 보스전을 무력화하는지 |
| Debuff 다수 누적 | 경험치 보상과 피로도 균형 |

## 결론

당장 큰 방향은 나쁘지 않다. 오히려 증강 종류가 많아서 빌드 다양성은 충분하다. 지금 제일 먼저 잡아야 할 건 신규 콘텐츠 추가가 아니라, 설명/실제 효과 불일치와 조합 판정 문제다.

밸런스 수치만 보면 `Miniaturize`, `Drone Hive`, `Laser Convergence`, `Endless Rain`이 고점 후보이고, 시스템 문제로는 `Light Step`, `Sniper -> Railgun`, `Ether Sword` 보스 피해 누락이 우선순위가 높다.
