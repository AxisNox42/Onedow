# 최종 보스 기획안 v2: ETHER_SWORD_MASTER.sys

**내부 클래스명:** `EtherSwordBoss`  
**보스 픽 번호:** `20`  
**역할:** 메인 모드 최종 보스  
**태그라인:** `Task terminated - no survivors expected`  
**핵심 감각:** 좁은 공간에서 검의 예고선을 읽고, 한 끗 차이로 피한 뒤 짧은 딜 타임을 가져가는 보스

---

## 1. 방향성

ETHER_SWORD는 화려한 콤보 보스가 아니라 **대시 검격 보스**가 중심이다. 다만 돌진만 있으면 좌우 와리가리나 시계방향 무빙으로 파훼되므로, 기본 공격은 반드시 필요하다.

플레이어가 느껴야 하는 구조:

- 기본 검기와 넓은 견제기로 이동 습관을 흔든다.
- 보스가 차징하고 돌진 경로를 명확히 보여준다.
- 플레이어가 아슬아슬하게 피한다.
- 검이 박히고 보스가 멈춘다.
- 짧은 극딜 타임을 얻는다.

패턴은 강해야 하지만, “어디서 맞았는지 모르겠다”가 나오면 실패다.

---

## 2. 기본 스펙

| 항목 | 값 |
|------|----|
| 기본 HP | `18,000 * BossDir::HpMul(20) * actRules.hpIntensityCap` |
| HpMul | `3.20f` |
| HIT_RADIUS | `60px` |
| 접촉 피해 | `12 HP/s` |
| P2 전환 | HP 65% |
| P3 전환 | HP 35% |
| 발악 전환 | HP 10% |
| Task Kill | HP 1% |

난이도별 차이는 반드시 적용한다.

- 쉬움: 경고 시간 +20%, 피해 -20%, 탄막 빈도 -20%
- 보통: 기준값
- 어려움: 경고 시간 -15%, 피해 +15%, 탄막 빈도 +15%

---

## 3. 아레나: System Isolation

P1부터 아레나는 보이지만, 피해 판정은 P2부터 적용한다.

- 중심: 화면 중앙
- 반지름: `min(screenW, screenH) * 0.42f`
- 경계 밖 피해: **플레이어 최대 HP의 12%/s**
- 경계 검 수: 24개
- 경계는 벽 판정이 아니라 피해 경고선이다.

P2 진입 시 장벽 검이 화면 바깥에서 원형 경계로 모이는 연출을 넣는다.

---

## 4. 기본 공격

기본 공격은 대시를 대신하는 패턴이 아니라, 대시가 잘 통하도록 플레이어의 고정 무빙을 깨는 장치다. 모든 기본 공격은 짧고 명확해야 하며, 사용 후 SUDO_EXECUTE로 자연스럽게 이어질 수 있어야 한다.

### Edge Slash

플레이어의 좌우 회피를 끊는 가로/대각 검기.

- 경고: 0.55초
- 피해: 10
- 속도: 640
- P1부터 사용
- 보스가 대시 차징 전에 1~2발 사용

의도: 계속 좌우로 흔드는 플레이를 막는다.

### Orbit Cut

플레이어가 시계방향으로 계속 돌 때 경로 앞쪽에 짧은 원호 검격을 만든다.

- 경고: 0.65초
- 피해: 12
- 원호 지속: 0.22초
- P2부터 사용
- 원호는 벽이 아니라 짧은 피해 판정

의도: 한 방향 원형 무빙을 끊는다.

### Cross Check

보스가 짧게 검을 세우고 십자 예고선을 만든 뒤, 두 방향 중 하나를 먼저 베고 나머지를 늦게 벤다.

- 경고: 0.75초
- 첫 베기 피해: 11
- 두 번째 베기 피해: 8
- P2부터 사용
- 어려움에서는 두 번째 베기 지연 시간이 짧아짐

의도: 플레이어가 대시 직전 위치를 너무 쉽게 고정하지 못하게 한다.

기본 공격 사용 규칙:

- P1: Edge Slash만 사용
- P2: Edge Slash + Orbit Cut + Cross Check
- P3: 기본 공격 1개 후 SUDO_EXECUTE로 연결
- 발악: 기본 공격을 많이 늘리지 말고 SUDO_EXECUTE 템포를 빠르게 한다

---

## 5. 패턴 A: SUDO_EXECUTE

메인 패턴. 모든 페이즈에서 사용한다.

```text
대기 -> 기본 공격 0~1회 -> 차징 -> 대시 -> 패널티 윈도우 -> 대기
```

P2 이후에는 대시 전에 기본 공격이 1회 들어간다. 단, 기본 공격이 끝나고 0.25초 안에 차징 예고가 시작되어야 리듬이 끊기지 않는다.

### 차징

- P1: 1.0초
- P2: 0.8초
- P3: 0.65초
- 발악: 0.55초

검이 플레이어 방향을 조준하고, 돌진 경로를 긴 선으로 보여준다. 발사 직전 0.18초는 방향을 고정한다.

### 대시

- 속도: `2400 px/s`
- 검 길이: `600px`
- 피해: 30 고정
- 판정은 보스 중심 원형이 아니라 **검 선분 기준**으로 처리한다.

### 패널티 윈도우

- P1: 1.5초
- P2: 1.25초
- P3: 1.0초
- 발악: 0.8초

이 시간에는 보스 이동과 패턴 A 공격을 멈춘다. 플레이어가 확실히 보상 딜을 넣는 구간이다.

---

## 6. 패턴 B: BACKGROUND_ROUTINE

P2부터 사용하는 보조 패턴. P2에서는 패턴 A와 **교대**, P3부터는 **동시** 사용한다.

동작:

1. 보스 잔상이 아레나 외곽에 생성된다.
2. 잔상은 원형 궤도를 돈다.
3. 일정 간격으로 플레이어 방향 검기를 발사한다.
4. 지속 시간이 끝나면 잔상이 사라진다.

수치:

| 페이즈 | 쿨다운 | 지속 | 발사 간격 | 검기 피해 | 검기 속도 |
|--------|--------|------|-----------|-----------|-----------|
| P2 | 8.0s | 5.0s | 0.22s | 14 | 580 |
| P3 | 5.0s | 6.0s | 0.18s | 15 | 620 |
| 발악 | 상시 | 상시 | 0.24s | 12 | 560 |

P2에서는 패턴 B 중 본체가 은닉/무적 상태가 되어도 된다. P3부터는 본체가 패턴 A를 계속 사용한다.

---

## 7. 발악: FATAL_ERROR

HP 10% 이하에서 시작한다.

- 본체는 패턴 A를 빠르게 반복한다.
- 잔상은 패턴 B를 느린 간격으로 계속 사용한다.
- 대시 패널티 윈도우 시작 위치에 배드섹터를 만든다.

배드섹터:

- 크기: `80 x 80`
- 최대 개수: 12개
- 피해: `3.5 HP/s`
- 이동 속도 감소: `-50%`
- 지속: 보스 생존 중

배드섹터는 반드시 main 이동 처리와 피해 처리에 연결한다.

---

## 8. Task Kill

HP가 1% 이하가 되면 일반 사망을 막고 Task Kill 시퀀스에 들어간다.

규칙:

- HP를 1%로 고정한다.
- 이후 플레이어 탄 피해를 무시한다.
- 모든 기존 적탄과 잔상은 제거한다.
- 렌더는 scissor 밖 **전체 화면 최상단**에서 처리한다.

시퀀스:

| 시간 | 내용 |
|------|------|
| 0.0s | 전투 정지, BGM 페이드 |
| 1.0s | 검이 화면 상단 중앙으로 이동 |
| 2.0s | 안전지대 생성 |
| 3.0s | 검 스윕 시작 |
| 3.25s | 판정 |

판정:

- 안전지대 안: 보스 사망 처리, `OnBossKilled(20, 50)` 진행
- 안전지대 밖: 플레이어 즉사

주의:

- Task Kill 성공 시 `exploded=true`를 먼저 세팅해서 main 사망 처리를 스킵하면 안 된다.
- HP가 한 방에 0 이하로 떨어져도 Task Kill을 건너뛰면 안 된다.

---

## 9. 구현 주의점

- 검 대시/베기 판정은 렌더된 검의 선분과 맞춰야 한다.
- PUNISH 상태를 명시적으로 둔다.
- 기본 공격은 대시 사이클을 대체하지 않고, 대시 직전 견제기로만 사용한다.
- P2 이후에도 한 사이클에 기본 공격은 최대 1개만 사용한다.
- `Difficulty difficulty` 인자는 실제 수치에 반영한다.
- 아레나 피해는 보스 HP가 아니라 플레이어 최대 HP 기준이다.
- 패턴 B 은닉/무적 여부는 main의 보스 피격 루프와 연결한다.
- Task Kill 렌더는 보스 창 scissor 안에서 처리하지 않는다.
- 배드섹터는 `EtherSwordBoss::IsBadSector()`를 이동 감속과 피해 양쪽에서 사용한다.

```text

- 검 선분 기반 피격 판정 정리

- 배드섹터 감속/피해 연결
- 난이도별 수치 적용

[P2]
- Task Kill 전체 화면 렌더
- 페이즈 전환 연출
- 검기/장벽/코어 렌더 polish
```

## 11. 최종 의도

ETHER_SWORD는 “탄이 많아서 어려운 보스”가 아니다.

이 보스의 재미는 검이 오는 방향을 보고, 정말 아슬아슬하게 피하고, 바로 반격하는 리듬에 있다. 기본 공격은 그 리듬을 망가뜨리는 추가 콤보가 아니라, 플레이어가 너무 단순한 무빙으로 돌진을 무력화하지 못하게 만드는 압박 장치다.
