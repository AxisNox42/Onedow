# 보스 기획안: TESS.glitch / Gravity Core

## 1. 방향

TESS.glitch는 막대, 벽, 장벽 판정을 쓰지 않는 중력 코어 보스다.

전투의 핵심은 플레이어를 물리적으로 가두는 것이 아니라, 블랙홀 흡입, 역방출, 원형 탄막, 짧은 중력 펄스로 이동 판단을 흔드는 데 있다.

외형은 글리치 큐브 + 항성 코어 + 공전축 링을 유지한다. 보스 주변을 도는 링과 입자들이 공격 전조처럼 정렬되며, 페이즈가 오를수록 회전축이 불안정해진다.

## 2. 금지 요소

- wall 판정 사용 금지
- 막대 투사체, 장벽, 충돌 블록 금지
- 플레이어를 물리적으로 밀어서 화면 구석에 가두는 패턴 금지
- 화면 전체를 막는 격자 패턴 금지
- 소환몹, 오래 남는 장애물 금지

## 3. 기본 스킬

기본 스킬은 페이즈와 상관없이 사용한다. 단, 페이즈가 오를수록 경고 시간이 짧아지고 범위가 조금 커진다.

### Black Hole

플레이어 주변 또는 보스 아래쪽에 중력장을 만든다.

- 중형 원형 범위
- 지속 중 약한 지속 피해
- 범위 안의 플레이어를 중심으로 천천히 흡입
- 단독 사용하거나 Reverse Burst와 연계

### Reverse Burst

중력장이 반전되며 고리 형태의 충격파가 터진다.

- 원형 링 판정
- 단발 피해
- 약한 넉백
- Black Hole 종료 직전 연계용으로 사용

### Gravity Pulse

짧고 빠른 기본 압박기다.

- 플레이어 근처 또는 보스 주변에 작은 링 생성
- 경고 후 매우 짧은 판정 발생
- 피해는 낮지만 회피 리듬을 흔드는 용도
- 모든 페이즈에서 빈 패턴을 채우는 기본기

## 4. 특수 스킬

### Gravity Breath

기존 레이저형 브레스가 아니라, 보스가 맵 중앙으로 이동한 뒤 330도 방향에 약한 탄환을 대량 난사하는 패턴이다.

- 보스가 중앙으로 이동하며 원형 전조 표시
- 전체 360도 중 약 330도는 탄막 영역
- 피할 수 있는 구멍은 3방향
- 구멍은 각 방향마다 작게 열림
- 탄환 하나의 피해량은 낮음
- 탄환은 중앙에서 바깥으로 퍼져 나감
- 탄환은 플레이어 사격으로 제거 가능
- 안전 구멍은 텔레그래프에서 청록색 가이드로 표시

의도:
- 레이저처럼 한 줄을 피하는 패턴이 아니라, 작은 안전각을 보고 자리를 잡는 패턴
- 피격 한 번은 치명적이지 않지만, 잘못 서 있으면 연속 피격으로 손해를 보는 구조
- 중앙 이동 연출과 함께 보스의 핵심 패턴처럼 보이게 함

## 5. 페이즈 구성

### Phase 1: Gravity Wake

첫 보스급 난이도를 유지하되, 너무 비어 보이지 않게 기본 스킬을 섞는다.

사용:
- Black Hole
- Reverse Burst 약한 버전
- Gravity Pulse

감각:
- 블랙홀과 펄스로 이동을 유도한다.
- 아직 Gravity Breath는 사용하지 않는다.
- 회피 규칙을 학습시키는 구간이다.

### Phase 2: Gravity Breath

중앙 탄막 브레스를 해금한다.

사용:
- 기본 스킬 전체
- Gravity Breath
- Black Hole -> Gravity Breath
- Gravity Breath -> Reverse Burst

감각:
- 작은 안전 구멍을 보고 위치를 잡아야 한다.
- Black Hole로 이동을 흐트러뜨린 뒤 브레스를 연결한다.
- 탄환 피해는 낮지만 누적 피격이 위험하다.

### Phase 3: Singularity Break

모든 패턴의 템포가 빨라지고 연계가 겹친다.

사용:
- 기본 스킬 전체 강화
- Black Hole 2개
- Reverse Burst 강화
- Gravity Breath 연속 또는 좁은 안전각 버전

감각:
- 보스가 중앙으로 이동하는 순간 안전 구멍을 빠르게 찾아야 한다.
- 탄막 자체는 약한 다단 피해지만, Black Hole과 겹치면 이동 실수가 커진다.
- 벽 판정 없이 순수 중력과 탄막으로 압박한다.

## 6. 난이도 기준

쉬움:
- 전조 시간이 길다.
- Gravity Breath 구멍이 조금 넓다.
- 탄환 수와 속도가 낮다.
- 기본 스킬 범위가 작다.

보통:
- 기준값 사용.
- Phase 2부터 Gravity Breath를 안정적으로 사용한다.

어려움:
- 전조 시간이 짧다.
- Gravity Breath 구멍이 좁다.
- 탄환 수와 속도가 증가한다.
- Phase 3에서 연속 브레스 빈도가 증가한다.

## 7. 구현 메모

- 기존 `walls`, `orbs` 컨테이너는 호환용으로만 유지하고 비워 둔다.
- `hitWall()`은 항상 false를 반환한다.
- Gravity Breath는 직접 충돌 판정이 없고, 요격 가능한 `Bullet`을 생성해 처리한다.
- Gravity Pulse와 Reverse Burst는 짧은 링 판정이다.
- Black Hole만 지속 피해와 흡입을 담당한다.
