### 🪨 [Tier 0.5] The Node — 부유 파편
**역할:** 경험치 자판기, 더미 데이터. The Hive가 소환하거나 초반에 홀로 출현.  
**대체 대상:** DDoS / DDOS — 동일하게 소형 물량 소모품이지만 사격 없이 단순 박치기만.

**형태**
- Scale: `0.4f`
- 빈 마름모(◇) 와이어프레임 1레이어, 선 1px
- 컬러: 칙칙한 버건디 `#8B0000` 계열, 채도 낮음
- 정중앙 극소 붉은 픽셀 코어

```
        /\
       /  \
      / ·  \        ← 내부 비어있음, 선만 존재
      \    /        ← 코어(·)는 극소 판정점
       \  /
        \/
```

**이동·회전**
- 플레이어 방향 느린 등속 직선 이동 (회피 없음)
- 시계 방향 느린 회전 `rotSpeed = 30.0f * dt`

**행동**
- 탄막 없음. 몸통 충돌 데미지만 존재
- **사망 연출:** 마름모 4선이 각각 툭 끊어지며 페이드아웃 (폭발 없음)

**코드 매핑:** 현재 `MobKind::DDOS` → `MobKind::NODE` 로 rename 또는 Node 전용 클래스

### 🔪 [Tier 1] The Rotor — 회전 칼날
**역할:** 돌격형 팝콘 몹. 물량 공세의 핵심.  
**대체 대상:** Process / NORMAL — 기본 추격 역할 유지, 사격 추가 + 고속 회전 시각

**형태**
- Scale: `0.6f`
- 4각 별(✧) 또는 십자(✚) 외곽선, 꼭짓점 날카로움
- 컬러: 오렌지-레드 `#FF4500` 계열
- 중앙 밝은 주황 픽셀 코어

```
           ↑
          /│\
         / │ \
   ←←←──/──★──\──→→→     ← 4방향 극단적으로 뾰족한 끝
         \ │ /
          \│/
           ↓
   (반시계 -300°/s 고속 자전)
```

**이동·회전**
- Steering Behavior 곡선 접근 (현재 직선 추격 → 부드러운 방향 전환)
- **반시계 방향** 고속 회전 `rotSpeed = -300.0f * dt` (기동성이 시각적으로 느껴져야 함)

**행동**
- FSM: `[CHASE]` 단일 상태 유지하며 일정 쿨타임마다 사격
- **탄막 [데이터 바늘]:** 얇고 짧은 직선, 꼬리 없음, 고속 직진

**코드 매핑:** 현재 `Monster` 클래스 + `MobKind::NORMAL` 기반 유지, 사격 로직 추가

### 👁️ [Tier 2] The Lens — 다중 렌즈
**역할:** 스나이퍼. 정밀 고속탄 타격.  
**대체 대상:** Adware / RangedMob — 원거리 공격 역할 유지, FSM 4단계 스나이퍼로 격상

**형태**
- Scale: `1.0f`
- 정사각형(□) 2겹, 서로 엇갈려 교차 회전 (Layer 1 / Layer 2)
- 컬러: 진홍 `#DC143C` (차가운 느낌 혼합)
- 중앙 붉은 다이아몬드 코어

```
         ◆                        ← Layer 2 (45° 사각형)
      ┌──┼──┐
      │  │  │
    ◆─┤  ♦  ├─◆   Layer 1 ┌──┐ → CW  +90°/s
      │  │  │   Layer 2  ◆  → CCW -90°/s
      └──┼──┘
         ◆

    [AIM 상태: 두 레이어가 완벽히 겹쳐 정렬됨]

        ◆◆
       ┌◆┐
       ◆[♦]◆   ← 코어 백색 점멸
       └◆┘
        ◆◆
```

**이동·회전**
- 플레이어와 일정 사거리 유지하며 Hovering 공전
- 평상시 Layer1 시계방향 `+90.0f`, Layer2 반시계 `-90.0f` 교차 회전

**행동 — FSM**
```
[IDLE - 호버링] → [AIM - 조준] → [FIRE - 발사] → [RECOIL - 반동] → [IDLE]
```
- **AIM:** 회전 강제 Lerp→0, 두 사각형 45° 완전 정렬, 코어 백색광 점멸 0.5초
- **FIRE:** 빛 번쩍임 후 탄 발사
- **RECOIL:** 기체 뒤로 살짝 밀렸다가 IDLE 복귀
- **탄막 [광속 쐐기탄]:** 꺾쇠(〉) 형태, 얇은 Trail, 초고속 (전체 탄 중 최속)

**코드 매핑:** 현재 `RangedMob` 클래스 → FSM 상태 변수 + 2겹 사각형 렌더링으로 재구성

### 🛰️ [Tier 1] The Satellite — 궤도 위성
**역할:** 기생형 방어막. 총알 흡수기. 중성자별 붕괴의 화약.  
**대체 대상:** 없음 (완전 신규) — 단, Tier 2+ 고티어 숙주 등장 시 세트로 자동 스폰됨.

**형태**
- Scale: `0.4f` (팝콘몹보다 작음)
- 빈 원(○) 또는 얇은 정육각형(⬡) 와이어프레임. 속 빈 방패 느낌
- 컬러: **숙주와 동일 색상, Alpha 60%** (반투명)
- 정중앙 아주 작은 주황색 꽉 찬 점 코어 (피격 판정)
- **Tether 선:** 숙주 코어 ↔ 위성 코어 사이에 흐릿한 광선 항상 표시

```
                       ╔════[HOST 코어]════╗
                        ≋≋≋≋≋≋ tether ≋≋≋≋≋≋
                   ↺ (○)     ← 속 빈 원, Alpha 60%
                orbit↗ ↘
     (○)                        (○)
   ≋≋≋≋≋≋≋≋≋≋╗            ╔≋≋≋≋≋≋≋≋≋
             [HOST]─────[HOST]
   (위성 2~4기가 숙주 주위를 동시에 고속 공전)
```

**이동·회전**
- 단독 스폰 불가. Tier 2 이상 숙주 등장 시 **2~4기** 동시 스폰
- 자전: 반시계 고속 회전 `rotSpeed = -400.0f * dt`
- 공전: 숙주를 중심점으로 일정 궤도 반지름 유지하며 고속 공전

**행동**
- 사격 없음 (DPS = 0)
- **방어 기믹:** 플레이어 총알이 위성에 닿으면 총알 소멸 + 위성 HP 감소. 숙주로 가는 딜을 막는 회전 방패
- 숙주가 살아있는 동안 공전 유지 → 숙주 사망 시 **중성자별 붕괴 기믹** 발동

**코드 매핑:** 별도 `Satellite` 구조체. 숙주 `Monster*` 포인터 보유, 공전 각도 누적

### 🌟 핵심 기믹: 중성자별 붕괴 (Neutron Star Collapse)
**트리거:** 위성이 살아있는 상태에서 **숙주의 HP가 0** 이 되는 순간 발동  
**컨셉:** 본체가 중성자별로 압축되며 위성을 흡수 → 흡수 개수 비례 반격탄 폭발

#### Phase 1 — 붕괴와 흡수 (Implosion, ~0.3초)
- 숙주 본체: 폭발하지 않고 다각형 골격이 안쪽으로 쪼그라들며 **순백색 구체**로 압축
- 남은 위성들: 즉시 공전 물리 정지 → 약 0.3초에 걸쳐 백색 코어로 직선 빨려 들어감
- 위성 흡수 시마다 내부 변수 `absorbed_count++`

```
━━━━━━━━━━━ 중성자별 붕괴 시퀀스 ━━━━━━━━━━━

 ┌─ Phase 1: IMPLOSION ─┐  ┌─ Phase 2: HITSTOP ─┐  ┌─ Phase 3: SUPERNOVA ─┐
 │                      │  │                     │  │    ↖   ↑   ↗         │
 │  ○ →        ← ○      │  │        ✦            │  │  ←  ·(☀)·  →        │
 │    ╲        ╱        │  │      ☀☀☀☀☀          │  │    ←  ·☀·  →        │
 │     ╲  ☀☀  ╱         │→│      ☀☀☀☀☀      →  │  │  ←  ·(☀)·  →        │
 │     ╱      ╲         │  │     (PEAK 휘도)      │  │    ↙   ↓   ↘        │
 │  ○ ←        → ○      │  │   위성 전원 소멸      │  │  반격탄 n×2발 방사   │
 └──────────────────────┘  └─────────────────────┘  └──────────────────────┘
   위성이 백색 코어로 빨려 들어감  0.1~0.2s 정적       360° 균일 쐐기탄
```

#### Phase 2 — 초신성 폭발 (Supernova Burst)
- **히트 스톱:** 흡수 완료 후 0.1~0.2초간 정적. 코어 최대 휘도 점멸 (폭발 직전 텐션)
- **폭발:** 카메라 쉐이크 + 백색 코어 파열
- **반격탄 생성:**
  - 발사량 = `absorbed_count × 2` (위성 3개 흡수 → 6발)
  - 형태: 날카롭고 뾰족한 고속 쐐기탄(〉)
  - 궤도: 코어 중심 360° 균일 방사형

**연동 대상 숙주 (Tier 2+):** The Lens, The Pulsar, The Quasar, The Octagon, The Hive  
*(Tier 0.5 Node / Tier 1 Rotor 는 위성 보유 불가)*

**코드 구조안:**
```cpp
// 숙주 Monster 사망 처리 시
if (host->hp <= 0.0f && !host->satellites.empty()) {
    host->alive = false;
    SpawnNeutronCollapse(host);   // 위성 흡수 + 반격탄 코루틴
} else {
    host->alive = false;          // 위성 없으면 일반 사망
}

// 붕괴 상태 머신 (별도 NeutronCollapseEvent 구조체)
// Phase: IMPLOSION → HITSTOP → SUPERNOVA → DONE
```

### ⚡ [Tier 2.5] The Quasar — 퀘이사
**역할:** 맵 절단기. 줄넘기 패턴. Laser Sweeper.  
**대체 대상:** 없음 (완전 신규)

**형태**
- Scale: `2.0f` (세로로 매우 긴 형태)
- 레일건 프레임 — 양옆이 열린 길쭉한 십자가(✚), 중앙 통로 개방
- 컬러: 핏빛-네온 레드
- 중앙 길쭉한 붉은 직사각형 코어

```
        ║   ║
        ║   ║
        ║   ║
   ═════╬═══╬═════     ← 양 옆이 열려있음 (사격 통로)
        ║■■■║           ← 코어 (붉은 직사각형)
   ═════╬═══╬═════
        ║   ║
        ║   ║
        ║   ║

   CHARGE 상태 (조준선 노출):
   · · · ║   ║ · · ·   ← Alpha 30% 조준선 화면 끝까지
        ║■■■║
   · · · ║   ║ · · ·

   SWEEP 상태 (레이저 ON + 회전):
   ══════╬═══╬══════════════════ [BEAM] ══   ← 기체가 돌면서 빔 스윕
```

**이동·회전**
- 맵 중앙 또는 지정 위치 이동 후 정지
- IDLE 시 부드러운 회전; SWEEP 시 `rotSpeed = 45.0f * dt` 강제 회전

**행동 — FSM**
```
[IDLE] → [CHARGE - 조준선] → [SWEEP - 레이저+회전] → [OVERHEAT - 휴식] → [IDLE]
```
- **CHARGE:** 회전 정지, 화면 끝까지 닿는 얇은 조준선(Alpha 30%) 1초 노출
- **SWEEP:** 굵은 레이저(Collider 포함) 활성화 + 기체 느린 회전
- **탄막 [데이터 빔]:** 투사체 아닌 BoxCollider/Raycast 기반 지속 레이저

**코드 매핑:** 신규 클래스 `Quasar`. 레이저 = 위치+각도 기반 AABB/OBB 판정 필요

**대체 대상:** 없음 (완전 신규)

## 코드 네이밍 계획 (MobKind enum 변경안)

```cpp
// 현재 → 신규
MobKind::NORMAL   → MobKind::ROTOR    // The Rotor    (회전 칼날)
MobKind::DDOS     → MobKind::NODE     // The Node     (부유 파편)
MobKind::SPAWNER  → MobKind::HIVE     // The Hive     (넥서스)
// RangedMob 클래스 → LensMob 클래스로 rename    // The Lens  (다중 렌즈)

// 신규 추가 (끝에 append — 인덱스 보존)
MobKind::PULSAR   // The Pulsar   (맥동성)
// Quasar / Octagon 은 별도 클래스로 분리 (보스급)

// 위성 — MobKind 에 추가하지 않고 별도 구조체로 관리
struct Satellite {
    float orbitAngle;       // 공전 각도 (rad, 매 프레임 누적)
    float orbitRadius;      // 궤도 반지름 (px)
    float spinAngle;        // 자전 각도 (시각용)
    float hp;
    bool  alive;
    Monster* host;          // 숙주 포인터 (nullptr 이면 고아 처리)
};

// 중성자별 붕괴 이벤트
struct NeutronCollapseEvent {
    glm::vec2 pos;          // 폭발 위치
    int       absorbed;     // 흡수된 위성 수
    float     timer;        // 페이즈 타이머
    enum class Phase { IMPLOSION, HITSTOP, SUPERNOVA, DONE } phase;
};
```

> ⚠️ enum rename 시 저장 인덱스 충돌 주의. 끝에 신규 추가 후 기존 항목은 deprecated alias로 유지.

현재 active roster는 `Process/NORMAL · Adware/RangedMob · DDoS/DDOS · Botnet/SPAWNER` 4종.

- Phase 1부터 순차 진행, 각 Phase 완료 후 플레이테스트로 스폰 밸런스 검증 권장
