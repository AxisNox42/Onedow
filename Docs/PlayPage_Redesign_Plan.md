# PLAY 페이지 리디자인 기획안 — "STAR CHART"

## 0. 전제

- 이 게임의 전투는 **데스크탑 화면 위 투명 오버레이 창**에서 일어난다. 플레이어는 "OS 창들 사이에서 벌어지는 전투"를 보는 것이 코어 경험.
- 게임 전체 비주얼 테마는 **별자리(성좌)** 로 통일한다.
- 따라서 PLAY 화면은 "설정창"이 아니라, **런 전에 밤하늘 성도(星圖)를 그리는 의식**이어야 한다. 난이도/무기/굴레 선택 = 별을 찍어 하나의 별자리(런 빌드)를 완성하는 행위.
- 스타일 기준은 `UI_RunConfig_Unification_Plan.md`를 계승하되, 글로우·별 렌더링은 "장식"이 아니라 "정보 표현 수단"으로 사용한다.

## 1. 현행 문제점

- `Scene_RunConfigInline` (`WiNILL/Core/Scenes/Scenes.cpp:7162-7762`)의 4분할 구조(좌 메뉴 / 좌 무기 / 우 캔버스 / 하단 PLAY)로 시선이 분산됨.
- WEAPONS / TRIALS가 `canvasPage` 토글로 숨겨져 있어 런 구성이 한눈에 안 보임.
- 난이도 선택 UI는 기획상 폐기됐으나 코드에 잔존(레거시).
- 풀스크린 `Scene_RunConfig` (`Scenes.cpp:6042-6986`) 와 인라인 버전 두 벌 공존 → 이중 유지.

## 2. 컨셉: "STAR CHART — 런 성도"

> 플레이어는 별자리 관측자다. 런을 시작하기 전, 이번 런의 운명이 될 별자리를 직접 잇는다.

- 화면 전체 = 어두운 밤하늘 성도 캔버스 (기존 `DrawMenuBackground` + 별자리 배경과 시각적 연속성 유지 — 메인메뉴 위 인라인 패널이므로 "같은 하늘의 다른 구역을 보는" 느낌).
- 각 선택 항목은 UI 카드가 아니라 **성좌 노드(별)** 로 표현하고, 선택 시 별들이 선으로 이어지며 하나의 런 별자리가 완성된다.
- 완성된 별자리는 런 내내 해당 런의 "상징"이 된다 (향후 HUD/결과 화면에 재사용 가능).

## 3. 레이아웃 (1640×910 기준, `uiS` 비례)

```
┌────────────────────────────────────────────────────────┐
│ STAR CHART // RUN PREPARATION              [ESC] BACK  │ ← 얇은 헤더 라인
│                                                          │
│   · 무기 성좌 ·            · 굴레 궤도 ·        · 런 요약 · │
│                                                          │
│  ✦ RIFLE ───╮        ┌──(좌우 스크롤 띠)──┐    DIFFICULTY —│
│    별 노드   ╲       │ ◇ 굴레1 ◇ 굴레2 ◇ │    WEAPON    —│
│  ✧ STATIC ──╯        │    굴레3 ◇ 굴레4 …│    SHACKLES  —│
│    FIELD             └────────────────────┘    ────────────│
│  (선택 시 6축 스탯 바가                                    │
│   별빛 그래프로 표현)                          ✦ LAUNCH    │
│                                             (완성된 별자리  │
│                                              중심의 별)     │
└──────────────────────────────────────────────────────────┘
```

- **좌 컬럼 — 무기 성좌**: 무기 2종(RIFLE / STATIC FIELD)을 카드 대신 별 클러스터 노드로. 선택된 무기는 밝게 점등 + 6축 스탯 바가 해당 별 주변에 방사형으로 펼쳐짐. 기존 호버 스탯 모핑 연출(`statVals`) 유지.
- **중앙 — 굴레 궤도 띠**: 굴레(Shackle) 칩을 가로 스크롤 가능한 궤도 띠로 배치. 좌우 화살표 + 드래그/휠 스크롤. 칩은 작은 별/다이아몬드 문양, 선택 시 점등되고 궤도 선으로 연결.
- **우 컬럼 — 런 요약 + LAUNCH**: 선택 결과가 실시간으로 "그려지는 별자리" 미리보기 + 텍스트 요약(WEAPON / SHACKLES +N). LAUNCH 버튼은 별자리의 가장 밝은 별 위치에, 기존 코너라인+다이아몬드 장식 계승. 라벨은 굴레 수에 따라 `LAUNCH +N`.
- 선택이 모두 유효해지는 순간 별들이 선으로 이어지는 연출 → 완성된 런 별자리가 LAUNCH 별로 수렴.

## 4. 상호작용 흐름

1. 메인메뉴 PLAY → 인라인 STAR CHART 패널 펼침 (기존 진입/exit 애니메이션 구조 유지: `s_MainMenuRunConfigPanel`, `playExit`).
2. 무기 별 선택 → 스탯 방사형 표시.
3. 굴레 궤도에서 칩 선택/해제 (가로 스크롤), 또는 "굴레 추가" 노드 → `Scene_TrialSelectInline`으로 진입 (기존 경로 유지, `Scenes.cpp:7764`).
4. LAUNCH → collapse 애니메이션 + 별자리 점등 연출 → 굴레 있으면 무작위 배정 후 TrialSelect, 없으면 `FinalizeLoadout` (`Scenes.cpp:5866`) → READY.
5. ESC/우클릭 뒤로가기 유지.

## 5. 비주얼 규칙 (별자리 테마 적용)

- 배경: 기존 메뉴 배경 별하늘 유지, 패널 영역은 아주 얕은 어두운 면 + 코너 브라켓(과도한 글로우 금지 — `UI_RunConfig_Unification_Plan.md` 준수).
- 별 노드: `DrawPrim`/`drawDiamond` 기반, 상태 3단계(미획득 흐림 / 호버 미세 점등 / 선택 점등+연결선). 글로우는 선택 별에만 제한적 사용.
- 연결선: 얇은 1px 라인 + 느린 파동 알파. 완성 시 한 번 밝아졌다가 안정.
- 스탯 6축: 기존 바 유지하되 배치를 선택 별 주변 방사형으로.
- 텍스트: 기존 `T(StrId::…)` 다국어 시스템 그대로, 헤더 라벨을 "STAR CHART" 무드로 교체.
