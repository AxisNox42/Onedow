# 보스 기획안: BLINDSPOT.null / Cursor Lantern

**내부 클래스명:** `BlindspotNullBoss`  
**보스 픽 번호:** `22` (문서상 임시 예약, 코드 미등록)  
**역할:** 특별 캠페인/이벤트 보스  
**태그라인:** `The threat is not where you are looking.`  
**경고 색상:** `{ 0.08f, 0.10f, 0.16f }` + 조명부 `warm white`

---

## 1. 보스 아이덴티티

BLINDSPOT.null은 보스 고유 창을 가지지 않는 보스다.

전투가 시작되면 화면 전체가 어두워지고, 플레이어가 커서로 바라보는 방향만 부채꼴 조명처럼 밝아진다. 이 보스전의 핵심은 탄막 밀도가 아니라 **정보 부족**이다. 플레이어는 공격하려면 커서를 보스 쪽으로 둬야 하지만, 동시에 어둠 속에서 생성되는 위험도 확인해야 한다.

전투 감각:

- 플레이어의 커서 방향이 조준, 시야, 정보 확인을 동시에 담당한다.
- 보스는 항상 보이기보다, 조명 안에 들어왔을 때만 명확해진다.
- 위험 예고는 어둠 속에서도 희미하게 보이지만, 조명으로 비추면 정확한 판정이 드러난다.
- 넓은 맵이지만 시야가 좁아서 심리적으로 좁게 느껴진다.

목표는 공포 게임이 아니라, 탄막 슈팅 안에서 "어디를 봐야 하는가"를 계속 고민하게 만드는 것이다.

---

## 2. 금지 요소

- 완전 암전으로 정보가 사라지는 패턴 금지
- 조명 밖 공격이 경고 없이 즉시 피해를 주는 구조 금지
- 보스가 계속 완전 은신해서 딜 타임을 찾기 어려운 구조 금지
- 커서 조명과 실제 조준 방향이 따로 노는 구조 금지
- 화면 전체를 계속 어둡게만 만들어 피로감이 큰 구조 금지
- 보스 고유 창 생성 금지
- 즉사기 남발 금지

어둠은 불공정함이 아니라 정보량 조절 장치여야 한다.

## 3. 기본 스펙

|------|----|
| 기본 HP | `12,800 * HpMul * actRules.hpIntensityCap` |

BLINDSPOT은 보스 창이 없으므로 월드 전체를 전장으로 사용한다. 대신 보스 본체는 지나치게 빠르게 움직이면 안 된다. 플레이어가 조명으로 찾고 반응할 시간이 필요하다.

## 4. 핵심 시스템: Cursor Lantern

전투 중 화면 전체에 어둠 오버레이를 깐다.

조명 규칙:

- 플레이어 중심에서 커서 방향으로 부채꼴 밝은 영역 생성
- 조명 안에서는 보스, 공격 예고, 위험 판정이 선명하게 보임
- 조명 밖에서는 실루엣과 희미한 경고만 보임
- 조명은 즉시 회전하지 않고 아주 약한 지연을 둔다
- 지연은 조작 불쾌감이 생기지 않도록 0.04~0.07초 수준만 사용

권장 구현 메모:

```cpp
struct LanternState {
    float ang;
    float targetAng;
    float coneRad;
    float len;
    float darknessAlpha;
};
```

렌더링 의도:

- 어둠은 완전 검정이 아니라 70~82% 어둡게 덮는다.
- 조명 중심부는 밝고, 외곽은 부드럽게 흐려진다.
- 조명 안의 공격 예고는 색과 테두리가 뚜렷해진다.
- 조명 밖의 예고는 낮은 알파로만 보인다.

## 5. 페이즈 구조

### Phase 1: First Look

플레이어가 커서 조명 규칙을 익히는 구간이다.

사용 패턴:

- Shadow Step
- Blind Mark
- Needle From Dark

감각:

- 보스를 찾고 조준하는 법을 배운다.
- 조명 밖 경고가 완전히 안 보이는 게 아니라 희미하게 보인다는 점을 익힌다.
- 아직 시야 방해가 심하지 않다.

### Phase 2: Peripheral Threat

조명 반대편과 외곽 시야를 압박한다.

사용 패턴:

- 기본 패턴 전체
- Peripheral Mine
- Gaze Split
- Dark Corridor

감각:

- 보스를 계속 바라보면 주변 위험을 놓친다.
- 주변을 확인하면 보스 딜 타임을 놓친다.
- 조명 방향 선택이 전투의 핵심이 된다.

### Phase 3: Blindspot Panic

보스가 플레이어의 시선 이동을 역이용한다.

사용 패턴:

- 모든 기본 패턴 강화
- Afterimage Hunt
- Blackout Pulse
- Last Seen

감각:

- 시야가 좁아진 듯한 심리적 압박이 생긴다.
- 그래도 모든 위험은 미리 읽을 수 있어야 한다.
- 정답은 빠른 반응보다 "지금 봐야 할 곳" 판단이다.

## 6. 기본 스킬

### Shadow Step

보스가 조명 밖으로 짧게 사라진 뒤, 플레이어의 조명 외곽에 다시 나타난다.

동작:

1. 보스가 흐려지며 그림자 잔상 생성
2. 0.35~0.55초 후 조명 외곽 또는 플레이어 측면에 재등장
3. 재등장 위치에 짧은 원형 경고
4. 작은 파동탄 6~10개 발사

수치:

| 난이도 | 사라짐 시간 | 파동탄 수 | 피해 |
|--------|-------------|-----------|------|
| 쉬움 | 0.58s | 6 | 6 |
| 보통 | 0.46s | 8 | 8 |
| 어려움 | 0.36s | 10 | 10 |

의도:

- 보스가 어둠 속에서 이동한다는 정체성을 만든다.
- 재등장 위치는 완전 랜덤이 아니라 조명 외곽 중심으로 잡아 플레이어가 찾을 수 있게 한다.

### Blind Mark

플레이어 주변에 어둠 표식을 남긴다. 조명으로 비추면 정확한 범위가 드러난다.

동작:

1. 플레이어 이동 예상 경로 근처에 어둠 표식 생성
2. 조명 밖에서는 흐린 점으로만 표시
3. 조명 안에 들어오면 원형 위험 범위가 선명해짐
4. 0.90초 후 폭발

수치:

- 반경: 쉬움 52 / 보통 62 / 어려움 72
- 피해: 쉬움 8 / 보통 11 / 어려움 13
- P2부터 2개 동시 생성 가능
- P3 어려움에서는 3개 동시 생성 가능

의도:

- 플레이어가 어둠 속 희미한 정보를 무시하지 않게 만든다.
- 조명으로 확인하면 대응하기 쉬워져야 한다.

### Needle From Dark

어둠 속에서 얇은 직선탄이 날아온다. 발사 방향은 먼저 희미한 선으로 예고된다.

동작:

1. 화면 외곽에 작은 눈 모양 점 생성
2. 플레이어 방향으로 희미한 선 표시
3. 조명으로 비추면 선이 굵고 명확해짐
4. 0.55~0.80초 후 빠른 바늘탄 발사

수치:

- 탄속: 쉬움 620 / 보통 760 / 어려움 900
- 피해: 쉬움 7 / 보통 9 / 어려움 11
- 관통 없음

의도:

- 조명 밖 공격도 무조건 불공정하지 않게 만든다.
- "저 희미한 선을 확인할지, 보스를 계속 공격할지" 선택하게 만든다.

## 7. 특수 스킬

### Peripheral Mine

조명 바깥쪽 주변 시야에 지뢰성 그림자 덩어리를 만든다.

동작:

1. 플레이어 기준 좌우 70~120도 방향에 그림자 지뢰 생성
2. 조명으로 직접 비추기 전까지는 낮은 알파로만 표시
3. 일정 시간 후 플레이어 쪽으로 천천히 이동
4. 닿거나 시간이 끝나면 폭발

수치:

- 이동 속도: 80~130 px/s
- 폭발 반경: 60
- 피해: 10
- 최대 개수: 쉬움 2 / 보통 3 / 어려움 4

의도:

- 정면만 보는 플레이를 막는다.
- 커서를 크게 흔들어 주변 확인을 해야 하지만, 너무 자주 강요하지 않는다.

### Gaze Split

보스와 위험 예고가 서로 다른 방향에 생긴다.

동작:

1. 보스가 조명 안에 들어와 딜 타임을 제공
2. 동시에 조명 밖 반대편에 Blind Mark 또는 Needle 예고 생성
3. 플레이어가 보스를 계속 때리면 위험 예고 확인이 늦어진다
4. 위험 예고가 발동한 뒤 보스는 짧게 후퇴

수치:

- 딜 타임: 1.15초
- 반대편 예고 발동: 0.85초
- P3에서는 딜 타임 0.95초

의도:

- 이 보스의 대표 심리전.
- 공격 욕심과 생존 확인 사이의 선택을 만든다.

### Dark Corridor

화면에 좁은 밝은 경로와 어두운 위험 구역을 만든다.

동작:

1. 맵 전체가 더 어두워짐
2. 플레이어 커서 방향 조명 외에 2~3개의 희미한 안전 경로 표시
3. 어두운 벽 같은 그림자 선이 천천히 밀려옴
4. 플레이어는 조명으로 안전 경로를 확인하며 이동

수치:

- 지속 시간: 쉬움 2.6s / 보통 2.2s / 어려움 1.8s
- 그림자 선 피해: 7
- 그림자 선은 벽 판정이 아니라 피해 판정만 가진다

의도:

- 보스 고유 창이 없는 대신 화면 전체를 이벤트 공간으로 쓰는 패턴.
- 실제 충돌 벽은 만들지 않아 불쾌한 끼임을 피한다.

### Afterimage Hunt

P3 전용. 보스 잔상이 여러 곳에 생기고, 조명으로 진짜 위치를 판별해야 한다.

동작:

1. 보스 잔상 3개 생성
2. 잔상은 모두 짧은 조준 모션을 취함
3. 조명 안에 들어온 잔상은 가짜면 바로 부서짐
4. 진짜 보스만 조명 안에서 그림자가 반대로 흔들림
5. 0.80초 후 진짜 보스가 Needle 3발 발사

수치:

- 가짜 잔상: 피해 없음
- Needle 피해: 8
- 어려움에서는 발사 각도 3방향

의도:

- 플레이어가 조명으로 조사하는 행위를 공격 대응의 일부로 사용한다.
- 완전 운이 아니라 판별 규칙이 있어야 한다.

### Blackout Pulse

짧은 암전 펄스. 완전 암전은 아니고 조명 범위가 순간적으로 줄어든다.

동작:

1. 보스가 중앙 또는 외곽에서 낮게 울림
2. 0.55초 경고
3. 0.90초 동안 조명 길이와 각도가 감소
4. 감소 중 Blind Mark 1~2개 생성
5. 종료 후 조명 원상복귀

수치:

- 조명 각도 감소: 기본의 65%
- 조명 길이 감소: 기본의 72%
- 피해 판정 없음
- P3에서만 사용

의도:

- 최종 페이즈 압박용.
- 공격 자체보다 정보 확인 능력을 줄이는 디버프 패턴.

### Last Seen

P3 클라이맥스 패턴. 보스가 마지막으로 조명에 비친 위치를 기준으로 공격한다.

동작:

1. 보스가 1.2초 동안 조명에 닿을 때마다 잔상을 남김
2. 마지막으로 비춘 위치가 붉게 고정
3. 그 위치에서 방사형 탄막 발생
4. 동시에 보스 본체는 다른 방향에서 Needle From Dark 준비

수치:

- 방사형 탄막: 14~20발
- 탄 피해: 5
- Needle 피해: 10
- 쉬움에서는 Needle 연계 없음

의도:

- 플레이어가 보스를 찾는 행위 자체가 공격 위치를 만든다.
- 단, 마지막 위치 고정 후 충분히 이탈할 시간이 있어야 한다.

## 8. 난이도별 조정

### 쉬움

- 조명 각도 72도
- 조명 길이 화면 긴 축의 0.72배
- 조명 회전 지연 거의 없음
- Blind Mark 동시 개수 제한
- Blackout Pulse 조명 감소 약함
- Last Seen의 Needle 연계 없음

### 보통

- 기본 수치 사용
- P2부터 Gaze Split, Dark Corridor 사용
- P3부터 Afterimage Hunt, Blackout Pulse, Last Seen 사용

### 어려움

- 조명 각도 56도
- 조명 길이 화면 긴 축의 0.58배
- Shadow Step 재등장 시간이 짧음
- Peripheral Mine 최대 4개
- Afterimage Hunt의 Needle 각도 증가
- Last Seen 방사형 탄막 수 증가

어려움에서도 조명 밖 공격은 반드시 희미한 예고를 가져야 한다.

## 9. 렌더링/연출 메모

### 어둠 오버레이

- 기본 어둠 알파: P1 0.68 / P2 0.74 / P3 0.80
- 조명 내부는 부채꼴 그라데이션
- 조명 중심부는 약한 따뜻한 흰색
- 조명 외곽은 청회색으로 흐려짐

### 보스 외형

- 명확한 몸체보다 검은 실루엣 + 흰 윤곽선
- 조명 안에 들어왔을 때만 눈 또는 코어가 보임
- P3에서는 몸체가 끊어진 잔상처럼 보임
- 보스 창이 없으므로 UI보다 월드 오브젝트처럼 보여야 함

### 공격 예고

- 조명 밖: 낮은 알파의 회색/보라 실루엣
- 조명 안: 판정 범위 테두리와 중심점 표시
- 발동 직전: 짧은 흰색 글림 또는 외곽선 수축

### 사운드

- 조명 밖 위협은 작은 속삭임/노이즈
- 조명 안에서 위협 확인 시 짧은 클릭음
- Shadow Step 재등장 시 낮은 저음
- Blackout Pulse는 심장박동 같은 둔탁한 사운드

## 10. 구현 메모

권장 구조:

```cpp
enum class SkillType {
    ShadowStep,
    BlindMark,
    NeedleFromDark,
    PeripheralMine,
    GazeSplit,
    DarkCorridor,
    AfterimageHunt,
    BlackoutPulse,
    LastSeen
};

struct BlindThreat {
    SkillType type;
    float x, y;
    float ang;
    float radius;
    float t, warn, dur;
    bool revealed;
    bool hit;
};
```

핵심 판정:

- `isInLanternCone(x, y)` 함수 필요
- 조명 내부 여부에 따라 렌더 알파와 세부 표시를 다르게 처리
- 실제 피해 판정은 조명 여부와 무관하게 작동하되, 반드시 사전 예고가 존재해야 함
- 보스 본체는 조명 안에 있을 때만 완전한 알파로 렌더링

커서 조명 계산:

```cpp
float aimAng = atan2(mouseY - playerY, mouseX - playerX);
lantern.ang = approachAngle(lantern.ang, aimAng, turnSpeed * dt);
```

성능 주의:

- 어둠 오버레이는 전체 화면 1~2패스 안에서 처리
- 조명 그라데이션은 가능하면 기존 `drawCircle`, `drawLine`, `drawTri` 계열로 근사
- 위협 객체는 최대 24개 이하 유지
- 보스 창을 만들지 않으므로 fake window/scissor pass에 의존하지 않음

## 11. 다른 보스와의 역할 차이

### VOLLEY와 차이

VOLLEY는 무기별 정직한 예고와 발사 리듬을 학습시키는 보스다. BLINDSPOT은 예고를 숨기지 않지만, 예고를 정확히 읽으려면 커서를 돌려 확인해야 한다.

### TESS와 차이

TESS는 화면 장악과 중력 압박이 중심이다. BLINDSPOT은 화면을 직접 막는 대신, 플레이어가 볼 수 있는 정보량을 제한한다.

### Ether Sword와 차이

Ether Sword는 최종보스식 결단과 고피해/즉사 압박을 담당한다. BLINDSPOT은 특별 캠페인 보스답게 정보 판독과 시야 관리에 집중한다.

추천 포지션:

- 특별 캠페인 보스
- 어둠/시야 제한 테마 이벤트
- 보스 고유 창 없는 실험형 전투

추천 보상:

- 커서 조명 관련 증강
- 조준 방향 시야 확장 증강
- 어둠 속 적 표시 증강
- 회피 후 짧은 시야 확대 증강

## 13. 의도 요약

BLINDSPOT.null의 핵심은 "공격을 피하는 법"보다 "무엇을 먼저 확인할지"다.

좋은 플레이 감각:

- "보스를 더 때릴지, 주변 예고를 확인할지 고민된다."
- "조명으로 비추니까 위험 범위가 정확히 보인다."
- "어둠 속에서도 힌트는 있었고, 내가 놓친 것이다."

실패한 플레이 감각:

- "안 보이는 곳에서 갑자기 맞았다."
- "커서를 돌리느라 조작감이 답답하다."
- "계속 어두워서 피곤하기만 하다."

구현 시에는 정보 부족의 긴장감을 만들되, 모든 피해는 플레이어가 납득할 수 있는 예고를 가져야 한다.
