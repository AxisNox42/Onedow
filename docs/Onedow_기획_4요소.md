# Onedow — 제작 이유 · 강점 · 재미 · 타깃

> 항목마다 **핵심 한 줄 + 상세(짧게)**

---

## 1. 제작 이유

**핵심 한 줄**
```
「바탕화면」을, 창 크기만큼만 보이는 전장으로 바꾸고 싶었습니다.
```

**상세**
```
로그라이트는 많지만 대부분 「게임 화면 한 장」 안에서만 싸웁니다.
Onedow는 Windows 창·바탕화면을 전투 규칙으로 쓰고,
DWM 오버레이로 진짜 데스크톱 위에 게임을 띄웁니다.
뱀서류 빌드 재미 + 수동 조준 + 디버프 선택을 한곳에 담고 싶었습니다.
```

---

## 2. 게임의 강점

**핵심 한 줄**
```
익숙한 OS UI가 곧 규칙이고, 그 위에 깊은 로그라이트 빌드가 있습니다.
```

**상세**
```
· 창 = 시야 (클리핑) + 바탕화면 오버레이 — 다른 게임에 없는 연출·메카닉
· 증강·디버프·조합·직업·ACT 보스 — 런마다 다른 빌드·환경
· 수동 조준 슈팅 — 자동 공격 뱀서와 다른 조작감
· .exe/.sys 보스 — OS 메타가 패턴·세계관과 연결
```

---

## 3. 재밌다고 생각하는 이유

**핵심 한 줄**
```
「창을 어디에 두느냐」가 전술이 되고, 매 런 빌드가 달라집니다.
```

**상세**
```
· 창 밖은 안 보임 → 창 옮기기·겹치기가 곧 플레이
· 증강 + 디버프로 「강하지만 불편한」 한 판의 개성
· 보스·ACT마다 환경이 바뀌고, ENDLESS·메타로 「한 판 더」가 이어짐
```

---

## 4. 타깃 플레이어

**핵심 한 줄**
```
뱀서는 해봤는데, 새 규칙·수동 사격·OS 메타를 원하는 PC 로그라이트 유저.
```

**상세**
```
· VS·탕탕 경험자 — 조합·웨이브는 좋지만 자동 공격만으론 부족한 사람
· OneShot·OS 패러디 좋아하는 인디 PC 유저
· 빌드 실험·수동 에임을 즐기는 탑다운 슈팅 팬
(스토리 1회형·모바일 원핸드 클리어 위주 유저는 비타깃)
```

---
