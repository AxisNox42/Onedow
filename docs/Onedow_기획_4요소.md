# Onedow — 제작 이유 · 강점 · 재미 · 타깃

> PPT / 발표 스크립트용 · 항목마다 **핵심 한 줄 + 상세 설명**

---

## 1. 제작 이유

### 핵심 한 줄
```
「바탕화면」이라는 익숙한 공간을, 창 크기만큼만 보이는 전장으로 바꾸고 싶었습니다.
```

### 상세 설명
```
로그라이트·서바이벌 게임은 많지만, 대부분 「게임 전용 화면 한 장」 안에서만 싸웁니다.
반면 우리가 매일 쓰는 Windows는 창을 열고, 닫고, 겹치고, 옮기는 공간입니다.

Onedow는 이 익숙함을 그대로 전투 규칙으로 가져왔습니다.
플레이어·적·보스가 각자 가짜 OS 창을 소유하고,
창 안에서만 월드가 보이고 싸워집니다.
DWM 투명 오버레이로 실제 바탕화면 위에 게임이 떠 있기 때문에,
「내 컴퓨터 위에서 일어나는 일」처럼 느껴지는 경험을 만들고 싶었습니다.

또한 뱀서류의 「한 판 더, 다른 빌드」와
수동 조준 슈팅의 「에임·회피」,
디버프까지 고르는 「리스크 있는 빌드」를
한 프로젝트 안에서 합치고 싶었습니다.
```

---

## 2. 게임의 강점

### 핵심 한 줄
```
익숙한 OS UI가 곧 게임 규칙이고, 그 위에 깊은 로그라이트 빌드가 얹혀 있습니다.
```

### 상세 설명
```
【시스템·연출】
· DWM 투명 오버레이 — 진짜 바탕화면 위에서 플레이
· Fake Window + Scissor 클리핑 — 「창 = 시야」라는 명확한 규칙
· 멀티 창 z-order — 여러 창에 걸친 객체는 창마다 렌더, 전술·가독성 동시 확보
· .exe / .sys / .worm 보스명 — OS·바이러스 메타포가 패턴과 연결됨

【게임플레이·콘텐츠】
· 증강(일반~신화) + 디버프 + 조합 레시피 — 빌드 실험 폭이 넓음
· 시작 무기 6종·직업 5종(업적 해금) — 런마다 다른 출발점
· ACT 시스템 — 보스 클리어 시 런 전체 스폰·난이도 테마 변경
· 수동 조준·사격 — 자동 공격 뱀서와 차별화된 조작감

【기술·완성도】
· C++17 + OpenGL 배치 렌더 — 1인 개발로도 안정적인 프레임·대량 객체 처리
· 크리에이티브 모드·다국어(KR/EN/JP) — 테스트·발표·확장에 유리
```

## 3. 재밌다고 생각하는 이유

### 핵심 한 줄
```
「창을 어디에 두느냐」가 승패와 가독성을 동시에 바꾸고, 매 런마다 빌드가 달라집니다.
```

### 상세 설명
```
【즉시 재미 — 규칙 하나로 새로움】
· 처음엔 「창 밖은 안 보인다」는 규칙이 낯설지만,
  익숙해지면 창을 옮기고 겹치는 것 자체가 전략이 됩니다.
· 바탕화면 위에서 싸운다는 연출이, 평범한 탑다운과 다른 긴장감을 줍니다.

【중기 재미 — 빌드·선택】
· 레벨업마다 증강 3택1, 조건에 따라 디버프까지 선택.
  「강해지지만 불편해지는」 조합이 한 판의 개성을 만듭니다.
· 연쇄·차크람·드론·신화 등 무기·증강 시너지를 찾는 과정이 VS류의 중독성과 비슷하지만,
  수동 사격이라 「내 손으로 터뜨린다」는 체감이 더 큽니다.

【장기 재미 — 보스·ACT·메타】
· 보스마다 패턴·전조·ACT 테마가 달라, 같은 슈팅이라도 환경이 바뀝니다.
· 코인·업적·직업 해금으로 「다음 런엔 이렇게 해보자」가 이어집니다.
· ENDLESS 구간에서 자신의 빌드 한계를 겨루는 재미.

【개발자로서 재미있다고 느끼는 포인트】
· OS 메타 + 로그라이트 + 수동 슈팅이 겹치면서, 장르를 베낀 게 아니라
  규칙 하나(창=시야)에서 파생된 독자적 플레이가 나온다는 점.
```

## 4. 타깃 플레이어

### 핵심 한 줄
```
로그라이트·빌드덕과 PC·OS 감성을 좋아하는, 「뱀서는 해봤는데 뭔가 더 새로운 거」를 찾는 유저.
```

### 상세 설명
```
【1순위 — 핵심 타깃】
· Vampire Survivors·탕탕특공대 등 뱀서라이크 경험자
  → 성장·조합·한 판 더에 익숙하지만, 자동 공격만으로는 부족했던 사람
· 인디·실험적 UI/UX에 관심 있는 PC 유저
  → OneShot·OS 메타·데스크톱 패러디를 좋아하는 층

【2순위 — 확장 타깃】
· 탑다운 슈팅·듀댕·20MTD류 — 수동 에임·회피를 즐기는 유저
· 로그라이트 빌드 연구를 좋아하는 유저
  → 디버프·조합·신화 티어까지 파고들 타입

【3순위 — 비타깃 (기대치 조율)】
· 스토리·퍼즐 중심 1회성 경험을 원하는 유저 (→ OneShot 쪽)
· 순수 모바일 원핸드·스테이지 클리어만 원하는 유저 (→ 탕탕 쪽)
· 경쟁 FPS급 정밀 에임·PVP를 원하는 유저

【플레이어가 얻는 가치】
· 짧은 런으로도 「오늘은 이 빌드」 실험 가능
· 친숙한 OS 비주얼이라 진입 장벽은 낮고, 창 규칙은 깊음
· ACT·보스·메타로 장기적으로 갈수록 콘텐츠가 바뀜
```

## 발표용 4줄 요약 (슬라이드 한 장)

| 항목 | 핵심 한 줄 |
|------|------------|
| **제작 이유** | 바탕화면·OS 창을 전투 규칙으로 쓰고 싶었다 |
| **게임 강점** | 창=시야 + 데스크톱 오버레이 + 깊은 로그라이트 빌드 |
| **재미** | 창 위치가 전술, 매 런 빌드·ACT·보스가 다름 |
| **타깃** | 뱀서 경험자 중 새 규칙·수동 사격·OS 메타를 원하는 PC 유저 |

## 발표 클로징 (선택)

```
Onedow는 「내 PC 바탕화면」을 전장으로 바꾸고,
그 안에서 창을 움직이며, 조준하며, 빌드를 짜며 버티는 게임입니다.
```
