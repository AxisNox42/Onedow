## 슬라이드 02 · Development_Overview.sys

**슬라이드 제목**
```
Onedow — Development_Overview.sys
```

**섹션 탭**
```
Summary      → 요약

References   → 레퍼런스
Configuration → 구성
```

**프로젝트 개요 (Project Overview)**

**창 = 시야 (Window = Field of View)**
```
진짜 OS 창의 크기와 위치가 플레이어의 시야가 됩니다.
창 밖에서는 전투가 보이지 않으며, 창을 움직여 적을 찾아내야 합니다.
```

**증강 시스템 (Augment System)**
```
다양한 증강(Augment)을 조합하여 자신만의 빌드를 만듭니다.
런마다 다른 선택이 핵심입니다.
```

**ACT & 보스 패턴 (ACT & Boss Patterns)**
```
보스를 처치할 때마다 ACT 시스템이 전환되고,
각 ACT에 맞춰 몬스터·탄막 패턴이 바뀝니다.
```

**기술 스택 (Technical Stack)**
```
DWM 투명 오버레이와 OpenGL을 활용한 벡터 2D 그래픽.
Windows 환경에 최적화되어 있습니다.
```

**레퍼런스 게임 (Reference Games)**
```
· Vampire Survivors (성장 시스템)
· OneShot (창 메타 연출)
· OS 메타포 장르 (UI/UX)
```

## 슬라이드 03 · Game Concept & Strategy

**슬라이드 제목**
```
Onedow — Game Concept & Strategy
게임 컨셉 & 전략
```

**핵심 정체성 (CORE IDENTITY)**
```
DWM Overlay              → DWM 오버레이
Window Clipping          → 창 단위 클리핑
Target Audience          → 타깃 유저
MARKET POSITION          → 시장 포지션
Differentiation          → 차별점
Technical Differentiation → 기술적 차별점
```

**DWM 투명 오버레이**
```
Desktop Window Manager 기술을 활용하여
투명 화면 전체를 전장으로 전환합니다.
플레이어의 실제 작업 환경과 게임이 공존하는
독특한 몰입감을 제공합니다.
```

**창 단위 클리핑**
```
진짜 OS 창의 경계를 전투 영역으로 제한하는
클리핑 방식을 채택했습니다.
창을 옮기고 적을 찾아내는 것이
플레이의 핵심입니다.
```

**핵심 가치 (Core Value)**
```
단순한 슈팅을 넘어 'OS 환경'이라는 친숙함을
게임 메카닉으로 재창조합니다.
실제 바탕화면의 재미와 로그라이트의
반복 플레이를 결합하여
최대의 리플레이 가치를 제공합니다.
```

**타깃 유저 (Target Audience)**
```
로그라이트 매니아 & 데스크톱 메타포 선호층

Vampire Survivors의 중독성을 즐기면서,
새로운 시스템과 메타포에 관심 있는
하이퍼 캐주얼 유저를 타깃으로 합니다.
```

복잡한 로그라이트 상태를 효율적으로

GameManager 아키텍처를 설계했습니다.

## 슬라이드 06 · Game Structure & Play Flow

**슬라이드 제목**
```
Onedow — Game Structure & Play Flow
게임 구조 & 플레이 흐름
```

**스테이지 구조 (STAGE ARCHITECTURE)**

**0–5 · ACT: Adaptation (적응)**
```
기본 시스템 익히기 및 초기 난이도 상승 단계.
플레이어가 창 시야 규칙에 적응하는 구간입니다.
```

**6–15 · ACT: Escalation (확대)**
```
고급 빌드 및 보스전 빈도 증가.
극한의 빌드 최적화가 요구되는 심화 단계입니다.
```

**∞ · ACT: Infinite Loop (무한)**
```
한계에 도전하는 엔드리스 모드.
자신의 빌드가 어디까지 버티는지
검증하는 최종 콘텐츠입니다.
```

**플레이 플로우차트 (PLAY FLOWCHART)**
```
게임 시작 (GAME START)
    ↓
메인 메뉴 (MAIN MENU)
    ↓
무기 / 증강 선택 (WEAPON / AUGMENT SELECT)
    ↓
인게임 전투 (GAME PLAY — COMBAT)
    ↓
보스 조우 (BOSS ENCOUNTER)
    ↓
게임 오버 (GAME OVER) / 클리어 (CLEAR)
    ↓
빌드 최적화를 위한 반복 (REPEAT FOR BUILD OPTIMIZATION)
```
