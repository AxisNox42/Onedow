## 슬라이드 02 · Development_Overview.sys

**헤더**
```
Onedow — Development_Overview.sys
```

**탭/섹션 라벨**
```
요약 · 시스템 · 레퍼런스 · 구성
```

**Project Overview / 프로젝트 개요**

**Window = Field of View / 창 = 시야**
```
진짜 OS 창의 크기와 위치가 플레이어의 시야가 됩니다.
창 밖에서는 전투가 보이지 않으며, 창을 움직여 적을 찾아내야 합니다.
```

**Augment System / 증강 시스템**
```
다양한 증강(Augment)을 조합해 자신만의 빌드를 만듭니다.
런마다 다른 선택이 핵심입니다.
```

**ACT & Boss Patterns / ACT & 보스 패턴**
```
보스를 처치할 때마다 ACT 시스템이 전환되고,
각 ACT에 맞춰 몬스터·탄막 패턴이 바뀝니다.
```

**Technical Stack / 기술 스택**
```
DWM 투명 오버레이와 OpenGL을 활용한 벡터 2D 그래픽.
Windows 환경에 최적화되어 있습니다.
```

**Reference Games / 레퍼런스 게임**
```
· Vampire Survivors (성장·빌드 시스템)
· OneShot (창 메타 연출)
· OS 메타포 장르 (UI/UX)
```

**헤더**

```
Onedow — Game Concept & Strategy
```

**CORE IDENTITY / 핵심 정체성**

| 라벨 | 한국어 |
|------|--------|
| DWM Overlay | DWM 오버레이 |
| Window Clipping | 창 단위 클리핑 |
| Target Audience | 타깃 유저 |

| Differentiation | 차별점 |
| Technical Differentiation | 기술적 차별점 |

**DWM 투명 오버레이**
```
Desktop Window Manager 기술을 활용해
투명화면 전체를 전장으로 전환합니다.
플레이어의 실제 작업 환경과 게임이 공존하는
독특한 몰입감을 제공합니다.
```

**창 단위 클리핑**
```
진짜 OS 창의 경계를 전투 영역으로 제한하는
클리핑 방식을 채택했습니다.
창을 옮기고 적을 찾아내는 것이
플레이의 핵심입니다.
```

**Core Value / 핵심 가치**
```
단순한 슈팅을 넘어 'OS 환경'이라는 친숙함을
게임 메카닉으로 재창조합니다.
실제 바탕화면의 재미와 로그라이트의
반복 플레이를 결합해 최대의 리플레이 가치를 제공합니다.
```

**Target Audience / 타깃**
```
로그라이트 매니아 & 데스크톱 메타포 선호층

Vampire Survivors의 중독성을 즐기면서,
새로운 시스템과 메타포에 관심 있는
하이퍼 캐주얼 유저를 타깃으로 합니다.
```

**헤더**
```
Onedow — DEVELOPMENT_Process.cpp
```

**CORE IMPLEMENTATION / 핵심 구현**

**DWM + OpenGL Overlay**
```
Desktop Window Manager와 OpenGL을 결합해
투명화면 위에 게임 레이어를 구현했습니다.
시스템 리소스를 최소화하면서도
높은 프레임 안정성을 유지합니다.
```

**Multi-pass Scissor Clipping**
```
진짜 OS 창 영역에 맞춰 렌더링을 제한하는
기술입니다.
여러 개의 창이 겹치거나 이동할 때
정확한 클리핑으로 몰입감을 유지합니다.
```

**GameManager & Augment System**
```
복잡한 로그라이트 상태를 효율적으로
관리하기 위해 중앙 집중식
GameManager 아키텍처를 설계했습니다.
```

**DEBUG CONSOLE / 디버그 콘솔**

| ID | ISSUE & RESOLUTION / 이슈 & 해결 | STATUS |
|----|----------------------------------|--------|
| BUG-01 | 창 포커스 시 레이어 깜빡임 → DWM 레이어링 순서 수정 | **해결** |
| BUG-02 | 디버프 선택 화면 오버플로우 → 오버레이 투명도 조정 | **해결** |
| BUG-03 | 멀티 윈도우 좌표 불일치 → 좌표 변환 알고리즘 개선 중 | **진행 중** |

## 슬라이드 06 · Game Structure & Play Flow

**헤더**
```
Onedow — Game Structure & Play Flow
```

**STAGE ARCHITECTURE / 스테이지 구조**

**0–5 · ACT: Adaptation / 적응**
```
기본 시스템 익히기 및 초기 난이도 상승 단계.
플레이어가 창 시야 규칙에 적응하는 구간입니다.
```

**6–15 · ACT: Escalation / 확대**
```
고급 빌드 및 보스전 빈도 증가.
극한의 빌드 최적화가 요구되는 심화 단계입니다.
```

**∞ · ACT: Infinite Loop / 무한**
```
한계에 도전하는 엔드리스 모드.
자신의 빌드가 어디까지 버티는지
검증하는 최종 콘텐츠입니다.
```

※ **수정 권장 (실제 구현)**
```
ACT 0 · BOOT     — 워밍업 (기본 몬스터·증강 익히기)
ACT 1~5          — 보스 클리어할 때마다 테마·스폰 bias 변경
ACT ∞ · ENDLESS  — 5보스 클리어 후 무한 구간
```

**PLAY FLOWCHART / 플레이 플로우**

| 영어 | 한국어 |
|------|--------|
| GAME START | 게임 시작 |
| MAIN MENU | 메인 메뉴 |
| WEAPON / AUGMENT SELECT | 무기 / 증강 선택 |
| GAME PLAY (COMBAT) | 인게임 (전투) |
| BOSS ENCOUNTER | 보스 조우 |
| GAME OVER | 게임 오버 |
| CLEAR | 클리어 |
| REPEAT FOR BUILD OPTIMIZATION | 빌드 최적화를 위한 반복 |

※ **플로우 보강 권장 (한 줄씩 추가)**
```
직업 선택 → 시작 무기 3택1 → (레벨업) 증강 선택 → (조건) 디버프 선택
→ 보스 인터미션 / 런 상점 → 사망 → 코인·업적·직업 해금 → 재도전
```
