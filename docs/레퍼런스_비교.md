## 01 · vs 뱀파이어 서바이버스 (Vampire Survivors)

### 공통점
```
· 한 판(런) 안에서 시간이 지날수록 적이 많아지고, 플레이어는 점점 강해진다.
· 레벨업·선택을 통해 무기·능력을 조합하며 「내 빌드」를 만든다.
· 보스·고난도 구간에서 패턴을 읽고 버티는 서바이벌 감각이 있다.
· 「한 판 더」 — 죽어도 다음 런에서 다른 조합을 시도하고 싶은 로그라이트 구조.
· 2D 탑다운, 탄막·대량 몬스터, 가벼운 조작으로 빠른 템포를 유지한다.
```

### 차이점
```
· 시야: 뱀서는 맵 전체가 항상 전장. Onedow는 「가짜 OS 창 안」만 시야·전투가 인식된다.
· 조작: 뱀서는 이동 위주 + 자동 공격. Onedow는 WASD + 마우스 조준·사격(수동 에임).
· 성장: 뱀서는 무기·패시브 중심. Onedow는 증강 + 디버프 + 조합 레시피 + 직업·시작 무기.
· 세계관: 뱀서는 판타지·고딕. Onedow는 Windows·프로세스·.exe/.sys OS 메타포.
· 플랫폼 연출: 뱀서는 일반 게임 창. Onedow는 DWM 투명 오버레이로 「진짜 바탕화면」 위에 뜬다.
· 런 구조: 뱀서는 스테이지·타임 서바이벌. Onedow는 무한 런 + 보스 클리어 시 ACT 테마 전환.
```

### 한 줄 정리
```
「뱀서의 빌드 중독」 + 「창 시야·수동 사격·OS 세계관」
```

## 02 · vs 탕탕특공대 (Survivor.io)

### 공통점
```
· 뱀서라이크 계열 — 이동하며 몰려오는 적을 막고, 런 중 스킬·무기를 골라 성장한다.
· 짧은 판·반복 플레이에 최적화되어, 조합 실험이 핵심 재미다.
· 대량 몬스터, 보스전, 레벨업 선택 UI 등 「모바일 뱀서」가 익숙한 패턴을 공유한다.
· 한 손(또는 단순) 조작으로도 긴장감 있는 웨이브 서바이벌을 만든다.
· 영구 성장·메타(장비, 해금 등)로 재방문 동기를 준다.
```

### 차이점
```
· 플랫폼·타깃: 탕탕은 모바일·스테이지/챕터 클리어. Onedow는 PC·데스크톱·무한 런.
· 시야·전장: 탕탕은 고정 맵 전체. Onedow는 플레이어·적·보스가 각자 「창」을 가지며,
  창 밖은 보이지 않고, 창을 옮겨 시야와 전투 구역을 바꾼다.
· 조작: 탕탕은 이동 중심(공격 자동/반자동). Onedow는 조준·사격을 플레이어가 직접 한다.
· 성장 깊이: 탕탕은 스킬·장비 성장. Onedow는 증강 등급·디버프·신화·조합 등 빌드 폭이 넓다.
· 보스: 탕탕은 스테이지별 보스. Onedow는 VOLLEY·GLITCH·UNKNOWN.sys 등 OS 테마 보스 + ACT.
· 연출: 탕탕은 일반 2D UI. Onedow는 Win11 패러디·작업표시줄·가짜 창 크롬.
```

### 한 줄 정리
```
「탕탕의 웨이브·성장 감각」 + 「PC 데스크톱·창 단위 시야·수동 전투」
```

## 03 · vs OneShot

### 공통점
```
· Windows·OS·「창(Window)」을 게임의 핵심 연출·메카닉으로 사용한다.
· 플레이어가 일상적으로 쓰는 UI(창 테두리, 바탕화면)를 깨는 몰입·위트가 있다.
· 「게임이 OS 안에서 일어난다」는 메타포로 차별화한다.
· 인디 감성 + 강한 컨셉 하나로 기억에 남는 경험을 목표로 한다.
```

### 차이점
```
· 장르: OneShot은 퍼즐·어드벤처·RPG(스토리 1회성). Onedow는 액션 로그라이트(반복 런).
· 창의 역할: OneShot은 창 밖·OS와 「내러티브·4th wall」. Onedow는 창 = 「시야·클리핑·전투 규칙」.
· 전투: OneShot은 거의 없음. Onedow는 탄막·보스·증강 빌드가 본편.
· 플레이 시간: OneShot은 클리어형 단일 경험. Onedow는 ENDLESS·메타 성장·업적·직업 해금.
· 멀티플레이어 요소: OneShot은 NPC·이야기. Onedow는 z-order·멀티 fake window 렌더.
```

### 한 줄 정리
```
「OneShot의 창 메타」 + 「로그라이트 액션·반복 플레이·빌드」
```

## 종합 — Onedow만의 위치

### 세 게임과의 공통점 (Onedow가 가져온 것)
```
① 뱀서·탕탕에서: 런 중 성장, 빌드 조합, 웨이브·보스, 「한 판 더」
② OneShot에서: OS·창을 게임 세계의 일부로 쓰는 메타포
```

### 세 게임과의 차이점 (Onedow만의 것)
```
· 진짜 바탕화면 DWM 오버레이 (일반 게임 창이 아님)
· 가짜 OS 창 = 시야·클리핑 — 맵 전체가 아닌 「창 안」만 전장
· 수동 조준·사격 + 증강·디버프·조합이 동시에 있는 PC 로그라이트
· 보스·ACT가 OS 프로세스 테마 (.sys / .exe / .worm)
```

### 발표용 클로징 한 줄
```
Onedow는 「뱀서·탕탕이 익숙하게 만든 로그라이트」 위에
「OneShot이 보여준 창 메타」를 「전투 규칙」으로 올린 게임입니다.
```
