# Onedow — 레퍼런스 게임 비교 (PPT용)

> 슬라이드 02·03 보강 또는 **별도 1장**으로 사용  
> 비교 대상: **뱀파이어 서바이버스** · **탕탕특공대 (Survivor.io)** · **OneShot**

---

## 한 장 요약 (발표 멘트용)

```
같은 장르(로그라이트·서바이벌)를 공유하지만,
Onedow만 「창 = 시야」와 「진짜 바탕화면 오버레이」를 전투 규칙으로 씁니다.
뱀서·탕탕은 익숙한 ‘한 화면에서 버티기’,
OneShot은 ‘창 메타’의 선행 사례,
Onedow는 그 둘 사이에서 ‘액션 + OS UI’를 합친 형태입니다.
```

|------|-------------------|--------------------------|------------|
| **장르** | 2D 불릿 헤븐 로그라이트 | 모바일 뱀서라이크 슈팅 | 2D 오버레이 로그라이트 |
| **화면** | 게임 전용 단일 맵 | 스테이지별 단일 맵 | **실제 Windows 바탕화면 + 가짜 OS 창** |
| **시야** | 맵 전체가 항상 보임 | 맵 전체가 항상 보임 | **창 안만 렌더·전투 인식 (클리핑)** |
| **조작** | 이동 위주 (자동 공격) | 이동 위주 (자동/반자동 공격) | **WASD + 마우스 조준·사격** (수동 에임) |
| **성장** | 레벨업 → 무기·패시브 픽 | 런 중 스킬·무기 조합 | **레벨업 증강 + 디버프 + 조합 + 직업·시작 무기** |

| **메타** | 캐릭터·무기 해금 | 장비·영구 성장 (모바일) | **코인·업적·직업 해금·도감** |
| **핵심 재미** | 빌드 폭발·한 판 더 | 한 손 조작·대량 몬스터 | **창 옮기기·z-order·바탕화면 위 전투** |

| 구분 | OneShot | **Onedow** |
|------|---------|------------|

| **창 활용** | 창 밖·OS와 **내러티브** 연출 | 창과 **전투·시야 규칙** |

## 슬라이드용 짧은 카드 (각 2~3줄)

### vs Vampire Survivors
```
공통: 레벨업 빌드, 몬스터 웨이브, 보스, 한 판 더.

차이: 뱀서는 「맵 전체 = 시야」 자동 공격.
      Onedow는 「가짜 창 = 시야」 수동 조준 + 디버프 선택.
```

### vs 탕탕특공대 (Survivor.io)
```
공통: 뱀서라이크, 스킬 조합, 대량 적, 보스전.

차이: 탕탕은 모바일·스테이지 클리어·이동만 조작.
      Onedow는 PC 데스크톱·무한 런·창 위치가 전술.
```

### vs OneShot
```
공통: Windows·창을 세계관·연출에 사용.

차이: OneShot은 퍼즐·스토리 중심 1회성 경험.
      Onedow는 슈팅·로그라이트·반복 런.
```

## 발표 Q&A 예상

**Q. 뱀서랑 뭐가 달라요?**  
→ 시야가 **창 단위**이고, **수동 조준**이며, **디버프를 고르는** 로그라이트입니다.

**Q. 탕탕특공대랑?**  
→ 비슷한 **성장·웨이브** 감각은 같지만, **스테이지 클리어**가 아니라 **데스크톱 위 무한 런** + **창 이동**이 핵심입니다.

**Q. OneShot이랑?**  
→ OneShot은 **창으로 이야기**하는 게임, Onedow는 **창으로 싸우는** 게임입니다.
